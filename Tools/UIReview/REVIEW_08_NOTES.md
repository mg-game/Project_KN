## 검토 화면 열기


브라우저에서 `http://localhost:8772/handoff.html`을 열면 전달 규격을 확인합니다. `http://localhost:8772/?view=results`는 결과 검토부터 시작합니다. `?view=growth`는 강화부터 시작합니다. `http://localhost:8772/`은 홈에서 시작합니다. 외부 CDN·API·폰트 다운로드는 없습니다. 관리형 Chrome의 직접 file:// 열기는 정책상 차단되어 로컬 HTTP로 검증했습니다.

## 08 화면 전환·입력 취소

재현한 문제 두 가지를 수정했습니다. 편성 슬롯을 누른 채 홈으로 이동하면 늦게 유실자가 해제되고 편성 화면이 다시 열리던 문제, 강화 중 창에서 포커스가 떠나도 구매가 계속되던 문제입니다.

- 화면/비율 변경 때 미확정 편성 홀드·드래그를 정리하며 유실자 배치를 보존합니다.
- 프리셋 홀드는 화면/포커스 이탈이나 8px 초과 이동에서 저장 없이 취소합니다. 취소 후 우연한 탭 불러오기도 막습니다. 정상 홀드 저장과 나중의 탭 불러오기는 유지합니다.
- 조준은 화면/비율/포커스 전환에서 비용 없이 취소합니다. 이후 새 탭은 정상 소환합니다.
- 강화 홀드는 포커스 이탈에서 반복을 중지합니다. 이미 완료한 구매는 보존하고 새 입력으로만 다시 구매합니다.
- 공명 확인 중 다른 화면으로 나가면 기억 조각을 쓰지 않습니다.

홀드 시간과 비용·밸런스 예시는 그대로입니다. `verify-flow.cjs`는 실제 포인터로 조작하고, 포커스 이탈은 브라우저 `blur` 이벤트로 정리 경로를 실행합니다. Unity·실기기 앱 숨김/복원 검증은 아닙니다. `flow-*-08.png`는 해당 흐름의 캡처입니다. 07의 가독성 스타일과 참조 캡처는 유지합니다. 현재 화면 규격은 `handoff-*-08.png`와 `ScreenHandoff.json`을 확인합니다.

## 07 가독성·상태 표시

선택한 전투·성장의 주요 보조 문구를 390px 논리 참조에서 11px 이상, 성장 구매 버튼은 12px로 보완했습니다. 내구·비용·재사용 대기·수급, 성장 배지·수선점 보상·공유 레벨·효과 설명을 확인합니다. 전역 최소 크기나 실기기 접근성 인증은 아닙니다.

단추가 부족하면 비용과 `부족`, 잠금은 `1-1 후 해금`, 최대는 `최대 레벨`을 표시합니다. 수선점에는 부족한 단추 수/해금 조건을 안내합니다. 전투에는 부족·소환 상한·AUTO/배속 해금·재사용 대기 이유를 짧게 표시합니다. 안내는 포인터를 가로채지 않습니다. 비용 공식·밸런스·입력 시간·소비 차단 규칙은 유지했습니다.

색상 6쌍은 브라우저의 실제 계산 스타일을 읽었으며 최소 대비 7.38:1입니다. 그라디언트 끝점과 반투명 받침의 흰 배경 합성을 사용했습니다. 화면 전체/상위 투명도/실기기 검수는 아닙니다. 기본 긴 강화 화면은 첫 줄 구매 버튼이 보이고, 더 긴 내용은 스크롤합니다.

`readability-board-*-07.png`는 보드용 캡처입니다. 부족 화면은 안내와 카드 비용을 함께 보이도록 본문을 80px 스크롤했습니다. `handoff-*-08.png`에는 8개 화면×2비율의 현재 배치가 있습니다. 과거 중복 캡처는 새 ZIP에서 줄였고 이전 ZIP 01~06은 보존했습니다.

## 06 통합 검수·전달 규격

- 전달 뷰어에서 홈·전투 / 편성 / 실패 / 강화 목록 / 성장 상세 / 공명 확인 / 일시정지 / 결과를 고르고 긴 화면·짧은 화면을 비교합니다. 영역이나 목록을 누르면 해당 좌표가 강조됩니다.
- 좌표는 왼쪽 위 원점의 브라우저 논리 px입니다. 390×845, 390×693 참조이며 Unity RectTransform·실기기 Safe Area 확정값이 아닙니다. `build-handoff.cjs`로 JSON·16개 캡처를 재생성합니다.
- ART-01~15 + D-44를 대조합니다. PNG 후보 48종, 코드 프리뷰, UI 범위 밖 작업을 구분하며 최종 채택 상태를 바꾸지 않습니다. PNG 후보는 05와 바이트 단위로 같습니다.
- 강화 시트 뒤의 일시정지·배속·AUTO·소환·투자가 키보드로 실행되던 문제를 수정했습니다. 공명 취소/확정 뒤에도 차단을 유지하며 하단 탭·전투 알림은 사용할 수 있습니다.
- 실패 리포트는 배경 입력을 막고 3개 CTA 안에서 포커스를 순환합니다. 강화 시트는 Escape로 닫고 강화 탭으로 포커스를 돌립니다.
- 긴 편성 화면에서 홈용 덱 위치가 덮어쓰던 문제와 작은 화면의 목록/안내 겹침을 수정했습니다. 요약·덱·프리셋·목록·안내·복귀 버튼의 세로 경계를 두 비율 모두 검사합니다. 가로 목록 스크롤은 의도된 동작입니다.
- 최종 채택·수선점 교체 작화·8–11px 보조 문구 가독성·노치와 홈 안전 영역·Unity 임포트/압축/TMP·실기기 검수는 남아 있습니다.

## 전투 결과·보상 검토

- 일반 승리, 같은 구역 반복, 10스테이지 보스, 실패 일부 보상, 연속 실패 후 한 구역 후퇴, 퇴각을 비교합니다.
- 보상은 자동 정산 표시입니다. 보상 아이콘이나 자세히 보기를 누르면 내역을 확인합니다. 수령 버튼은 없으며 성장 지갑·실제 세이브·아이템을 변경하지 않습니다.
- 외부 **자동 이동 흐름 재생**을 켜면 실제 시간 1.5초 후 정해진 구역으로 이동합니다. 상세 확인은 최초 결과 시점부터 최대 6초이며 반복해서 눌러도 더 늘어나지 않습니다. 즉시 이동은 한 번만 처리하고, 다른 화면으로 나가면 자동 이동을 취소합니다.
- 결과 동안 배경 소환·수선등 조작을 막습니다. 실패 화면의 편성/강화는 기존 검토 화면으로 이어집니다. 강화 시트 위 클리어/실패 알림도 결과로 연결됩니다.
- 단추 86/180, 사탕 3/10, 실패 진행도 60%와 보존 단추 15는 정본 공식의 고정 예시입니다. 보너스 0%, 이벤트 1배, 재료 드롭·호감도 초상은 예시입니다. 실제 난수·인벤토리·트랜잭션은 연결하지 않았습니다.
- 퇴각의 부분 보상 기준은 미정이므로 지급 수치·0 보상을 제시하지 않습니다. 신규 구조·별 평가·챕터 보상은 추가하지 않았습니다.
- 작은 화면에서는 본문을 스크롤할 수 있고, 다음 전투와 회복 버튼은 고정됩니다. `handoff-results-tall/short-08.png`는 현재 결과 배치입니다. 6상태는 검토 화면과 `verify-results.cjs`에서 재현합니다.

## 강화·성장 검토

1. 목록: 고정 단추·기억 조각, 수선점 강화와 10레벨 보상 예고, 추천 줄, 유실자 2열 카드.
2. 카드: 역할·예시 편성 배지·공명 가능 점, 단추 비용·부족/잠금/최대. 레벨업 중 카드 순서가 바뀌지 않습니다.
3. 상세: 지킴이·잔향이가 공유하는 레벨, 공격력·체력 전후와 증가값, ×1/×10.
4. 공명: 공용 능력치·잔향이 소환 비용·지속 시간을 비교하고 확인 후 기억 조각을 씁니다. 취소하면 보존합니다.
5. 피드백: 짧은 칩으로 연속 레벨업을 합산합니다. 우편 지급은 예고 문구로만 표시합니다.

길게 누르기는 0.45초부터 반복합니다. 스크롤·포인터 이동/취소·뷰 변경·부족 시 멈춥니다. ×10은 살 수 있는 수로 줄이며 수선점 최대 구매는 2레벨 이상 살 수 있을 때 켜집니다. 옆의 상태 선택으로 부족·부분 구매·최대·잠금·공명 하한을 비교할 수 있습니다.

수치와 비용·능력치·전투력·편성 배지는 검토용 예시입니다. 실제 밸런스·경제·세이브·온라인 트랜잭션·실시간 수급을 구현한 것이 아닙니다. 한계 돌파·기억 각성·동시 출현 증가는 P1로 유지합니다.

## 검증 재현

미리보기는 이미 렌더링된 PNG를 사용하므로 Node 패키지가 필요하지 않습니다. 검증/출력 스크립트는 현재 Linux 환경의 Node, Sharp, Playwright, `/usr/bin/chromium`을 사용합니다. 서버를 실행한 뒤 필요할 때 실행합니다.

```sh
node verify-flow.cjs
node build-flow-board.cjs
node verify-readability.cjs
node verify-handoff.cjs
node verify-results.cjs
node verify-growth.cjs
node verify.cjs
node verify-interactions.cjs
```

리소스 재출력은 `node build-assets.cjs` 다음 `node refine-delivery.cjs` 순서입니다. 신규 작화 채택·Unity 임포트·플랫폼 압축·TMP·실기기 터치/성능 검수는 남아 있습니다. 브라우저 44px 검수는 참조 논리 크기이며 실기기 인증이 아닙니다.
