# Project_KN
2D 방치형 RPG 게임 (Unity)

## 빠른 시작
1. `git lfs install` → `git clone` → `git lfs pull`
2. UnityYAMLMerge 등록 ([CONTRIBUTING.md §1-1](./CONTRIBUTING.md))
3. Unity Hub → Add project from disk → 저장소 루트
