## 0. 개요
- 목적: **만난 유실자를 보고 · 키우고 · 알아 가는 곳**. 방치형이라 키우기는 강화 탭(`UI_Growth`)이 빠른 길이고, 여기는 **한 명을 깊게** 보는 곳.
- M1 화면: **C-1 유실자 탭(격자)** · **C-2 유실자 상세(머리 + 성장 칸 + 4탭)** · **C-3 외형 탭** · **C-4 정보 탭(이야기 · 호감도)**. 진화 기억도 탭은 `SYS_Evolution` §2.7, 성장 칸은 `UI_Growth` §2.3을 따른다.

## 1. 현재 구현 (요약)
- **친구들 탭** (`CharacterPanel`): DB의 모든 계보(M1 7)를 4열 격자로. 보유 먼저 → 정렬(⇅ 등급순 / 레벨순). 머리 줄 = 도감 알약(1-10 전 '도감 보유/전체', 뒤 '도감 n%' + NEW) · '진화 제작 가능 N' 칩 · 정렬 버튼.
- **계보 카드** (`CharacterCardView`): 보유 = 초상화 · 특성 칩 · 'Lv.N' · '진화 k/n' 알약 · 전투력 · 호감도 Lv5 이상 하트 틀 · 빨간 점(진화 · 공명 · 외형 · 받을 호감도). 미보유 = 검은 실루엣 · 종족 이름 · '미보유' 칩.
- **캐릭터 상세** (`CharacterDetailPopup`): 큰 초상화 · 이름(외형 반영) · 종족 · 별 · 역할 / 성향 / 특성 칩(누르면 말풍선) · 계보 레벨업(실타래, 길게 누르면 반복) · 호감도 · 기억편 · 계보 공명 + 탭 **[진화 기억도 | 스킬·시너지 | 의상 | 정보]**. 왼쪽 위 잔액 칩(실타래, 2026-11-14 단추에서 바뀜).
  - 다른 계보로 열면 진화 기억도 탭부터, 같은 계보면 보던 탭. `UINav.OpenCharacter(계보, 탭)`로 어디서든 원하는 탭으로 열 수 있음.
  - 미보유 계보 = '소환하러 가기' → '‹ {이름} 상세로' 돌아가기 칸을 넣고 소환 시트로.
  - 잠금: 레벨업 1-1 전(버튼 꺼짐 + '1-1 클리어 시') · 의상 2-5 전(탭 이름 옆 자물쇠).
- **스킬·시너지 탭**: 기본형 고유 스킬 카드(+ '잔향이 전용' 칩) · 형태별 스킬 줄 · 이 계보가 여는 시너지(특성 · 역할 · 조합, 지금 편성 상태).
- **의상 탭** (`CostumeListView`): '보유 외형 n/m · 보유 효과 공격력 +N%' + 기본 외형 + 계보 의상 줄(초상화 · 이름 · 감정 변화 "외로움 → 위로" · 획득 방법 · 진행도 · [해금] / [장착] / [장착 중] / 상점).
- **정보 탭**: 호감도 칸(받을 단계 → 점) · 이야기(원래 사물 · 성격) · 프로필(종족 · 체형 · 특성 · 컬러) · 기본형 능력치.

## 2. 기획 방향 (To-be) — DD

### 2.1 화면 흐름
```
하단 탭 [유실자] ─→ C-1 유실자 탭 (시트, 전투는 뒤에서 계속)
  ├─ 머리 도감 알약 탭 ─→ 도감 (1-10 전이면 잠금 토스트)
  ├─ '진화 제작 가능 N' 칩 탭 ─→ 그 계보 C-2 · 진화 기억도 탭
  ├─ 보유 카드 탭 ─→ C-2 유실자 상세
  │    ├─ 성장 칸 [레벨업] [공명] ─→ UI_Growth §2.3
  │    ├─ 탭 [진화 기억도] ─→ SYS_Evolution §2.7
  │    ├─ 탭 [스킬·시너지] ─→ 시너지 줄 탭 → 시너지 상세
  │    ├─ 탭 [외형] ─→ C-3
  │    └─ 탭 [정보] ─→ C-4
  └─ 미보유 카드 탭 ─→ C-2 (미보유 모양)
       └─ [찾으러 가기] ─→ M1: 소환 시트 (‹ 상세로 칸) / P1: 구조 대상이면 원정 탭 · 유실표 장부 쪽
```

### 2.2 C-1 유실자 탭 — 요소별 기능
1. **머리 줄**: ① 도감 알약 '수선 장부 n%' (D-55 도감 = 수선 장부, 이름은 §3 #6) ② '진화 제작 가능 N' 칩 (0이면 숨김) ③ 정렬 '⇅ 등급순 / 레벨순'.
2. **격자**: 4열. M1 7장이라 2줄 — 빈 칸 없이 7장만 (소프트런칭 9 · 정식 15에서도 같은 규칙).
3. **보유 카드**: 초상화 · 특성 칩 · 'Lv.N' · 진화 알약(M1 '진화 k/n' 그대로, P1 단계 표시 §3 #3) · 전투력 · 하트 틀 · 빨간 점.
4. **미보유 카드**: 실루엣 · 종족 이름 · **'아직 못 찾음'** 칩 (§3 #1). 실루엣은 흐리게 하지 않음(지금 규칙 — 대비 4.5 이상).
5. 빨간 점 우선: 진화 제작 가능 > 공명 가능 > 받을 호감도 > 받을 외형 (카드에는 점 하나만).

### 2.3 C-2 유실자 상세 — 요소별 기능
1. **머리**: 초상화(장착 외형) · 이름(외형 이름 반영) · 원래 사물(종족) · 별 · 칩 3종(역할 · 성향 · 특성 — 누르면 설명 말풍선).
2. **성장 칸**: `UI_Growth` §2.3 그대로 (레벨업 전→후 미리보기 M1 · 공명 '준비 완료' 덮개).
3. **탭 4개**: [진화 기억도 | 스킬·시너지 | 외형 | 정보] — 이름만 '의상' → **'외형'** (D-55 #7).
4. **처음 여는 탭**: 지금 = 다른 계보면 진화 기억도. To-be = **그 계보를 처음 열 때 한 번만 [정보]**(이야기 먼저), 그 뒤로는 지금 규칙 (§3 #2).
5. **미보유 상세**: 성장 칸 자리에 '아직 못 찾은 유실자예요' + [찾으러 가기]. 탭은 [정보]만 열림(이야기 일부 · 실루엣), 나머지 탭 자물쇠.

### 2.4 C-3 외형 탭 (D-55 반영)
1. 머리: **'보유 외형 n/m · 보유 효과 공격력 +N% / 최대 +10%'** — 상한 도달 시 '+10% (최대)' 금빛.
2. 줄 순서: 장착 중 → 받기 가능(빨간 점) → 보유 → 조건 진행 중 → 이벤트 · 시즌(상점 · 수첩).
3. 줄 행동: [받기] (조건 충족) → [입기] → [입는 중] (금) · 미충족 = 진행도 '원정 3/5회' · 이벤트 = [상점 가기 ›].
4. P1 (D-55 #3): 직업 형태 9종이 들어오면 짝짝이 19줄 → 머리에 필터 칩 [전체 · 보유 · 미보유].

### 2.5 C-4 정보 탭
1. 호감도 칸(맨 위, 받을 단계 → [받기]) · 2. 이야기(원래 사물 · 잃어버린 사연) · 3. 프로필 · 4. 기본형 능력치 — 지금 그대로.
- 컨셉 연결: 이야기 칸 제목 = **'잃어버린 이야기'**, 구조(P1)로 만난 유실자는 구조 장면 다시 보기 버튼 (P1, `SYS_Rescue`).

## 6. 확장성 · 유지보수
- 격자는 DB 계보 수를 그대로 그림 → 로스터가 15명으로 늘어도 코드 수정 없음. 15명이 넘으면 머리에 특성 필터 칩 추가 (P2).
- 탭 열기는 `UINav.OpenCharacter(계보, 탭)` 하나로 모여 있음 → 새 진입(도감 · 외형 구매 '바로 입혀 보기' 등)도 같은 길.

> 💡 **조합 제안 (검토용)** — 호감도 × 외형
> 호감도 단계 보상 중 하나를 **"그 유실자가 좋아하는 외형 고르기"** 로. 외형이 능력치 상한(10%)으로 묶인 대신, "누구를 아끼는지"가 외형 수집으로 이어져 수집형 애착 루프가 생김.
