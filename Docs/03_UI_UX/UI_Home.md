> 핵심 발견: **"홈"이 두 개다.** 코드의 홈 = **사냥 화면**(전투가 계속 돌고 메뉴가 그 위에 시트로 올라옴). UI 기획서의 홈 = **수선점 집**(HM-001, 주민이 사는 집 + 시설 핫스팟). 이 문서는 M1 홈을 정하고, 두 그림을 하나로 잇는 방법을 제안한다 (§3 #1).

## 0. 개요
- 목적: 방치형의 첫 화면 = **"내가 없어도 싸우고 모으는 중"**이 보이는 곳. 들어오자마자 받을 것 · 할 것 · 다음 목표가 한눈에.
- M1 화면: **H-1 홈(사냥)** · **H-2 하단 탭 + 시트** · **H-3 복귀 · 잠자기**.
- 다른 화면과의 관계: 전투 HUD(`UI_Battle`)는 홈 위에 그대로 얹힌다 — 전투 화면 = 홈.

## 1. 현재 구현 (요약)
- **MAIN = 사냥**: 앱을 켜면 언제나 MAIN. 스테이지 전투가 자동으로 계속 돈다 (클리어 → 다음 스테이지 · 실패 → 한 칸 뒤로 · 보스 자동 재도전, D-28 #9).
- **하단 탭 바 7칸**: `강화 · 편성 · 친구들 | 사냥 | 원정 · 소환 · 상점`. 옆 탭 6개는 **전투 위로 시트**를 연다(전투는 뒤에서 계속). 같은 탭 다시 누름 · 사냥 · 끌어 내림 = 시트 닫고 MAIN.
- **상단 바** (높이 130 — 전투를 크게): 수선점 레벨 · 전투력 칩(누르면 권장 전투력) · 단추 / 별조각 칩 · 초당 단추 · 우편 배지 · ≡ 메뉴(일지 · 출석 · 이벤트 · 가방 · 공지 · 설정).
- **전투 HUD**: 스테이지 · 보스까지 처치 진행(보스 등장 후 보스 체력) · 수선점 내구 · 잔향 · AUTO / 배속.
- **스테이지 패널 + 권장 전투력 알약** (`내 전투력 / 권장` + 여유 · 도전 · 어려움) → 누르면 **챕터 지도**(10칸).
- **빠른 아이콘 레일** 좌우 (이벤트 > 출석부 > 수선 일지 > …, 시트 열리면 사라짐).
- **수선 바구니 위젯** (오른쪽, 4단계 그림 + 시간 알약, 가득이면 금빛 흔들림).
- **가이드 퀘스트 줄** (왼쪽 아래, 보상 그림 · 문구 · 진행 막대, 완료면 "받기", 아니면 그 기능으로 이동).
- **잠자기 모드**: 2분 무입력 → 화면 반 어둡게 + "쉿, 친구들이 수선점을 지키고 있어요" + 실시간 숫자.
- **복귀 화면** "다녀오셨어요!" (10분 넘게 비우면) · **다시 만난 날** 카드 (며칠 만에).
- 강화 탭 아이콘: x10 강화를 살 수 있으면 금빛이 숨쉼.

## 2. 기획 방향 (To-be) — DD

### 2.1 화면 흐름
```
[앱 실행]
  → IF 비운 시간 ≥ 10분 → (H-3) 복귀 화면 "다녀오셨어요!" → [받기] → 보상 날아가기
  → IF 며칠 만 → 다시 만난 날 카드 먼저
  → (H-1) 홈 = 사냥 (전투 진행 중)
(H-1) 홈
  ├─ 하단 탭 (옆 6개) ─→ (H-2) 시트 (전투는 뒤에서 계속, 소리만 낮춤)
  │     └─ 같은 탭 · 사냥 · 아래로 끌기 ─→ 홈
  ├─ 스테이지 패널 ─→ 챕터 지도 ─→ 칸 선택 (파밍 · 보스 도전)
  ├─ 수선 바구니 ─→ 바구니 팝업 (받기)
  ├─ 가이드 퀘스트 줄 ─→ 완료면 받기 / 아니면 그 기능으로 이동 + 손가락
  ├─ 빠른 아이콘 ─→ 이벤트 · 출석 · 일지
  ├─ ≡ 메뉴 ─→ 가방 · 공지 · 설정 …
  └─ (P1) 수선점 탭 ─→ 수선점 안 (주민 생활 · 시설) = HM-001 · HM-002
[2분 무입력] → (H-3) 잠자기 모드 → 아무 입력 → 홈
```

### 2.3 H-1 요소별 기능
1. **상단 바** : 현재 구현 그대로. 전투력 칩 탭 → 권장 전투력 토스트 · 재화 칩 탭 → 얻는 곳
2. **전투 HUD** : `UI_Battle` §2 ①~④ (스테이지명 · 제한시간 · 웨이브 · 보스 HP / 남은 적)
3. **권장 전투력 알약** : `내 전투력 / 권장` + 평가 낱말 칩 → 탭 = 챕터 지도 (현재 구현)
4. **⏸ · 배속 · AUTO** : `UI_Battle` §2 ⑤~⑦ (오른쪽 세로)
5. **지킴이 초상 5** : `UI_Battle` ⑧ (왼쪽 세로)
6. · 8. **빠른 아이콘 레일** : 좌 1 · 우 2칸, 우선순위 = 이벤트 > 출석 > 수선 일지 (현재). **시트가 열리면 사라짐**
7. **전장** : `UI_Battle` ⑨~⑪
9. **수선 바구니 위젯** : 4단계 그림 + 시간 알약 · 가득 = 금빛 · 탭 = 바구니 팝업 (현재)
10. **가이드 퀘스트 줄** : 현재 구현 그대로. 튜토리얼(D-32) 끝난 뒤 다음 할 일 1줄
11. **잔향 + 수선등** : 잔향 `보유/상한 · +초당` 오른쪽에 `[🏮 L2 → 20]` (`UI_Battle` ⑫ · ⑭ 합침)
12. **소환 덱** : `UI_Battle` ⑬ 그대로
13. **하단 탭 바 7칸** : 이름 = `강화 · 편성 · 유실자 | 사냥 | 원정 · 소환 · 상점` ("친구들" → "유실자", D-43 #7). 잠긴 탭 = 자물쇠 + 해금 스테이지

### 2.4 H-2 시트 규칙
```
[옆 탭 누름]
IF 탭 잠김 → 자물쇠 흔들기 + "N-N 클리어하면 열려요" 토스트 (현재 TabGate)
ELSE IF 같은 탭이 열려 있음 → 시트 닫기 → 홈
ELSE → 시트 열기 (전투는 뒤에서 계속 · 소리 낮춤 · 빠른 아이콘 · 가이드 줄 숨김)
[시트 열린 동안 전투 이벤트]
  보스 등장 · 수선점 위기(30% 이하) · 클리어 / 실패 → 시트 위 작은 알림 칩 (탭 = 시트 닫고 홈)  🆕
  ※ 시트가 전투를 다 가려서 위기를 놓치는 문제 대응
[강화 탭 아이콘] x10 강화 가능 → 금빛 숨쉬기 (현재)
```

### 2.5 H-3 복귀 · 잠자기
- **복귀 화면** (10분 이상): "N시간 N분 동안 유실자들이 수선점을 지켰어요" + 단추 · 처치 수 · 바구니 상태 → `[받기]` (현재 구현, 문구만 "친구들" → "유실자")
- **잠자기 모드** (2분 무입력): 현재 구현 그대로 — 방치형의 "보고만 있어도 되는" 화면
- 순서 고정: 다시 만난 날 → 복귀 화면 → 이벤트 시작 카드 → 홈 (한 번에 하나, 현재 발표자 규칙)

## 6. 확장성 · 유지보수
- 홈 = 전투 화면이라 **전투 UI(`UI_Battle`) 수정은 곧 홈 수정** → 두 문서의 레이아웃 표(§2.2 · UI_Battle §1)를 같이 고칠 것
- P1 수선점 집은 "수선점 탭 → 집 안" 한 진입점만 추가하면 되게 홈 구조를 바꾸지 않는다
- 미리보기: [`KN_Preview`](../00_Overview/KN_Preview.md) 전투 탭을 홈 레이아웃으로 바꿔 보여 준다

> 💡 **조합 제안 (P1 검토용)** — 방치형 "전투 = 홈" × 수집형 "주민 생활"
> 전장 가운데 수선점을 누르면 카메라가 수선점 안으로 줌 인 → 주민(편성 밖 유실자)이 생활하는 집. **편성에 안 쓰는 유실자가 집에서 "일"을 하며 작은 방치 보상(재료 · 기억 조각)**을 만든다. 편성 밖 캐릭터에게도 쓸모가 생기고(수집 동기), 홈 구조는 그대로 — HM-001의 감성을 사냥 화면 안에 넣는 방법.
