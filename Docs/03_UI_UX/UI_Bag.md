> 결론 먼저: 가방은 **"재료 도감 + 얻는 곳 안내"** 로 이미 잘 짜여 있다 (없는 재료도 흐리게 보이고, 누르면 얻는 곳으로 바로 가고, 돌아오는 칩까지). 바꿀 것은 **D-54 이름(원정 → 의뢰)을 바로 가기에 맞추는 문구**와, P1 수선점 시설(D-55)이 재료를 쓰기 시작할 때 **"어디에 쓰는지"** 줄을 더하는 것.

## 0. 개요
- 목적: "이 재료 어디서 얻지?" "뭐에 쓰지?"를 **한 번 눌러서** 해결. 방치형 재료 막힘의 출구.
- 진입: 홈 ≡ 메뉴 → 가방 (M1 7탭에 없음, D-44) · 진화 레시피 · 부족 팝업에서 재료 칸 탭.
- M1 화면: **B-1 가방** · **B-2 재료 정보** · **B-3 부족 팝업의 얻는 곳**(공용).

## 1. 현재 구현 (요약)
- **가방** (`BagPopup`, 창 1060): 모든 재료(9종)를 보여 줌 — 없는 재료는 흐리게(수량 0 = SubText), 가진 수는 금빛. 순서 = 가진 것 먼저 → 높은 등급 먼저. 그 밖에 가진 아이템도 함께.
- 창 아래 늘 **'재료 모으는 곳'** 칸: '재료는 원정·던전·상점에서 모을 수 있어요' + 바로 가기 **[원정 ›][잔향이 던전 ›][상점 ›]**. 잠긴 곳 = α0.55 + 자물쇠, 누르면 여는 조건 토스트(창 그대로). 열린 곳 = '‹ 가방으로' 칩을 넣고 그 탭 · 쪽으로.
- **재료 정보** (`ItemInfoPopup`): 아이콘 · 등급 · 보유 수 · 설명 · **획득처 목록** — 갈 수 있는 곳 먼저(콘텐츠 순서, 스테이지는 맨 뒤) → 잠긴 곳(열리는 순서). 줄 = 종류 태그 · 이름 · [가기 ›] / 잠김 줄 '스테이지 2-9 클리어 시' + [잠김](누르면 이유 토스트).
- '가기 ›'는 누를 때 다시 확인 — 잠겼으면 토스트만, 스테이지는 '전투(스테이지)에서 가끔…' 토스트만, 갈 수 있으면 돌아가기 칩 + 이동.
- **부족 팝업 얻는 곳** (`ShortfallSourceRow`): 같은 모양 · 받지 않은 별조각 우편 줄은 금 테 강조.

## 2. 기획 방향 (To-be) — DD

### 2.1 화면 흐름
```
≡ 메뉴 [가방] ─→ B-1 가방
  ├─ 재료 칸 탭 ─→ B-2 재료 정보
  │    ├─ 얻는 곳 [가기 ›] ─→ 그 탭 · 쪽 (시트 머리 '‹ 가방으로') ─→ 칩 탭 → B-1 → B-2 다시
  │    ├─ 잠긴 줄 [잠김] ─→ 토스트 '스테이지 2-9 클리어 시 열려요' (팝업 그대로)
  │    └─ (P1) 쓰는 곳 [보기 ›] ─→ 진화 레시피 / 시설 상세
  └─ 아래 바로 가기 [의뢰 ›][던전 ›][상점 ›]
```

### 2.2 B-1 가방 — 요소별 기능
1. **재료 격자**: 등급 테두리 · 아이콘 · 수량(없으면 흐린 0). 지금 순서 유지.
2. **재료 모으는 곳 칸**: 문구 '재료는 **의뢰 · 던전 · 상점**에서 모을 수 있어요' · 바로 가기 **[의뢰 ›][던전 ›][상점 ›]** (D-54 #5 쪽 이름 = 의뢰). 잠김 규칙 그대로.
3. (P1) 머리에 **'곧 필요한 재료'** 알약 1개: 진화 제작 · 시설 강화 중 가장 가까운 목표 1개가 모자라게 하는 재료 → 누르면 그 재료 B-2.

### 2.3 B-2 재료 정보 — 요소별 기능
1. 아이콘 · 이름 · 등급 · 보유 수 · 설명 (지금).
2. **얻는 곳** 목록 (지금 규칙 그대로). 줄 이름도 D-54 · D-55에 맞춤: 원정 구역 → '의뢰 · {구역}' · 던전 → '던전 · {N}층부터'.
3. **쓰는 곳** 목록 🆕 (P1): '진화 · {형태}' / '한계 돌파 · Lv.{N}' / '시설 · 기억등 Lv.{N}' — [보기 ›]. 지금은 레시피 쪽에서만 재료 → 얻는 곳 방향만 있음.
