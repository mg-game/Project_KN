## 0. 개요
- 목적: **보내 두고 잊었다가 받으러 오는 곳**(의뢰) + **하루 3장 도전하는 곳**(던전) + (P1) **누구를 구하러 갈지 고르는 곳**(유실표 장부).
- M1 화면: **E-1 원정 탭(쪽 2개)** · **E-2 구역 카드** · **E-3 원정 준비 팝업** · **E-4 던전 카드 · 소탕 팝업**.

## 1. 현재 구현 (요약)
- **원정 탭** (`ExpeditionPanel`): 머리 한 줄 = 쪽 고르기 **[원정][잔향이 던전]** + 가운데 칩(원정 '진행 중 1/3' / 던전 '입장권 1/2') + 오른쪽 [모두 받기](받을 원정 있을 때만) 또는 [모두 다시 보내기](받을 것 없고 다시 보낼 구역 있을 때, 2-1 개방, 처음 쓰기 전 NEW).
  - 처음 쪽 = 원정 · 입장권이 남았는데 원정 자리가 모두 진행 중이면 던전. 앱 켜진 동안 고른 쪽 기억. 던전 쪽에선 던전 음악.
  - 쪽 배지: 원정 = 받을 수 · 던전 = 입장권 남으면 점. 던전 잠김(1-10 전) = 흐림 + 자물쇠 + '1-10' 알약, 누르면 토스트.
- **구역 카드** (`ExpeditionZoneCardView`): 잠김(그림 흐림 + '스테이지 2-9 클리어 시 / 열려요') / 보내기 / 진행 중(멤버 · 남은 시간 · 진행 바 · '길게' '밤새' 칩) / 완료(빛나는 [받기]). 지난 친구가 모두 갈 수 있으면 버튼 **[다시 보내기]**(바로 출발) + 아래 '친구 바꾸기 ›'.
- **원정 준비** (`ExpeditionSetupPopup`): 친구 칸 격자(초상화 · 이름 · 레벨 · 고른 순서 · 편성 중이면 '지킴이' / '잔향이' 알약 · 다른 원정 중이면 흐림 + 사유) · 다녀올 시간 3칸('30분 · 보상 ×1' / '1시간 30분 · ×2.8' / '3시간 · ×5.4') · 예상 획득 · [자동 선택] · [출발].
  - 열 때: 지난 친구 그대로 채움, 안 되면 조용히 자동 선택 (열자마자 출발 가능).
  - **자동 선택 순서: 원정에 안 나감 → 진화 조건 '원정 N회'가 많이 남음 → 전투력 → ID.** 편성 중인 친구도 고름 (지금은 원정 중에도 싸우니까, M05).
- **던전 카드** (`DungeonCardView`): 다음 층 · 입장권 '1/3' + '충전까지 7:38:48' · 권장 줄 '권장 12,345 · 잔향이 9,876' + 평가 칩(여유 / 도전 / 어려움 — 잔향이 덱 전투력 기준) · [도전] → 결과 보상 팝업(실패해도 얻은 것 있으면 날림) · [소탕] → 소탕 팝업 · 아래 '층별 보상' 다음 세 층(달빛 조각은 확률 표시).
- **소탕 팝업** (`DungeonSweepPopup`): 돌파한 층 고르기 · (5층 돌파 뒤) '[-] ×n장 [+]' → '{n}장 소탕' → '{층}층 {n}번 소탕 완료 / 잔향이들이 익숙한 길을 {n}번 다녀왔어요.'

## 2. 기획 방향 (To-be) — DD

### 2.1 화면 흐름 (D-54 반영)
```
하단 탭 [원정] ─→ E-1 (쪽 기본: 받을 것이 있는 쪽 > (P1) 찾아가기 켜진 유실표 > 의뢰)
  ├─ (P1) 쪽 [유실표 장부] ─→ 장별 유실표 카드 [찾아가기] → 구조 전투 (SYS_Rescue)
  ├─ 쪽 [의뢰] ─→ E-2 구역 카드
  │    ├─ [보내기] ─→ E-3 준비 → [출발] ─→ (편성 중 친구 포함?) 확인 "편성에서 빠져요" ─→ 출발
  │    │                       └─ 출발 가드 걸림 → 버튼 회색 + "1명만 보내면 출발할 수 있어요"
  │    ├─ [다시 보내기] ─→ 가드 확인 → 바로 출발 / 걸리면 E-3 열기
  │    └─ [받기] ─→ 보상 팝업 → (편성 칸 비어 있으면) 원래 자리로 복귀 토스트
  └─ 쪽 [던전] ─→ E-4 "기억의 안쪽" 카드 [도전] / [소탕]
머리 오른쪽: [모두 받기] / [모두 다시 보내기]
```

### 2.2 E-1 원정 탭 — 요소별 기능
1. **쪽 고르기**: M1 **[의뢰 | 던전]** (D-54 #2 · #5) · P1 **[유실표 장부 | 의뢰 | 던전]**.
2. **가운데 칩**: 의뢰 '진행 중 1/3' · 던전 '입장권 1/3' (지금).
3. **[모두 받기]**: 그대로. 받은 뒤 복귀한 계보가 있으면 토스트 '{n}명이 원래 자리로 돌아왔어요'.
4. **[모두 다시 보내기]**: 출발 가드를 구역마다 차례로 확인 → 걸리는 구역은 **건너뛰고** 토스트 '{n}곳을 다시 보냈어요 · {m}곳은 싸울 친구가 모자라 남겨 뒀어요' (§3 #2).
5. **쪽 배지**: 의뢰 = 받을 수 · 던전 = 입장권 점 · (P1) 유실표 = 찾아가기 가능 점.

### 2.3 E-2 구역 카드 — 상태 · 문구
| 상태 | 표시 | 버튼 |
|---|---|---|

| 보내기 | 구역 이름(D-54 #3 1장 이름) · 시간 · 보상 칩 | [보내기] / [다시 보내기] + '친구 바꾸기 ›' |
| 진행 중 | 멤버 초상 · 남은 시간 · 진행 바 · '길게' / '밤새' 칩 · **멤버 초상 위 '편성 잠김' 자물쇠 16** 🆕 | 없음 |
| 완료 | 빛남 | [받기] |

### 2.4 E-3 원정 준비 팝업 — 요소별 기능 (D-54 #1 적용)
1. **친구 칸**: 편성 중이면 '지킴이' / '잔향이' 알약 (지금). 고르면 알약 옆에 **'빠져요'** 작은 글 (보내면 편성에서 빠진다는 것을 미리).
2. **자동 선택 순서 (바뀜)**: **원정에 안 나감 → 편성에 없음 → '원정 N회' 많이 남음 → 전투력 → ID** (§3 #1). 편성 안 된 친구만으로 자리가 차면 편성은 건드리지 않음.
3. **출발 가드 줄** 🆕: 고른 뒤 남는 편성 가능 계보 < 3 이면 [출발] 회색 + 줄 '싸울 친구가 너무 적어요 · {k}명만 보내면 출발할 수 있어요'.
4. **출발 확인**: 편성 중 친구가 있으면 한 번 '편성에서 빠져요 (지킴이 짝짝이 · 잔향이 레이니)' → [빈 칸 자동 채우고 출발] / [그냥 출발] / [취소].
5. 다녀올 시간 3칸 · 예상 획득 — 지금 그대로.

### 2.5 E-4 던전 카드 (D-55 반영)
1. 카드 제목 **'기억의 안쪽'** · 쪽 이름은 '던전' (D-55 #2).
2. 권장 줄 · 평가 칩 · 입장권 · 충전 시계 — 지금 그대로.
3. 층별 보상: 달빛 조각 확률은 **상한 40%** 반영 표시 (D-55 #5).
4. [도전] 결과: M1 = 결과 보상 팝업 (지금) · P1 = 0.8초 '잔향이들이 기억의 안쪽으로…' 짧은 진행 연출 후 팝업 (§3 #3).
5. 원정 중 계보가 잔향이 덱에 있으면 카드 아래 '의뢰 중인 잔향이 {n}명은 빠져요' 줄 + [덱 바꾸기 ›] (D-54 · D-55 #6).

## 6. 확장성 · 유지보수
- 쪽 추가(유실표)는 지금 쪽 고르기 컴포넌트에 1칸 — 배지 · 기억 · 잠김 규칙 재사용.
- 출발 가드 판단은 **시스템 한 곳**(`ExpeditionSystem`)에 두고 준비 팝업 · 다시 보내기 · 모두 다시 보내기가 같은 함수를 부르게 (화면마다 따로 계산하면 어긋남).

> 💡 **조합 제안 (검토용)** — 의뢰 × 잔향이 던전
> 의뢰에서 돌아온 계보는 그날 **던전에서 잔향 수급 +10% ("다녀온 기억이 또렷해서")**. 보내기와 던전이 서로 경쟁(편성 잠금)만 하지 않고 순서가 생김: 아침에 보내고 → 받고 → 던전.
