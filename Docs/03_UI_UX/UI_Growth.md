- M1 화면 3개: **강화 탭** (메인 탭) · **캐릭터 상세의 성장 칸** · **레벨업 직후 피드백**.

## 1. 현재 구현 (요약)
- **강화 탭** (`GrowthPanel`): 위 = 수선점 강화 (x1 길게 누르기 · x10 · 최대 +N → 초당 단추 · 수선점 내구), 아래 = 보유 계보 레벨업 카드 목록.
- **계보 카드** (`GrowthLineageCardView`): 초상 + Lv · 이름 · 별 · **편성 중이면 팀 전투력 +N**, 편성 밖이면 "미편성" · 레벨업 버튼(길게 = 연속, 0.45초) · 잠김 = "1-1" 알약.
- 카드 정렬: 튜토리얼이 가리키는 계보 → 편성 칸 순 → 편성 밖 등급 높은 순 → ID. **레벨업으로 자리가 안 바뀜** (길게 누르는 손가락 밑 카드 유지).
- **캐릭터 상세** (`CharacterDetailPopup`): 계보 레벨업(단추) · 호감도 · 기억편 · 계보 공명(+5% → +10%, '준비 완료' 금 덮개) + 탭 [진화 · 스킬/시너지 · 의상 · 정보].
- 비용 버튼 3상태: 넉넉함 / 부족함(누르면 흔들기 + 단추 부족 토스트 1.5초에 1번) / 최대 레벨.
- 레벨업 피드백: `LevelUpFanfareView` (짧은 칩 · 효과음), 전투력 변화는 `PowerSystem.Changed`.

## 2. 기획 방향 (To-be) — DD

### 2.1 화면 흐름
```
[메인 탭바 · 강화] ─→ (GR-1) 강화 탭
   ├─ 수선점 카드 [x1 · x10 · 최대 +N] ─→ 초당 단추 · 내구 갱신 + 10레벨마다 별조각 우편
   ├─ 계보 카드 [레벨업] (탭 / 길게) ─→ (GR-3) 피드백 칩
   └─ 계보 카드 초상 탭 ─→ (GR-2) 캐릭터 상세 · 성장 칸
(GR-2) 성장 칸
   ├─ [레벨업] (x1 · 길게 · x10) ─→ 능력치 전→후 갱신 + (GR-3)
   └─ [공명] (기억 조각) ─→ 확인 창 ─→ 공명 효과 전→후 + (GR-3)
[강해지기 줄의 가기] ─→ GR-1 해당 카드 금빛 테 + 손가락 (현재 구현)
[전투 결과 · 실패] ─→ "강해지기" ─→ GR-1
```

### 2.2 GR-1 강화 탭 — 요소
1. **단추 잔액** (상단 고정) : 보유 단추 + 초당 단추 `+12.4/초`. 방치 지급으로 숫자가 계속 오른다
2. **수선점 카드**
   - 표시: 수선점 아이콘 · `Lv.N` · 초당 단추 `전 → 후` · 수선점 내구 `전 → 후`
   - `[x1]` 탭 = 1레벨 · 길게 = 연속 / `[x10]` / `[최대 +N]` (2레벨 이상 살 수 있을 때만 켜짐)
   - 10레벨마다 "별조각 50" 보상 예고 `Lv.20까지 3` (현재 우편 규칙의 화면 표시) 🆕
3. **계보 카드 목록** (2열 그리드)
   - 초상 · `Lv.N` · 이름 · 역할 아이콘(🗡 · 🛡 · ✚, D-39 S4) · **편성 위치 배지**(지킴이 방위 / 잔향이 덱) 🆕
   - 증가 표시: 편성 중 = `전투력 +N` (초록), 편성 밖 = "미편성" (회색)
   - `[레벨업 비용]` : 탭 = +1 · 길게 = 연속 · 부족 = 비용 빨강 + 흔들기 + 토스트
   - 공명 가능 = 카드 오른쪽 위 **"공명" 금 점** 🆕 (기억 조각 충분할 때만)
   - 정렬 = 현재 구현 그대로 (레벨업으로 자리 안 바뀜)
4. **추천 줄** (목록 위 1줄) 🆕 : `강해지기` 1순위 줄을 그대로 보여 줌 — "짝짝이 Lv.12 → 13 · 전투력 +84 (가장 효율)" · 탭 = 그 카드로 스크롤 + 금빛 테

### 2.3 GR-2 캐릭터 상세 · 성장 칸
1. **레벨 줄** : `Lv.12 → Lv.13` · 비용 · `[레벨업]` (탭 / 길게) · `[x10]`
2. **능력치 미리보기** 🆕 : 공격력 · 체력 `전 → 후 (+증가, 초록)` — 지킴이 · 잔향이 둘 다 적용
3. **안내 1줄** : "레벨은 지킴이 · 잔향이에 함께 적용돼요"
4. **공명 줄** : `공명 2 → 3` · 기억 조각 `보유 / 필요` (모자라면 빨강) · `[공명]` → 확인 창 (기억 조각은 다시 얻기 어려워서 확인)
5. **공명 효과 미리보기** 🆕 (D-29 #4)
   - 공용 : 공격력 · 체력 `+10% → +15%`
   - 잔향이 전용 : 소환 비용 `5 → 4` (공명 3 · 6 · 9에서 −1) · 지속 시간 `14 → 14.5초` (레벨당 +0.5초) · 동시 출현 🔒 (P1)
6. **기억 조각 얻는 곳** 줄 : 중복 소환 · (P1) 구조 · 원정 → 탭 = 해당 화면

### 2.4 GR-3 레벨업 직후 피드백
```
레벨업 성공
  → 카드/줄: Lv 숫자 펀치 + 반짝 0.45초
  → IF 편성 중 → "팀 전투력 +N" 칩 (화면 위 중앙, 1.2초, 연속 레벨업이면 합산 갱신)
  → IF 다음 스테이지 평가가 바뀜 (어려움 → 도전 → 여유) → "다음 스테이지: 도전 → 여유" 칩 추가 🆕
  → 10레벨 고비 → 기존 고비 칩 (현재 구현)
공명 성공
  → 공명 칩 + 효과 전→후 한 줄 ("소환 비용 5 → 4")
```
- 별도 "전투 반영 화면"(와이어프레임 05)은 만들지 않는다 — 방치형은 레벨업이 자주라 화면 전환이 피로 (§3 #4).

### 2.5 상태 · 버튼 규칙
```
[레벨업 버튼]
IF 계보 레벨업 잠김 (1-1 클리어 전)        → 버튼 보임 · 쓸 수 없음 · "1-1" 알약 · 누르면 잠금 토스트
ELSE IF 레벨 = 100                         → "최대 레벨" (쓸 수 없음)
ELSE IF 단추 < 비용                        → 비용 빨강 · 누르면 흔들기 + "단추가 N 부족해요" (1.5초에 1번)
ELSE                                       → 성공 → GR-3
[길게 누르기]  0.45초 뒤부터 반복 · 반복 중 토스트 없음 · 막히면 1번만 · 목록 스크롤하면 멈춤
[x10]          살 수 있는 만큼으로 자동 축소 (0이면 비활성) — 표시 "x10 (7)"
[공명 버튼]
IF 공명 = 10 → "최대" · ELSE IF 기억 조각 < 비용 → 빨강 · ELSE → 확인 창 → 성공
```
