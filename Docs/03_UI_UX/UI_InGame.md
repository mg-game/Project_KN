# 0. 문서 개요

UI 팀, 게임기획, 클라이언트, 서버, 아트 간 공통 기준 정의.

## 0.1 작성 목적

본 문서는 Lost & Lovely의 인게임 UI 구조, 주요 화면, 정보 우선순위, 인터랙션, 예외 상태를 정의한다. 특히 수선점 중심의 홈과 전투, 지킴이·잔향이 편성 및 소환, 캐릭터 수선·진화·외형변경이 하나의 플레이 루프로 연결되도록 설계하는 것을 목적으로 한다.

## 0.2 기준 자료와 전제

- 게임명은 Lost & Lovely로 고정한다.
- 장르는 캐릭터 수집형 방치 디펜스 RPG(360° 수성전)이며, 수선점이 홈·전투 코어·이동 수단·내러티브 중심을 동시에 담당한다.
- 세로형 모바일 9:16을 1차 기준으로 삼는다. 태블릿/폴더블 대응은 후속 스케일 규칙으로 확장한다.
- 본 문서는 기능과 UX 구조를 정의하는 v0.1이다. 픽셀 단위 GUI 아트, 최종 아이콘, 실제 수치 밸런스는 후속 문서에서 확정한다.
- 상점 상품 구성, 장비 시스템 등 현재 자료에 없는 항목은 임시 구조로만 정의하며 확정값으로 취급하지 않는다. (소환 재화 명칭은 **잔향**으로 확정 — 컨셉 부록 A 용어집 정본)

## 0.3 핵심 UX 목표

| 목표 | 사용자가 느껴야 하는 것 | UI 설계 원칙 |
|---|---|---|
| 집의 일체감 | 홈에서 키우는 수선점이 전투에서 지키는 바로 그 집이다 | 홈과 전투에서 수선점 외형·상태·성장 정보를 동일하게 노출 |
| 최애의 선명함 | 지킴이는 내가 직접 곁에 두고 키운 본체다 | 큰 크기, 불투명 표현, 전용 스킬, 방위 색으로 강조 |
| 물량의 손맛 | 잔향이는 계속 불러내는 귀여운 전투 분신이다 | 작고 반투명하며 발광, 탭 소환과 방향 드래그를 즉시 제공 |
| 수선의 놀이성 | 고치는 과정이 수치 강화가 아니라 변화의 기대감이다 | 수선 전/후 비교, 재료 선택, 실루엣·행동·연출 변화 강조 |
| 서사의 연결 | 외형변경에는 캐릭터가 그렇게 변한 이유가 있다 | 외형 선택 화면에서 이름·이유·짧은 이야기·미리보기 함께 제공 |

# 2. UI 디자인 원칙 및 공통 규격

기괴하게 사랑스럽고, 작은 화면에서도 즉시 읽히는 2D 토이 판타지.

## 2.1 시각 방향

- 기본 팔레트: 짙은 남보라/인디고 배경, 크림색 제목, 금색 포인트, 파스텔 보라·핑크·블루 보조색.
- 캐릭터와 수선점은 배경보다 채도와 명도를 한 단계 높여 전투 중 우선 인식되게 한다.
- UI 패널은 장식 프레임을 사용하되 정보 영역을 침범하지 않는다. 테두리는 중간 굵기, 모서리는 둥글게 처리한다.
- 중요한 기능은 아이콘만 두지 않고 짧은 텍스트 라벨을 병기한다.
- 컨셉 이미지를 UI에 삽입할 때는 원본 비율을 유지해 축소하며, 핵심 피사체를 자르지 않는다.

## 2.2 정보 계층

| 계층 | 용도 | 표현 |
|---|---|---|
| 1차 | 현재 목표, 수선점 위험, 보스 상태, 배치 가능 여부 | 가장 큰 숫자/바/버튼, 고대비 |
| 2차 | 캐릭터 상태, 잔향 보유량, 재료, 진행도 | 중간 크기, 아이콘+수치 |
| 3차 | 설명, 서사, 상세 효과, 획득처 | 탭/툴팁/상세 패널로 단계적 노출 |

## 2.3 공통 상태 표현

| 상태 | 표현 규칙 | 예시 문구 |
|---|---|---|
| 활성 | 고유색 프레임, 정상 채도, 터치 반응 | 배치 가능 |
| 비활성 | 채도 30%, 잠금/부재 아이콘, 원인 텍스트 | 수선 의뢰 중 |
| 선택 | 금색 또는 밝은 보라 외곽선, 1회 펄스 | 현재 선택 |
| 위험 | 붉은 테두리와 방향 화살표, 짧은 진동 | 북쪽 방어선 위험 |
| 완료 | 체크·별빛 파티클, 자동 접힘 | 기억등 복구 완료 |
| 획득 가능 | 작은 점/반짝임 배지, 최초 1회 강조 | 보상 수령 가능 |

**텍스트 톤** — 설명은 친절하되 세계관 어휘를 유지한다. 시스템 오류처럼 차갑게 말하지 않고, 캐릭터와 수선점의 상태로 번역한다. 예: "편성 불가"보다 "지금은 직접 나가 있어요".

# 4. 공통 HUD와 내비게이션

어느 화면에서도 현재 상태와 돌아갈 곳을 잃지 않게 한다.

## 4.1 상단 공통 영역

- 좌측: 플레이어 프로필, 수선사 레벨, 현재 경험치.
- 중앙 또는 우측: 주요 재화 2~3종. 재화가 많을 경우 가방 상세로 연결한다.
- 최우측: 알림, 우편, 설정. 신규 알림은 작은 점으로만 표시해 화면을 과도하게 덮지 않는다.
- 뒤로가기 버튼은 좌측 상단 고정. 홈 탭에서는 표시하지 않는다.

## 4.2 하단 내비게이션

- 5개 탭을 고정하며 중앙의 수선점 탭을 시각적으로 가장 크게 배치한다.
- 전투/연출/팝업에서는 하단 내비게이션을 숨긴다.
- 탭 전환 시 현재 화면의 미저장 변경이 있으면 저장/취소 확인 팝업을 노출한다.

## 4.3 공통 팝업

| 종류 | 사용 조건 | 버튼 규칙 |
|---|---|---|
| 확인 | 정보 전달만 필요 | 확인 1개 |
| 선택 | 진행/취소가 모두 유효 | 좌 취소, 우 확인 |
| 위험 확인 | 재화 소모·퇴각·초기화 | 취소 기본 포커스, 위험 버튼 붉은색 |
| 보상 | 획득 결과 | 화면 탭 또는 확인 |
| 튜토리얼 | 첫 기능 안내 | 지정 영역 외 입력 차단 |

- **dim 클릭 닫기 (공통 규칙)** — 모든 팝업·모달은 X(닫기) 버튼뿐 아니라 바깥쪽 어두운 영역(dim) 클릭으로도 닫힌다. 예외: 위험 확인 팝업과 튜토리얼 팝업은 dim 클릭을 무시한다 (명시적 선택 필요).

# 5. 수선점 홈

메뉴가 아니라 캐릭터들이 실제로 사는 날아다니는 집.

## HM-001 수선점 홈

| 항목 | 정의 |
|---|---|
| 목적 | 게임의 기본 허브. 주민 생활, 수선점 성장, 콘텐츠 진입, 현재 챕터 분위기를 한 화면에 통합한다 |
| 진입 | 로그인 완료, 전투 종료, 하단 수선점 탭 |
| 이탈 | 하단 탭 또는 콘텐츠 버튼 |
| 우선순위 | P0 |

**화면 구성**

- 중앙: 현재 성장 단계의 수선점 전경. 전투에서 사용되는 코어와 동일한 외형을 사용한다.
- 주민 캐릭터 3~6명이 생활 행동(시그니처 행동 포함, 컨셉 §8.2)을 수행한다. 터치 시 짧은 반응·대사·친밀도 요소를 노출한다.
- 시설 핫스팟: 수선 작업대, 기억 베틀, 기억등, 주민 방, 비행 준비실 등. 기능 잠금 시 실루엣과 해금 조건 표시.
- 상단: 프로필과 재화. 우측: 미션/우편/이벤트.
- 하단: 상점·캐릭터·수선점·가방·모험.

**주요 인터랙션**

- 빈 공간 드래그로 카메라를 제한적으로 이동한다.
- 주민 터치 → 말풍선 → 상세 보기 또는 작은 생활 이벤트.
- 모험 버튼 → 현재 유실표와 다음 목적지를 강조한 AD-001로 이동.
- 수선점이 비행 가능한 상태면 출동 버튼에 은은한 날개/천 펼침 애니메이션을 표시.

**상태 및 예외**

- 신규 유실자 합류: 홈 진입 시 주민들이 맞이하는 짧은 연출 후 방 배정 안내.
- 시설 성장 완료: 해당 시설만 강조하고 전투 능력 변화 요약 제공.
- 수선점 손상: 외벽 패치와 불빛 감소로 상태 표현. 기능은 막지 않되 복구 버튼 강조.
- 오프라인 보상: 홈 진입 직후 1회 팝업.
- 기억 베틀: 에피소드 1개 분량의 기억 조각이 모이면 베틀에 불이 들어오고 해당 캐릭터가 베틀 곁을 서성인다 (강제 팝업 없음 — 컨셉 §5.6 서사 소비 동선).

> **기획 메모** — 수선점은 배경 오브젝트가 아니라 플레이어의 집이다. 화면의 중심 면적을 충분히 차지하고, 캐릭터가 그 안에서 살고 있다는 감정을 전달한다.

## HM-002 시설 상세/성장

| 항목 | 정의 |
|---|---|
| 목적 | 수선점의 방과 시설을 성장시키고, 홈 외형 및 전투 효과를 확인한다 |
| 진입 | HM-001 시설 핫스팟 |
| 이탈 | 닫기 또는 성장 완료 |
| 우선순위 | P1 |

**화면 구성** — 시설 일러스트/레벨 · 현재 효과와 다음 레벨 효과 · 필요 재료 · 성장 후 외형 미리보기 · 연결된 콘텐츠 바로가기

**주요 인터랙션** — 재료 아이콘 탭 → 획득처 · 성장 버튼 → 확인 → 연출 · 외형 비교 슬라이더

# 7. 전투 편성: 지킴이와 잔향이

같은 캐릭터를 어느 자리에 세울 것인가가 매 전투의 선택.

## FM-001 전투 편성

| 항목 | 정의 |
|---|---|
| 목적 | 하나의 캐릭터 목록에서 최대 5명의 지킴이와 잔향이 덱을 구성하고 빈 방위를 확인한다 |
| 진입 | AD-002 편성 수정/전투 시작, 캐릭터 메뉴 편성 바로가기 |
| 이탈 | 저장 후 AD-002 또는 전투 진입 |
| 우선순위 | P0 |

**화면 구성**

- 중앙: 수선점과 방위 링. 지킴이 슬롯 최대 5개 (8방위 스냅 — 시스템 §6.1).
- 지킴이를 배치하면 담당 요격 범위를 부채꼴로 표시한다 (5인으로 360°가 덮이지 않음을 시각화 — "어디를 비울 것인가"가 배치 판단의 본질).
- 하단: 잔향이 덱 슬롯. 각 카드에 소환 비용과 역할 아이콘.
- 좌/우: 보유 캐릭터 목록, 필터, 정렬, 편성 프리셋.
- 상단: 현재 스테이지의 주요 적 방향과 위험도 (스폰 집중 + 지속 압박 섹터 마커).

**주요 인터랙션**

- 캐릭터 카드 드래그 → 방위 링에 놓으면 지킴이, 하단 덱에 놓으면 잔향이로 등록.
- 이미 반대 역할에 등록된 캐릭터를 선택하면 "지금은 직접 나가 있어요" 또는 "잔향을 준비 중이에요" 안내 후 이동 여부 확인.
- 지킴이 슬롯 간 드래그로 방위 변경. 부채꼴 프리뷰 즉시 갱신.
- 프리셋 저장/불러오기. 스테이지별 마지막 편성 자동 기억.
- 전투 시작 전 빈 방향이 있으면 약한 경고를 표시하되 진입은 허용 (최소 1인 배치로 입장 가능 — 시스템 §6.1).

**상태 및 예외**

- 동시 등록 차단: 동일 캐릭터는 지킴이와 잔향이로 동시에 사용 불가 (배타 원칙 — 시스템 §4.1, 컨셉 §6.3).
- 파견 중: 양쪽 모두 회색 처리, 부재 배지와 복귀 시간 표시.
- 미보유/체험 캐릭터: 별도 탭으로 분리.
- 편성 인원 초과: 가장 최근 드롭을 취소하고 슬롯을 흔들어 피드백.
- 잔향이 미해금: 합류 단계 '피난자'인 캐릭터는 잔향이 덱 등록 불가 — "아직 형태가 흔들려요" 안내 (컨셉 §5.3, 시스템 §14-8).

> **기획 메모** — 지킴이는 애정·전략·서사를, 잔향이는 물량·손맛·귀여움을 담당한다. 편성 UI가 이 차이를 설명 없이도 읽히게 해야 한다.

## 7.1 지킴이/잔향이 카드 표현

| 항목 | 지킴이 | 잔향이 |
|---|---|---|
| 크기 | 큰 초상/전신, 불투명 | 작은 SD, 반투명 |
| 프레임 | 방위 색 + 방패 아이콘 | 발광 보라 + 잔향 아이콘 |
| 정보 | 전용 스킬, 복귀 시간 | 소환 비용, 예상 유지 시간 |
| 수량 | 최대 5명 고정 | 덱 등록 후 전투 중 반복 소환 |
| 외형 | 현재 진화/외형변경 반영 | 현재 외형의 단순화 파생형 |
| 소멸 | 쓰러져도 잠시 후 복귀 | 빛으로 풀려 본체에게 귀환 |

# 8. 전투 화면

수선점 중앙 코어를 지키는 한 화면 360° 수성전.

## BT-001 전투

| 항목 | 정의 |
|---|---|
| 목적 | 수선점을 중심으로 사방에서 접근하는 적을 지킴이와 잔향이로 방어한다 |
| 진입 | AD-002 전투 시작 |
| 이탈 | RS-001 승리, RS-002 실패, BT-002 일시정지 |
| 우선순위 | P0 |

**화면 구성**

- 중앙: 수선점 코어. 캐릭터보다 약 2배 크기. 외형과 손상 상태가 명확히 보인다.
- 수선점 주위: 빛의 결계 링. 안쪽은 아군 영역, 바깥은 적 접근 영역.
- 지킴이: 각 담당 방향에 배치되어 **담당 부채꼴 범위 안에서 자율 이동하며 교전하고 스킬을 사용한다** (시스템 §6.2 요격 규칙). 크고 불투명하며 발밑 방위 색 표시 (초상화 프레임 색과 동기화 — 시스템 §12.1).
- 잔향이: 작고 반투명·발광. 다수 배치되며 이동/귀환이 빈번하다.
- 상단: 스테이지명, 타이머(상시 노출 — 잔여 20% 진입 시 경고 톤), 웨이브 진행(Wave n/N), 보스 HP(쇄도 시 "남은 적 N" 카운터로 전환), 배속, 일시정지 (시스템 §10.1·§12.1).
- 하단(엄지 존): 잔향 보유량 + 보유 상한 게이지(상한 수치 미확정), 잔향이 덱 카드(소환 비용 뱃지), 수선등 밝히기 버튼, 재집결 버튼, 자동 소환 ON/OFF 토글(규격은 시스템 §12.3 자동전투 미결과 연동).
- 수선점은 전장의 **정중앙에 고정**되며 내구(Core HP)를 가진다. 내구/보호 한계는 중앙 하단에 노출하여 캐릭터 카드와 혼동되지 않게 한다. **내구 0 = 즉시 전투 종료(긴급 귀환, RS-002)** — 시스템 §10 STAGE_FAIL ①.
- 웨이브 예고: 결계 링 가장자리 방향 마커 (시스템 §12.1).

**주요 인터랙션**

- 잔향이 카드 탭(≤0.2s) → 가장 위험한 방향으로 자동 소환·배치 (위협도 최고 섹터 — 시스템 §5.2).
- 카드 홀드(>0.2s) 후 방향 드래그 → 부채꼴 프리뷰 → 놓으면 지정 방향 소환. 드래그 감도는 방향 벡터 기준.
- 드래그 중 원위치 또는 취소 영역으로 되돌리면 잔향 소모 없음.
- 지킴이 전용 스킬은 캐릭터 주변 버튼 또는 좌측 지원 UI로 노출. 자동/수동 옵션 지원. (스킬 버튼 위치는 하단 이동안과 A/B 대상 — 시스템 §12.1)
- 수선등 밝히기 → 전투 중 잔향을 투자해 수급 레벨을 올린다 (5단계, 스테이지 리셋 — 시스템 §7.1). 현재 레벨·다음 비용·사용 가능 상태를 명확히 표시. (긴급 방어 등 추가 액티브 효과 부여 여부는 §18 미확정)
- 재집결 → 방위 링 오버레이 → 드래그 재배치 → 확정 시 지킴이 전원 동시 이동. 쿨다운제(초기 60s), 이동 중 교전 불가 (시스템 §6.3).

**상태 및 예외**

- 잔향 부족: 카드를 어둡게 하고 필요한 수치를 붉게 표시.
- 위험 방향: 화면 가장자리와 링에 방향 경고. 지나친 화면 흔들림은 금지.
- 지킴이 쓰러짐: 사망 연출 없이 무릎/휴식 후 복귀 게이지. 부재 중 담당 방위 공백 표시.
- 잔향이 종료: 쓰러지는 대신 빛으로 풀려 수선점 방향으로 귀환. 만료 3초 전 깜빡임 예고 (발밑 게이지 금지 — 시스템 §5.3).
- 소환 상한 도달: 소환 버튼 비활성 + 가장 먼저 흩어질 잔향이의 잔여 시간 표시 (시스템 §5.4).
- 수선점 보호 한계 도달: 전투를 즉시 암전하지 않고 귀환 종 → 캐릭터 회수 → 긴급 귀환 순서 연출.

# 12. 외형변경

우리 게임의 핵심: 수선과 재활용의 이유가 새로운 모습이 된다.

**진화와 외형변경의 구분** — 진화는 캐릭터의 장기 성장 단계이며 능력·실루엣·서사를 영구 확장한다. 외형변경은 특정 수선 재료와 이야기를 통해 얻는 대체 모습으로, 캐릭터의 새로운 역할과 감정 해석을 보여준다. 기본 밸런스는 동일하게 유지하는 것을 권장한다.

## SK-001 외형변경

| 항목 | 정의 |
|---|---|
| 목적 | 보유한 외형을 미리보고, 외형이 만들어진 이유와 이야기를 확인한 뒤 적용한다 |
| 진입 | CH-002 외형 탭, 이벤트 보상 획득 |
| 이탈 | CH-002 |
| 우선순위 | P1 |

**화면 구성**

- 중앙: 현재 외형의 큰 전신 미리보기. 회전 대신 2~3개 포즈 전환을 권장.
- 하단/좌측: 외형 썸네일 목록. 보유/미보유/이벤트 종료 상태 표시.
- 우측: 외형명, 한 줄 설명, 외형변경 이유, 짧은 이야기, 획득 방법.
- 지킴이 미리보기와 잔향이 SD 미리보기를 함께 제공.
- 적용 버튼과 현재 적용 표시. 홈/전투 미리보기 배경 전환.

**주요 인터랙션**

- 썸네일 선택 → 즉시 전신/잔향이/홈 반응 미리보기 갱신.
- 이야기 버튼 → 3~5문장 상세 서사.
- 미보유 외형 → 획득처/이벤트 바로가기.
- 적용 시 지킴이와 잔향이 외형에 동시에 반영하되 잔향이는 단순화·반투명 파생형으로 표시.

**상태 및 예외**

- 이벤트 종료: 미리보기는 가능, 획득처에는 "현재 획득 불가" 표시.
- 진화 단계 미달: 적용 가능 여부를 정책으로 확정. 권장안은 적용 가능하되 체형은 현재 진화 단계 유지.
- 외형 전용 스킬 효과가 있을 경우 전투 밸런스와 분리된 연출 효과로 우선 설계.

> **기획 메모** — 외형변경은 단순 코스튬 목록이 아니다. 우산을 우비·천막·낙하산·배·온실·날개·드레스로 재활용한 이유처럼, 원물의 기능이 새 역할로 바뀐 이야기를 함께 판매한다.

# 16. 튜토리얼·알림·접근성

처음에는 쉽게, 오래 보면 깊게.

## 16.1 초반 5분 UI 온보딩

1. 수선점에 불을 밝힌다: 홈의 중앙 코어와 기본 탭을 소개한다.
2. 첫 방어전: 지킴이 1명을 자동 배치하고 수선점 보호 목표를 익힌다.
3. 첫 잔향이 소환: 카드 탭으로 자동 방향 배치 후, 두 번째 소환에서 홀드·드래그를 안내한다 (학습 계단 — 시스템 §5.2).
4. 긴급 귀환이 아닌 첫 승리: 보상과 임시 수선을 연결한다.
5. 새 유실자 합류: 피난자 상태와 캐릭터 상세를 소개한다.
6. 수선 1회: 수치 성장과 외형 변화의 기대를 보여준다.
7. 다음 유실표: 모험 지도로 이동하며 반복 루프를 완성한다.

## 16.2 알림 우선순위와 레드닷

| 우선 | 예시 | 표현 |
|---|---|---|
| 긴급 | 수선점 위험, 전투 핵심 조작 | 화면 중앙/방향 경고 + 진동 |
| 중요 | 성장 가능, 유실표 도착, 시설 완료 | 홈 아이콘 배지 + 짧은 토스트 |
| 일반 | 미션 보상, 우편 | 점 배지 |
| 정보 | 도움말, 획득처 | 툴팁/상세 |

**레드닷 규칙**

- 발생 조건: 수령 가능한 보상 존재(미션·우편), 신규 획득(캐릭터·외형), 성장 가능(재료 충족), 유실표 도착, 기억 베틀 에피소드 준비 완료.
- 표시 위치: 하단 탭 우상단 → 화면 내 해당 메뉴 → 대상 항목 순으로 체인 표시. 최하위 항목이 해소되면 상위로 전파 소멸.
- 소멸 조건: 해당 항목 확인/수령 시 즉시. 반복 발생형(일일 미션)은 리셋 시 재점등.
- 원칙: 레드닷은 "지금 하면 이득"에만 사용한다. 단순 신규 콘텐츠 홍보에 남용하지 않는다.

## 16.3 접근성

- 방위와 상태를 색만으로 구분하지 않는다. 아이콘, 패턴, 텍스트를 함께 사용한다.
- 전투 속도 배속 옵션(잠정안 0.5x/1x/1.5x/2x — 확정 아님, 시스템 §12.3 규격 확정 대기) 및 연출 축소 옵션을 제공한다.
- 진동 강도, 화면 흔들림, 번쩍임, 파티클 밀도 옵션을 제공한다.
- 작은 텍스트 확대 옵션과 자막 배경을 지원한다.
- 잔향이 반투명도는 배경과 겹쳐도 읽히도록 외곽선/발광 강도를 최소 기준 이상 유지한다.
- 튜토리얼은 다시 보기 가능하며, 조작 방식은 탭 중심/드래그 중심 중 선택할 수 있게 한다.
