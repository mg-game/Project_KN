## 0. 개요
- 목적: 하루 한 번 들러 **무료 선물 받고 · 모자란 재료 채우는** 곳 (방치형 일과). 이벤트 기간엔 이벤트 재화 쓰는 곳.
- M1 화면: **S-1 상점 탭(쪽 2개)** · **S-2 상품 카드 · 사기 흐름** · **S-3 오늘의 작은 선물**.

## 1. 현재 구현 (요약)
- **상점 탭** (`ShopPanel`, 1-8 개방): 제목 줄 없이 쪽 고르기 **[수선점 상점 | 별이 머문 밤 산책]**(이벤트 쪽 고르면 분홍 밑줄). 수선점 상점 쪽 오른쪽에 **'초기화까지 7:38:48'**(1초마다, 0이면 카드 다시 채움). 상품 4열 격자. 축제 이벤트 중이면 이벤트 쪽에 '축제 중' 알약.
- **오늘의 작은 선물** (`DailyGiftCardView`): 수선점 상점 쪽 맨 위 860×120 — 상자 · '하루에 한 번 무료로 받아요' · 보상 칩 · [받기](금). 받은 뒤 상자 열림 · '내일 새벽 5시에 새 선물이 와요' · 1시간 안이면 시계 · 마지막 3초 소리. 상점 탭 빨간 점.
- **상품 카드** (`ShopProductCardView`): 아이콘(재료 '×5' 배지 / 외형 초상화) · 이름 · '오늘 2/3 · 보유 15' · 가격 버튼. 품절 덮개.
- **사기** (`OnBuy`): 확인(`CanBuy`) → 모자라면 단추 = 부족 토스트 + 흔들기, 별조각 · 별빛 사탕 = 부족 팝업 · 하나짜리: **별조각 가격이면 쓰기 확인**(오늘 묻지 않기 없음), 단추면 바로 → 아이콘이 상단 바로 날아감 + 카드 튕김 + 토스트 + 0.15초 연타 막기 · 묶음 = 보상 팝업 '구매 완료' · **외형 = 쓰기 확인 → '의상 획득!' + '바로 입혀 보기'**(그 친구 상세 의상 탭).
- 하루 = 현지 05:00 날 키 (시계 되돌림에도 거꾸로 가지 않음).

## 2. 기획 방향 (To-be) — DD

### 2.1 화면 흐름
```
하단 탭 [상점] ─→ S-1 (마지막에 본 쪽, 처음 = 수선점 상점)
  ├─ 쪽 [수선점 상점] ─→ 선물 카드 [받기] → 보상 날아감
  │                    └─ 상품 카드 [가격] → (별조각이면 확인) → 날아감 + 토스트
  ├─ 쪽 [이벤트: {이벤트 이름}] (이벤트 기간에만 보임 · 끝나고 7일 유예 동안 '교환 마감 D-n')
  │    └─ 외형 [가격] → 확인 → '외형 획득!' → [바로 입혀 보기] → 유실자 상세 · 외형 탭
  └─ (P1 결제 뒤) 쪽 [별조각] ─→ 유료 상품 카드 [₩가격] → 스토어 결제 → 받기
```

### 2.2 S-1 상점 탭 — 요소별 기능
1. **쪽 고르기**: [수선점 상점 | 이벤트] — 이벤트 쪽 이름은 그 이벤트 이름 (지금 '별이 머문 밤 산책' 고정 → 이벤트 데이터에서 읽기). **이벤트가 없을 때는 쪽을 숨김** (§3 #2).
2. **초기화 알약**: '초기화까지 7:38:48' 그대로.
3. **선물 카드**: 그대로 (방치형 매일 들르기 장치).
4. **상품 격자**: 4열 그대로. 품절은 맨 뒤로 보내지 않음 (자리 고정이 "내일 또 사야지" 기억에 좋음).
5. **이벤트 재화 유예 표시** (D-30 #4): 이벤트가 끝나면 7일 동안 쪽 머리에 **'별빛 사탕 교환 마감 D-{n} · 남은 사탕은 단추로 바뀌어요'**.

### 2.3 결제 쪽 자리 (P1 — 결제 P0 끝난 뒤)
- 쪽 [별조각] 하나만 추가 (패키지 · 시즌 수첩 · 시작 주간은 이 쪽 안 카드로 — 탭을 늘리지 않음).
- 카드에 **유료 별조각 / 무료 별조각 구분 표기** (D-30 #3) — 상단 바 별조각 칩을 누르면 '유료 n · 무료 m' 말풍선.
- **확률이 섞인 유료 상품은 넣지 않는 것을 기본**으로 (확정 구성만). 확률 요소를 넣으면 그 카드에 확률 표시가 필요 — 한국 게임산업법 확률 공개 의무(2024-03-22 시행) 대상. 법률 자문 아님, 결제 붙이기 전 확인 (`SYS_Gacha` D-51과 같은 P0 묶음).
- 결제는 서버 영수증 확인 후 지급 (클라 단독 지급 금지 — 환불 회수 D-30 #3 전제).
