## 1. 레이아웃
> **D-44 (홈 #2)로 고침**: 전투 화면 = 홈(`UI_Home` §2.2)이라 하단 탭 바(80~100%)가 들어온다. 위 · 아래 메타 요소 배치는 `UI_Home`이 정본.
```
┌───────────────────────────────────────┐
│ (상단 바 — UI_Home ①)                    │  0~6%
│ ① 스테이지명 1-4 우산 보관소   ② ⏱ 2:14 │  6~11%
│ ③ Wave 2/4 ▮▮□□     ④ 보스/남은 적 바   │
│ (권장 전투력 알약)          ⑤ ⏸ ⑥ x2 ⑦ AUTO │
├───────────────────────────────────────┤
│⑧ 지킴이         ⑩ 웨이브 예고 마커(링 가장자리) │
│ 초상 5  ┌─────────────────────┐         │  전장 (11~64%)
│ (좌측)  │   ⑨ 원형 전장 · 결계 링     │  ⑮ 재집결 │  수선점 중앙 고정
│         │      🏠 수선점 (내구 ⑪)   │  (P1, 우하) │
│         └─────────────────────┘         │
├───────────────────────────────────────┤
│ (가이드 퀘스트)  ⑫ 잔향 37/99 +1.8  ⑭ [🏮 L2 → 20] │  64~71%
│ ⑬ [덱1][덱2][덱3][덱4][덱5][덱6]          │  71~80%
├───────────────────────────────────────┤
│ (하단 탭 바 7칸 — UI_Home ⑬)              │  80~100%
└───────────────────────────────────────┘
```
- **하단 포화 해결 (시스템 §12.1 ⬜)**: 소환 덱 6칸 + 수선등 1개(잔향 줄 오른쪽) = 하단 전투 버튼 7개. 재집결(P1)은 전장 오른쪽 아래 둥근 버튼. 지킴이 스킬 버튼은 M1에 두지 않음(§4 #2). (D-44로 2열 → 1열 + 잔향 줄)

## 2. UI 요소별 기능 · 인터랙션

1. **스테이지명** : "1-4 우산 보관소" (`Stage_Battle_Config.place_name`, D-34). 탭 → 반응 없음
2. **제한시간** : 남은 시간 상시 표시 (§10.1). 잔여 20% 이하 → 빨간색 + 1초 깜빡임. 튜토리얼 보호 스테이지(1-1~1-3)는 숨김 (`tutorial_time_limit_off`)
3. **웨이브 진행** : "Wave n/N" + 칸 막대. 보스 웨이브 칸은 해골 아이콘
4. **보스 HP / 남은 적** : 보스 등장 시 보스 이름 + HP 바. 보스 처치 후 최후의 쇄도면 → "남은 적 N" 카운터로 전환 (§18.3)
5. **일시정지** : 탭 → BT-002 (§3). 일시정지 중 시간 · 잔향 수급 정지
6. **배속** : x1 ↔ x2 토글. 잠김(1-6 클리어 전) → 자물쇠 덮개 + 토스트 (현재 `FeatureLockCover`)
7. **AUTO** : 자동 소환 · 자동 수선등 투자 ON/OFF (D-28 #11 기본 ON). 잠김(1-2 클리어 전) → 덮개
8. **지킴이 초상 리스트** (좌측 세로 5칸)
   - 표시: 얼굴 · 배치 방위 색 테두리(⑨ 발밑 링과 같은 색, 시스템 §12.1) · 스킬 쿨다운 원형 게이지
   - **체력 바 없음** — M1 지킴이는 피격 없음 (D-37)
   - 탭 → 해당 지킴이 발밑 1초 하이라이트 (정보용, 조작 없음)
   - 파견 중 계보는 편성 불가라 여기에 나오지 않음 (D-27 #5)
9. **원형 전장** : 수선점 중앙 고정, 8섹터(비노출). 결계 링 = 아군 영역 경계. 지킴이 발밑 방위 색 링
10. **웨이브 예고 마커** : 다음 웨이브 스폰 섹터의 링 가장자리에 화살표 3초 전 표시 (§12.1). 지속 압박 섹터는 옅은 고정 마커
11. **수선점 내구** : 수선점 아래 가로 바 (캐릭터 카드와 떨어진 위치, §8 BT-001). 30% 이하 → 빨강 + 수선점 불빛 감소 연출
12. **잔향 카운터** : "보유/상한" + 초당 수급 (수선등 레벨 반영). 부족한 카드가 있으면 숫자 흔들림 없음 (과한 피드백 금지)
13. **소환 덱** (6칸, 6번째는 2-9 클리어 전 자물쇠)
   - 카드: 얼굴 · 소환 비용 뱃지 · **성향 아이콘**(방패 · 화살 · 원 화살표, §18.1) · 쿨다운 덮개
   - 탭(≤ `hold_threshold_sec`) → 즉시 소환, 방향 자동 (§18.1 탭 규칙)
   - 홀드 → 조준 모드 → 드래그 방향에 부채꼴 프리뷰(섹터 하이라이트) → 놓으면 그 섹터로 소환
   - 덱 위로 되돌려 놓으면 취소 (잔향 소모 없음)
   - 비활성: 잔향 부족(비용 빨강) · 칸 대기 중(쿨다운 덮개) · 소환 상한 도달(⑬ 전체 흐림 + "가장 먼저 흩어질 잔향이 ○초" 표시, §5.4)
14. **수선등 밝히기** (§18.2)
   - 표시: 🏮 + 현재 레벨 `L2` + 다음 비용 `→ 20` + 투자 후 수급 미리보기 "+0.4/초"
   - 탭 → 투자 → 수선점 창문 불 하나 더 켜지는 연출 + 잔향 카운터 수급 갱신
   - 비활성: 잔향 < 비용(비용 빨강) · 최대 레벨(MAX 표시)
   - AUTO 중에도 수동 투자 가능 (수동 우선)
15. **재집결** (P1, D-27 #7) : M1에는 버튼 없음. 자리만 비워 둠

## 3. 화면 흐름
```
AD-002 스테이지 정보 ─[전투 시작]→ PREP(3초, 첫 웨이브 위험 방위 ⑩ 표시 · 탭으로 스킵)
  → 전투 진행 ─(보스 처치 · 잔존 0)→ 슬로우 → RS-001 승리 결과
             ─(보스 처치 · 잔존 > 0)→ 최후의 쇄도(④ 카운터) → 잔존 0 → RS-001
             ─(내구 0 OR 시간 초과)→ RS-002 실패 · 원인 리포트 + CTA 3버튼 (D-28 #10)
  ⑤ 일시정지 → BT-002 ─[계속]→ 전투 진행
                      ─[퇴각]→ 위험 확인 팝업(dim 클릭 무시) → RS-002 (원인 = 퇴각)
자동 진행(D-28 #9): 결과 화면 1.5초 → 다음(또는 같은) 스테이지 전투로 자동 전환 (현재 구현)
```

**BT-002 일시정지**
1. 현재 목표 요약 : "1-4 · Wave 2/4 · 남은 시간 2:14"
2. [계속하기] : 즉시 복귀
3. [전투 설정] : 배속 · AUTO · 수선등 자동 투자 ON/OFF (🆕 개별 토글)
4. [조작 도움말] : 탭 · 홀드 · 드래그 · 성향 아이콘 1장 요약
5. [퇴각] : 위험 확인 팝업 2단계
