## 2. 원본 기획 항목

### 한 줄 소개
문 너머를 다 봐야 마음이 놓이는, 떼어 버려진 현관문 렌즈.

### 외형
- 둥근 황동 테두리 + 볼록 렌즈 = 몸 전체. **렌즈 자체가 커다란 눈 하나** (눈동자가 렌즈 안에서 굴러다님)
- 뒤쪽 나사산 꼬리가 짧은 꼬리처럼 튀어나옴
- 렌즈 아래 작은 황동 덮개(외시경 뚜껑)가 눈꺼풀 — 깜빡일 때 찰칵
- 다리 없이 떠서 이동, 문짝 나뭇조각 하나를 방패 겸 받침으로 끌고 다님

### 성격
- 호기심이 많고 의심도 많다. 모든 문을 들여다봐야 직성이 풀림
- 본 것을 말하지 않고는 못 견딤 — 비밀을 지키는 게 제일 어려움
- 작은 소리에도 렌즈를 돌려 확인

### 원하는 것 · 필요한 것
- **원하는 것:** 문 너머의 모든 비밀을 확인하는 것.
- **필요한 것:** 모르는 채로 믿어 주는 것 — 4장 질문 "모든 비밀을 확인해야 할까?"의 답.

### 진화
- 미정 — `SYS_Evolution` · D-45 기준으로 코드 반영 때 설계.
- [기획 제안] 개화 방향 메모: A = "망원 렌즈" (사거리 강화, 렌즈가 길어짐) / B = "만화경" (렌즈가 여러 조각 — 여러 표적).

### 전투
- 기본: `Snipe` 성향 보정 그대로 (`SYS_InGameBattle` §G). 새 수치 없음.
- 고유 스킬 (방향만, 수치는 `CNT_Skill`): "한 점 응시" — 렌즈를 조여 가장 멀리 있는 망각체 1마리에 강한 한 방. 보스에게 표식.

### 관계 [기획 제안]
- **키키:** 열쇠는 문을 열고, 렌즈는 열지 않고 엿본다. 4장 키키 개인 이야기의 짝 — 서로의 방식을 못마땅해함
- **보틀리:** 열어 보지 않은 편지를 피피가 몰래 들여다보려다 혼남

### 수선점 합류
4-10 유실표 → 성의 문마다 엿보다 망각체로 오해받던 피피를 구조 → 수선점 창문 하나를 맡겨 주자 머묾 [기획 제안].

### 교훈
다 알아야 지킬 수 있는 건 아니다. 믿음은 모르는 부분까지 함께 안는 것.

### 대표 대사 [기획 제안]
- "잠깐, 저 문 너머 한 번만 보고!"
- "…안 봐도, 괜찮은 거야?"

### IP 확장
외시경 모양 스티커 · 문고리 걸이 · "엿보기" 미니 이벤트.

### 아트 제작 주의사항
- 렌즈 = 몸 구조. **사람이 돋보기를 든 모습 금지.**
- 눈 하나 캐릭터라 무섭지 않게 — 눈동자를 크고 둥글게, 눈꺼풀(뚜껑) 표정으로 귀여움
- 시트는 [`ART_Queue`](../07_Art/ART_Queue.md) → `ArtSource/Sheets/` (D-71).
