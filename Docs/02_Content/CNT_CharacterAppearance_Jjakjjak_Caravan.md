## 3. 유지 요소·재활용 구조 제안

기본 정체성·성격·합류·대표 대사는 [원본](./CNT_Character_Jjakjjak.md)을 따른다. 이번 카드에서 보존할 식별 요소는 ① 발꿈치의 단추눈·X자 눈·봉제 미소 ② 보라 커프와 크림 니트·분홍/파랑 패치 ③ 서로 다른 무늬의 짧은 양말 팔이다.

**실루엣 변화:** 짧은 봉제 몸에서, 앞쪽 얼굴 덩어리와 뒤쪽 방 2개가 연결된 낮고 긴 한 몸으로 제안했다. 메인 그림의 큰 덩어리는 총 3개다. 별도의 운전자·곰 인형이 집을 끄는 탈것이 아니다. 코드에 없는 방 수·구체적인 접합 방식은 이번 작화 제안이다.

| 부위 | 원재료·기존 구조 | 가공·재활용 제안 | 새 구조 | 움직임·쓰임 | 확인 상태 |
|---|---|---|---|---|---|
| 앞 얼굴 | 원본 양말 발꿈치·단추눈·봉제 입 | 얼굴 천과 커프를 보존해 첫 덩어리에 배치 | 앞쪽 방향·감정이 읽히는 큰 얼굴 | 이동집 전체가 같은 짝짝이임을 식별 | 원본 식별 + 배치 제안 |
| D1 연결부 | 양말 발목의 골지 커프 | 입구를 펼쳐 다음 방의 천 둘레와 꿰맴 | 짧은 주름 연결 통로 | 방이 연속된 한 몸으로 보임. 실제 굽힘은 미검증 | 구체적 연결 방식 제안 |
| D2 방 | 양말 발꿈치·발 부분의 도톰한 볼륨 | 천 둘레를 꿰매 둥근 방 벽으로 사용 | 낮은 둥근 방과 원형 창문 | 이동집·방벽의 큰 덩어리 형성 | 방·창문은 기존 코드, 부위 대응은 제안 |

**재질·색 제안:** 크림은 얼굴·방 벽, 보라는 커프·지붕 천·연결부, 분홍·탁한 파랑은 작은 패치·팔, 앰버는 창문 빛에 사용한다. 니트 결·솔기·천 두께는 보이되 금속 차량이나 가죽 가방으로 바뀌지 않는다. HEX는 확정하지 않는다. 카드의 금빛 창틀은 작화 제안이며 기계식 차체를 뜻하지 않는다.

## 4. 변경 이유·서사 연결

- 기본 결핍·성격은 원본 참조. 새 사건·캐릭터 관계·대표 대사는 만들지 않는다.
- 기존 코드의 계기: 길을 잃은 짝 양말들이 하나둘 이어 붙음 → 몸이 마디별 방을 가진 긴 이동집으로 변함.
- 코드 설명과 원본의 공동체 방향을 연결해 **함께 머무는 보금자리**로 표현한다. 새 외형의 특별 이벤트·획득 정책은 작성하지 않는다.
- 감정 변화의 구체적 사건·시점·대사는 미정. 이번 카드의 짧은 문장은 기존 설명의 시각 전달용 요약이며 새로운 확정 서사가 아니다.

## 6. 전투·잔향이·실제 PNG 주의사항

- 전투 역할·스킬은 [진화](../01_System/SYS_Evolution.md)·[스킬](./CNT_Skill.md) 정본 참조. 방어형이라는 이유로 신규 효과·수치·공격 장비를 만들지 않는다. 긴 몸이 방위를 감싸는 실제 표현은 코드 설명에 있으나 이번 정지 카드로 구현 검증하지 않았다.
- [잔향이 규격](../07_Art/ART_EchoSpec.md) D-48: 현재는 같은 본체 그림의 축소·알파·오라 처리. 개화형에서는 해당 개화 모습을 사용한다. 별도 잔향이 그림은 이번 제작 범위에 없음.
- 축소 때 남길 것은 앞 얼굴·큰 보라 연결부·둥근 방·바퀴다. 작은 별·세밀한 봉제 결·창틀 금속 장식은 생략 가능하다. 독립 유령·별도 거주자 스프라이트를 본체에 굽지 않는다.
- **이 카드 전체는 게임 PNG가 아니다.** 투명 본체 추출·1024 규격 정규화·알파/외곽선/밝기/64px/72px/실제 전투 검수는 미실시다. 긴 몸의 폭과 내용 높이 922를 함께 만족할 수 있는지는 별도 확인이 필요하다. 카드 크기를 기술 규격 통과로 해석하지 않는다.
- 실제 리소스를 만들 경우 [전투 규격](../07_Art/ART_BattleSpriteSpec.md)을 따르고, M1의 기존 그림·1장+코드 트윈 정책을 유지한다. 포즈·애니메이션 프레임·최종 에셋 교체를 추가하지 않는다.
