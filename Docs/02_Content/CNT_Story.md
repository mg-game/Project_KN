> 컨셉 문서 §7에 메인 스토리가 이미 있다 (프롤로그 · 1~6부 · 최종부). 코드에는 짧은 인트로 · 튜토리얼 말풍선 · 장마다 동화책 3줄이 있다. **둘이 다르게 흘러간다.** 이 문서는 컨셉을 정본으로 장 구성을 맞추고, M1에 실제로 나오는 **프롤로그 · 1장 문구**를 정한다.

## 0. 요약
- 컨셉 = **장 = 기억등 지역 7곳** (잊힌 것들의 거리 → 비 골목 → 황혼 극장가 → 천 개의 문 성 → 멈춘 기차역 → 계절 잃은 온실 → 이름 없는 중앙광장).
- 코드 동화책 = 4장 "분실물 보관소(립스틱)", 5장 "별빛 세탁소(몽당초)" — 컨셉 지역 · 캐릭터와 **어긋남**.
- D-49 구조 배치표(2장 루루팝 · 3장 엘리제 · 5장 네임리스 00 …)도 컨셉과 다름 → **컨셉 지역에 맞춰 다시 배치** (§3 #1). 장당 2명 · 총 15명은 그대로.
- 프롤로그: 코드 = "불 켜진 수선점에 짝짝이가 문을 엶" / 컨셉 = "**플레이어가 꺼진 수선점에 불을 켜자 몽실 · 짝짝이가 깨어남**" → 컨셉으로 (§3 #2).
- 튜토리얼 문구 중 **"불빛 게이지"(D-27로 폐지)** 1단계가 남아 있음 → M1 교체 필요 (§2.4).

### 1.1 인트로 (FTUE 0단계, 3장 · 약 20초 · 건너뛰기)
1. 잊힌 물건들이 하나둘 밤 골목으로 흘러들었어요.
2. 골목 끝 작은 수선점에 따뜻한 불이 켜졌어요.
3. 짝을 잃은 양말 짝짝이가 문을 열었어요. "어서 와요!"

### 2.2 프롤로그 — M1 인트로 교체안 (4장 · 약 25초 · 건너뛰기 유지)
```
[1] 문 닫은 분실물 보관소. 이름이 지워진 낡은 열쇠 하나.
    "자정이 되자, 열쇠가 벽에 없던 문을 열었어요."
[2] 불이 모두 꺼진 밤의 수선점. 계산대 위 오래된 장부.
    "원래대로 돌려놓으려 하지 마라. 먼저 사라지지 않게 붙잡아라." — 전대 수선사
[3] 플레이어가 수선점의 불을 켠다 → 몽당초 몽실과 짝 잃은 양말 짝짝이가 깨어난다.
    몽실: "불이… 다시 켜졌어!"   짝짝이: "새 식구다! 어서 와요!"
[4] 불빛을 본 그림자들이 골목 끝에서 몰려온다.
    짝짝이: "오랜만에 생긴 집이야. 이번엔 안 잃어버릴 거야!"
→ ftue_intro 말풍선 → 1-1 첫 전투
```
- 그림: 지금 인트로 그림 3장 중 2장 재사용(밤 골목 · 수선점) + 새로 2장(열쇠와 문 · 깨어나는 두 친구) [가정 — 아트 확인].
- 몽실이 컨셉에서 짝짝이와 함께 "기존 거주자"(§5.7) → 시작 4 중 키키 · 똑단이는 1-1 직전 짧은 한 줄로 합류 (§2.3).

> 💡 **조합 제안 (검토용)** — 방치 "잠자기 모드" × 이야기
