### 7.1 관찰 근거

- 기존 게임 기본형은 §3의 `jjak_base.png` 실물을 Git LFS에서 받아 보았다. **새로 생성하거나 이미지 파일을 수정하지 않았다.**
- SHA-256: `60d8eb0ca8c3fe3d62717c5254db0f15af77c801a275a2d4a7a03a5bd9675fb3`, 854,671 bytes. 근거 커밋 `4b73a5a`의 LFS OID·크기와 일치한다.
- 기존 밤지기 컨셉 `Art/Concept/jjak_nightkeeper.png`도 실물로 확인했다. SHA-256 `cfebf19bc33f6616a0544c3c9284f2a06ed584eca00bcf65ccf519857b3ab25c`, 2,478,247 bytes. 1122×1402 불투명 소개 카드다. 기본형 판정의 직접 기준으로 사용하지 않는다. 채팅 첨부와 파일 바이트 동일성은 검증할 수 없다.
- 기본형 육안 관찰: 크림색 니트 봉제 몸, 보라색 접힌 커프, 한쪽 보라 단추눈과 반대쪽 X자 눈, 꿰맨 웃는 입, 짧은 팔 둘·발 둘, 분홍/파랑 패치, 보라 발끝. 이미지에서 확인되는 것과 문서의 해부학 설명은 아래처럼 구분한다.

### 7.3 제작 기준 검토안 (승인 전)

- **유지 후보:** 낡은 천의 이음새·패치, 단추눈·꿰맨 입, 서로 다른 양말 팔다리, 외짝 양말의 윤곽, 크림/파스텔/보라 계열. 작은 유령은 본체와 분리한다.
- **기존 이미지에서 이어받을 인상 후보:** 따뜻한 표정·보라 커프·비대칭 얼굴. 반대 눈의 X자 모양·패치 위치·구체 체형 비율은 새 고정 설정으로 승인하지 않고 검토한다.
- **구조 보강 제안:** 커프(입구)·발목·발꿈치·발끝 솔기가 어느 신체 부위로 이어지는지 표시한 구조 러프를 만든다. 사용자 참고대로 얼굴이 발꿈치 면에 놓이는 안을 검토하고, 기존 코드의 “뒤꿈치=등” 설명과 달라지는 점을 남긴다.
- **수정 가능 후보:** 무늬 배치·색 비율·소품·표정 디테일. 변경해도 원형 구조·캐릭터 식별·작은 크기 가독성을 보존하는지 확인한다.
- **별도 결정:** 정확한 팔다리 개수·원물 부위의 접합 방식·대표 포즈·패치 위치. 구조 해석 없이 캐릭터 인형에 양말 장식만 붙이지 않는다.

### 7.5 진화 연결과 다음 산출물

- **기억형:** D-45의 같은 그림+기억 장식 레이어 1겹을 따른다. 사용자 참고의 “양말 팔다리를 덧붙일 자리”는 봉제선·패치 주변의 **레이어 접합 후보 위치**를 남기는 검토 사항으로 기록한다. 이것만으로 기억형에 새 팔다리 수·새 본체·새 실루엣을 확정하지 않는다.
- **개화 A:** 천 짝의 대행진 (신규), **개화 B:** 양말 카라반 (기존 그림 재사용). 근거는 SYS_Evolution §2.3이며, 기본형 검토에서 개화 외형을 다시 설계하지 않는다.
