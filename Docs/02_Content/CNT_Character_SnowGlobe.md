## 2. 원본 기획 항목

### 한 줄 소개
첫눈 오던 하루를 영원히 가둬 두고 싶은, 온실 구석의 스노우볼.

### 외형
- 유리 돔 = 머리 · 몸, 나무 받침 = 다리 대신 짧은 받침대. 돔 안에 **작은 눈 내리는 마을** + 그 앞에 얼굴 (돔 유리에 비친 듯 그린 눈 · 입)
- 유리는 간유리처럼 뿌옇게, 굵은 외곽선 (투명 X)
- 흔들 때마다 돔 안 눈송이가 휘날림 — 감정 표현 장치
- 받침 옆 작은 태엽 손잡이 (오르골 스노우볼) 하나가 팔처럼 움직임

### 성격
- 다정하지만 고집이 세다. 바뀌는 걸 싫어함
- 추억 이야기를 반복함
- 흔들리면(놀라면) 안이 눈보라가 됨

### 원하는 것 · 필요한 것
- **원하는 것:** 그 첫눈 오던 하루를 영원히 간직하는 것.
- **필요한 것:** 눈이 녹아도 기억은 남는다는 걸 믿고 다음 계절을 맞는 것 — 6장 질문 "순간을 영원히 붙잡으면 행복할까?".

### 진화
- 미정 — `SYS_Evolution` · D-45 기준으로 코드 반영 때 설계.
- [기획 제안] 개화 방향 메모: A = "눈보라 돔" (보호막 강화, 돔이 커짐) / B = "사계 구슬" (돔 안 계절이 바뀜 — 상황별 보조).

### 전투
- 기본: `Defense` 성향 보정 그대로 (`SYS_InGameBattle` §G). 새 수치 없음.
- 고유 스킬 (방향만, 수치는 `CNT_Skill`): "유리 돔" — 동료 하나를 투명 돔 보호막으로 감쌈. 돔 안은 잠깐 눈이 내려 망각체가 느려짐 [기획 제안].

### 관계 [기획 제안]
- **엘리제:** 6장 질문의 짝 — 같은 곡을 영원히 반복하는 오르골과 같은 하루를 영원히 가둔 스노우볼
- **레이니:** 비와 눈 — 날씨 친구

### 수선점 합류
6-5 유실표 → 겨울 한 칸을 지키며 아무도 못 들어오게 하던 글로비 → 수선점에 "새 겨울 장식"을 맡기자 문을 엶 [기획 제안].

### 교훈
영원히 붙잡아 둔 순간은 멈출 뿐이다. 녹아야 다음 눈이 내린다.

### 대표 대사 [기획 제안]
- "흔들지 마…! 눈이 다 흩어지잖아."
- "이번 겨울엔, 같이 볼래?"

### IP 확장
스노우볼 굿즈 (실제 상품성 높음) · 겨울 시즌 이벤트 마스코트.

### 아트 제작 주의사항
- 스노우볼 = 몸 구조. **사람이 스노우볼을 든 모습 금지.**
- 유리 반투명 대신 간유리 · 굵은 외곽 (보틀리와 같은 규칙) — 보틀리(초록 병)와 색 · 모양(돔 + 받침)으로 구분
- 시트는 [`ART_Queue`](../07_Art/ART_Queue.md) → `ArtSource/Sheets/` (D-71).
