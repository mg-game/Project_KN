### 7.1 기존 실물과 설정의 차이

- [기본형 이미지](https://github.com/mg-game/Project_KN/blob/4b73a5a33c22d1b6246794c86fdbf7b27db281b0/Assets/_Project/Art/Characters/mong_base.png)를 LFS에서 받아 SHA-256·바이트 수·육안·치수를 확인했다. **`1b35214088ef6232754a3b39381e969a1a48fde76e2c44dfb75c29217901943b`, 533,151 bytes, 1024×1024 RGBA**. `.meta`·GUID는 변경하지 않았다.
- 실물은 중앙 심지/불꽃 **하나**를 가진 둥근 몽당초, 흘러내리는 아이보리 촛농, 감은 눈·작은 미소·분홍 볼, 손, 보라 촛대와 구부러진 손잡이다.
- [기존 콘텐츠 코드](https://github.com/mg-game/Project_KN/blob/4b73a5a33c22d1b6246794c86fdbf7b27db281b0/Assets/_Project/Editor/Content/CharacterContent.Lineages.cs)도 몽당초와 불꽃 더듬이를 설명한다. 설정집은 생일 초·촛농 토끼·두 촛불 귀·샹들리에 같은 팔·금속 촛대다. 같은 그림/구조로 처리하지 않았다.
- MW1·MW2는 설정집의 **두 촛불 귀와 촛농 몸·금속 촛대**를 기준으로 한다. 기존 실물의 아이보리 촛농 재질·감은 눈·미소·볼·보라 촛대는 시각 참고다. 기존 한 불꽃 그림을 덮어쓰거나 바뀐 것으로 표시하지 않는다.
- `mong_lantern`·`mong_firefly`는 코드에 있는 별도 형태다. 이번 작업 표제를 그 형태나 진화 B 등으로 임의 대응시키지 않는다.

## 8. 보존 요소·재활용 구조 제안

보존 기준: [설정집 연결](./CNT_Character_Mongsil.md#2-원본-기획-항목-기존-원문으로-연결). ① 두 심지/불꽃의 긴 촛불 귀 ② 녹아내리는 아이보리 몸·따뜻한 표정 ③ 짧은 금속 촛대·수정 포인트를 유지한다. 토끼가 초 장식을 쓴 모양이나 니트 봉제인형이 아니라 **촛농 자체가 몸**이다.

| 구분 | 원재료·전 구조 | 가공/재활용 제안 | 새 구조·쓰임 | 상태 |
|---|---|---|---|---|
| 본체 | 원본의 촛농 몸·촛불 귀·금속 촛대 | 둥근 촛농 덩어리와 두 귀, 짧게 휜 팔·받침을 연결 | 한 몸인 촛농 토끼 실루엣 | 설정집 기반 새 작화 제안 |
| D1 | 몸에서 남은 촛농 | 모아 식힌 뒤 얕은 꽃잎형 손바닥으로 다시 빚음 | 손끝에 작은 촛농 방울을 담는 **받침 손** | 재활용 상세 제안 |
| D2 | 이번 요청의 밀랍 | 낮고 얕은 고리/컵 모양으로 빚어 각각의 귀 뿌리에 배치 | 두 촛불 아래의 **촛불 받침**, 흘러내리는 자국이 모이는 가장자리 | 재료 사용·구조 제안, 원본 소재 소급 아님 |
| D3 | 굳어 남은 촛농 조각 | 다시 이어 촛대 안쪽 둘레에 낮고 연속된 물결 테두리 형성 | 기존 금속 촛대 안에서 흐른 촛농을 받는 **테두리** | 재활용 상세 제안 |

- 변화는 몸 외곽의 받침 손, 귀 뿌리의 낮은 받침 두 개, 금속 촛대의 안쪽 촛농 테두리로 읽힌다. 갑옷·왕관·날개·무기는 추가하지 않는다.
- 손에 든 물방울 모양은 촛농이다. 불꽃은 귀 위 **2개만** 표현했다. 손바닥 방울에 별도의 심지/불꽃을 부여하지 않는다.
- 촛대 바깥은 기존 계열의 보라 금속으로 남기며 굽은 손잡이와 작은 수정 포인트를 유지한다. 촛농 테두리가 금속 전체를 대체하지 않는다.
- 재질·색: 몸/귀/손/테두리는 아이보리와 옅은 라벤더 그림자, 볼은 소량 분홍, 밀랍 받침은 꿀빛, 불꽃은 앰버/골드다. 밀랍의 표면이 금속 반지처럼 보이지 않도록 부드러운 녹은 가장자리와 반투명 느낌을 유지해야 한다. MW1의 D2는 금속처럼 읽히는 광택이 강했다. **MW2에서 무광에 가까운 꿀빛 밀랍·불규칙한 녹은 가장자리로 보완**해 금속 촛대와의 재질 차이가 더 뚜렷해졌다. 최종 작화 검수는 별도다. HEX·물성 수치는 미정이다.
- **실제 재료량·성형 공정·내열성·하중·회수 효율은 미검증**이다. 카드의 받침 설명은 디자인 기능 제안이다. 촛농이 무한히 재생되거나 불꽃 연료가 자동 순환한다는 설정을 만들지 않는다.

## 9. 변경 이유·카드 원문·디테일 대응

변경 의도는 **남은 촛농·밀랍의 흔적을 다시 쓰는 구조로 보이게 하는 것**이다. 촛농을 모으게 된 사건·누가 만들어 주었는지·변경 후 감정과 서사 시점·공식 외형명은 미정이다. 기본 성격·합류는 원본을 참조하며 새로운 생일 행사·대사·관계·획득을 추가하지 않는다.

| 카드 위치 | 원문 | 이미지 대응 |
|---|---|---|
| 제목 | 촛농·밀랍 몽실 | 재료 방향을 나타내는 작업 표제 |
| 부제 | 남은 따뜻함을 다시 빚어요 | 새 손·받침·테두리의 구조 제안 |
| 상태 | 재활용 외형 제안 · 검토 중 | 확정 설정·최종 채택 아님 |
| D1 촛농 → 받침 손 | 남은 촛농을 빚어 작은 손에 담아요. | 위를 향한 얕은 손과 작은 촛농 방울 |

## 11. 실제 게임용 PNG·잔향이·검수

- 스킬·전투 역할은 [원본](./CNT_Character_Mongsil.md)·[스킬 정본](./CNT_Skill.md) 참조. 촛농을 받는 모양을 새 회복량·보호막·자동 수선 효과로 확정하지 않는다.
- [잔향이 규격](../07_Art/ART_EchoSpec.md) D-48의 현재 본체 축소·알파·오라 원칙을 따른다. 이 외형의 실제 잔향이 적용은 유형·등록 정책이 미정이라 확정하지 않는다. 이번에 전용 반투명 PNG를 만들지 않는다.
- 게임용 단순화에서는 두 귀/불꽃·큰 얼굴·촛농 몸·짧은 촛대를 먼저 남긴다. 수정·금색 별·작은 방울·세부 광택은 생략 가능하다. 손의 얕은 그릇·D2의 재질 구분이 64px/72px에서도 읽히는지는 별도 확인이 필요하다.
- **카드는 실제 투명 전투 PNG가 아니다.** [전투 규격](../07_Art/ART_BattleSpriteSpec.md)의 캔버스·높이·바닥·중심·외곽선·알파·밝기·얇은 부속 비율, 축소·전장 대비를 통과했다고 표시하지 않는다. 촛대 옆 수정의 길이·분리 레이어도 실제 제작 때 검수한다.
- Unity 임포트·실제 전투·코드 트윈·잔향이 실행은 미실시. M1의 기존 아트·1장+코드 트윈 범위를 바꾸지 않는다.

| 검수 항목 | 결과 | 한계 |
|---|---|---|
| 기존 실물·원문·ID | 확인 | LFS SHA/크기·치수·기존 코드와 설정 차이 기록 |
| 정체성·큰 형태·프레임 | 육안 대조 | 두 촛불 귀·촛농 몸·촛대 적용. 최종 작화 채택은 별도 |
| 재활용 구조·D1~D3·문구 | 육안 대조·재질 보완 반영 | MW2에서 밀랍/금속 재질 차이와 이음 외관 보완. 실제 물성·공정 미검증 |
| 기존 데이터·이미지·GUID | 보존 | 기존 게임 에셋 교체 없음 |
| 실제 PNG·축소·Unity | 미실시 | 설명용 카드만 제작 |
| DD 검수·사람 확인·채택 | 미실시 | 검토 중 유지 |

남은 판단: 공식 외형명·유형·ID, 밀랍 수급/변경 계기·서사 시점, 실제 재질/접합과 단순화, 최종 작화 채택. 이번 카드만으로 설정 확정·공정 검증을 대체하지 않는다.

- 2026-11-12: 기존 실물 확인 → MW1 구조 제안 → D2 재질/D3 이음 보강 MW2 → 상세 텍스트·대응 검수 제작. 우선 3종의 카드+텍스트 사례가 준비됐으며 게임 적용 완료를 뜻하지 않는다.


## 12. 투명 본체 후보·규격·축소 검토 (2026-11-12)

후속 사용자 “아트 작업 진행해”에 따라 카드 이후의 게임용 본체 **검토 후보**를 제작했다. 앞 절의 “실제 PNG 미실시”는 카드 단계 기록이며, 현재 이 절의 실측·미검증 상태를 구분한다. **최종 채택·기존 에셋 교체·Unity 실행은 아직 미실시**다.

- 입력/수정: MW2 → 분리 R1 → 외곽선 R2 → 눈 가독성 R3.
- 두 촛불 귀·받침 손·밀랍 받침·촛농 테두리·보라 금속 촛대를 유지해 분리했다. R2 한쪽 눈의 어두운 영역이 49×28px로 작아 감은 눈 표정을 유지하며 R3에서 조금 넓고 깊게 보완했다. 수동 위치 ROI 안의 색상 연결 성분은 최종 왼눈 58×36·오른눈 64×41px로 확인했다. 색상 기반 근사이며 모든 작은 형태의 자동 의미 분할 검증은 아니다.

실제 저장 PNG를 기기 배율1의 브라우저에서 128px·64px, 잔향이 비교는 **PNG 캔버스80px→내용 약72px·알파0.75**로 표시하고 64px 검은 실루엣과 함께 육안 확인했다. 실제 `field_tall.png` 중앙 바닥을 사용한 비교 합성이며 Unity 화면이 아니다. 큰 정체성은 구분되지만 작은 무늬·솔기는 감소한다. 오라·코드 트윈·VFX는 적용하지 않았다.

짧게 붙은 등불·수정·리본과 원물 본체의 경계를 육안 확인했으나, **몸/부속 의미 분할에 따른 30% 정밀 측정·모든 작은 형태·모든 배경/VFX·Unity 임포트/실제 전투·DD/사람 확인·최종 채택**은 별도다. 새 PNG·임의 `.meta`를 Git에 등록하거나 기존 파일을 덮어쓰지 않았다.
