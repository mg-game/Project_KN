## 2. 원본 기획 항목

### 한 줄 소개
태엽이 다 풀릴 때까지 멈추지 않는, 대합실에 남겨진 장난감 기관차.

### 외형
- 기관차 = 몸 전체. 앞 보일러 둥근 면에 **얼굴 (동그란 헤드라이트 눈 2 · 웃는 입)**
- 등에 커다란 태엽 열쇠 — 감길수록 신남, 풀리면 졸림
- 굴뚝에서 수증기 대신 작은 구름 한 점 (갇힌 모양 아님 — 하얀 김)
- 바퀴 4개로 굴러감, 뒤에 빈 화물칸 하나를 끌고 다님 (빈 좌석)

### 성격
- 급하고 씩씩하다. "출발!"이 입버릇
- 멈추는 걸 무서워함 — 태엽이 풀리면 끝인 줄 앎
- 빈 화물칸에 아무나 태우려 함

### 원하는 것 · 필요한 것
- **원하는 것:** 마지막 역까지 달려 약속한 아이에게 도착하는 것.
- **필요한 것:** 도착하지 못해도 함께 달린 길이 끝났음을 받아들이고 떠나보내는 것 — 5장 질문 "떠나는 것과 버리는 것은 어떻게 다를까?".

### 진화
- 미정 — `SYS_Evolution` · D-45 기준으로 코드 반영 때 설계.
- [기획 제안] 개화 방향 메모: A = "급행" (돌격 강화, 객차가 붙어 길어짐) / B = "회차선" (빙 돌아오는 궤도 — 순회형).

### 전투
- 기본: `Assault` 성향 보정 그대로 (`SYS_InGameBattle` §G). 새 수치 없음.
- 고유 스킬 (방향만, 수치는 `CNT_Skill`): "출발 진행!" — 지정 방향 일직선 돌진, 경로의 망각체를 밀어냄. 태엽 단계에 따라 거리 증가 [기획 제안].

### 관계 [기획 제안]
- **아홉시(회중시계):** 5장의 짝 — 떠나려는 기관차와 멈춘 시계. "떠남 vs 멈춤"
- **웰리:** 둘 다 일단 뛰어드는 성격 — 누가 먼저 도착하나 경쟁

### 수선점 합류
5-5 유실표 → 대합실에서 태워 줄 손님을 찾던 칙폭이 → 수선점까지 태워 주겠다는 흥정 끝에 합류 [기획 제안].

### 교훈
떠나는 것은 버리는 게 아니다. 함께한 길을 품고 다음 역으로 가는 것.

### 대표 대사 [기획 제안]
- "칙칙폭폭! 출발 진행!"
- "…태엽이 다 풀리면, 나는 어디로 가?"

### IP 확장
태엽 기관차 장난감 · 열차표 굿즈 · 역 스탬프 랠리 이벤트.

### 아트 제작 주의사항
- 기관차 = 몸 구조. **사람이 기관사 모자를 쓴 모습 금지.** 실존 철도 회사 로고 · 색 조합 금지.
- 수증기는 하얀 김 — 불꽃 금지 (§15.1)
- 시트는 [`ART_Queue`](../07_Art/ART_Queue.md) → `ArtSource/Sheets/` (D-71).
