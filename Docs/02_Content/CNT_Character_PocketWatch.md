## 2. 원본 기획 항목

### 한 줄 소개
누군가 떠난 9시에 멈춰, 그 순간 전으로 돌아가고 싶은 회중시계.

### 외형
- 뚜껑 열린 회중시계 = 머리 · 몸통. 시계판 위에 **얼굴 — 시곗바늘 두 개가 눈썹처럼** 표정을 만듦 (9시 = 슬픈 표정)
- 시곗줄이 팔과 꼬리 — 줄 끝 고리로 물건을 잡음
- 열린 뚜껑이 망토처럼 뒤로 젖혀짐
- 바늘이 멈춰 있지만 가끔 거꾸로 한 칸씩 움직이려 함

### 성격
- 차분하고 정확하다. 시간 약속에 엄격
- 말끝마다 시각을 붙임 ("지금은 9시야.")
- 남의 시간은 아껴 주면서 자기 시간은 멈춰 둠

### 원하는 것 · 필요한 것
- **원하는 것:** 그 9시 전으로 시간을 되돌리는 것.
- **필요한 것:** 다시 째깍거리며 앞으로 가는 것 — 칙폭이와 함께 "떠나보내기"를 배움.

### 진화
- 미정 — `SYS_Evolution` · D-45 기준으로 코드 반영 때 설계.
- [기획 제안] 개화 방향 메모: A = "자정 종" (제어 강화, 종소리 광역) / B = "되감기" (뒤로 감기 — 아군 회복 성격).

### 전투
- 기본: `Support` 성향 보정 그대로 (`SYS_InGameBattle` §G). 새 수치 없음.
- 고유 스킬 (방향만, 수치는 `CNT_Skill`): "멈춘 9시" — 일정 범위 망각체의 움직임을 잠깐 느리게 (보스는 짧게) [기획 제안].

### 관계 [기획 제안]
- **칙폭이:** 5장 짝 — "떠남 vs 멈춤". 칙폭이의 태엽을 감아 주는 유일한 존재
- **엘리제:** 같은 곡을 반복하는 오르골과 같은 시각에 멈춘 시계 — "반복과 정지" 대화

### 수선점 합류
5-10 유실표 → 멈춘 플랫폼에서 9시를 기다리던 아홉시 → 칙폭이가 "다음 역 시간을 알려 줘" 하자 합류 [기획 제안].

### 교훈
멈춰 둔 시간은 지켜 주지 않는다. 다시 흘러야 그 순간도 추억이 된다.

### 대표 대사 [기획 제안]
- "지금은… 9시야. 언제나."
- "한 칸만 더 가 볼까. 째깍."

### IP 확장
회중시계 목걸이 · 탁상시계 · 매일 9시 접속 보상 연출.

### 아트 제작 주의사항
- 시계 = 몸 구조. **사람이 시계를 목에 건 모습 금지.**
- 시곗바늘 눈썹이 핵심 표정 장치 — 64 px에서 바늘 두께 확보
- 시트는 [`ART_Queue`](../07_Art/ART_Queue.md) → `ArtSource/Sheets/` (D-71).
