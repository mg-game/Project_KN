## 0. 개요
- 목적: 보스전 = 스테이지의 **시험**. 그 장에서 배운 동사(막기 · 부르기 · 비우기 · 지키기 · 밝히기)를 한 번에 묻는다.
- 원칙 (시스템 §9.2 FINAL_WAVE)
  1. 360° 패턴 최소 1개 — 한 방향만 막아서는 못 이긴다
  2. 페이즈제 — 체력 70% · 30%에서 패턴이 바뀐다
  3. 보스 처치 = 끝이 아니다 → 최후의 쇄도 (보스 올인 vs 주변 정리)
- M1 범위 (D-34 #5): **360° 패턴 · 페이즈 = 1-10만.** 1-1~1-9 보스는 현재 동작 + 잔향 흡수(D-40) 교체만.

## 2. 기획 방향 (To-be) — DD

### 2.0 보스별 정체성 — 요구하는 판단

| 보스 | 한 줄 | 요구하는 판단 | 지는 이유 (실패 원인 안내 문구) |
|---|---|---|---|
| 망각의 큰그림자 | 천천히 다가와 **잔향을 빨아먹는** 어둠 | **잔향을 쌓아 두지 말고 쓰기** — 투자(수선등)든 소환이든 빼앗기기 전에 | "잔향을 너무 많이 들고 있었어요" |
| 좀나방 여왕 | 부하를 계속 낳는 옷장의 주인 | **잔향이를 아무 데나 던지지 않기** — 부하(좀나방)는 지킴이로 받고, 잔향이는 여왕에게 | "좀나방이 잔향이를 갉아먹었어요" |
| 기억등을 삼킨 좀나방 여왕 (1-10) | 1장 종합 시험 | **빈 방향 메우기 + 보스 올인 vs 정리** — 8방향 동시 소환과 최후의 쇄도 | "빈 방향으로 좀나방이 들어왔어요" |

### 2.1 망각의 큰그림자 — M1 (현재 + 흡수 교체)

```
[등장] 보스 웨이브(웨이브 N) 시작 → 북(N) 진입 · 보스 안내 문구(counter_hint)
[이동] 코어 직진 (속도 0.16 — 가장 느림)
[잔향 흡수] (D-40 #1, I-10c)
  IF 수선점 중심 거리 ≤ drain_radius
     → drain_interval마다 잔향 −drain_per_tick
  IF 수선점에 닿음 (공성 1타마다)
     → 잔향 −drain_on_hit
  잔향은 0 아래로 내려가지 않음 · 흡수한 만큼 보스 머리 위 "−N" + 잔향 칸 흔들림
[분노] 체력 ≤ 50% → 현재 그대로 (속도 ×1.3 · 피해 ×1.4)
[처치] → 최후의 쇄도 (SYS §18.3)
```
- 판단 구조: 흡수 반경에 들어오기 **전에** 잔향을 쓰면 손해가 없다 → "모아서 L4 투자" 같은 비축 전략에 대한 견제. 반대로 수선등 레벨이 높으면 흡수를 수입으로 버틴다 (L1 1.0/초 vs 흡수 약 0.67/초 [가정]).
- P1 (M1 플레이테스트 뒤): 70% "그림자 갈래" = 좌우 인접 섹터에 망각의 그림자 1마리씩 / 30% 흡수 반경 ×1.3.

### 2.2 좀나방 여왕 — M1 (현재 그대로)

```
[등장] 북(N) 진입
[부하] minion_interval마다 보스 근처에 좀나방 minion_count마리 (현재 6초 · 2마리)
[천 갉아먹기] 좀나방 → 근처 천 특성 아군 공격력 −20% · 천 특성 잔향이 피해 ×1.5 (현재 FabricEater)
[분노] 체력 ≤ 50% → 부하 간격 ×0.6 (현재)
```
- 판단 구조: 여왕 쪽 방향에 잔향이를 잔뜩 던지면 좀나방에게 갉아먹힘 → 지킴이가 부하를 받고, 잔향이는 **앞장서기(Charge)**로 짧게 여왕만 친다.
- P1: 70% 날개 바람(전 방향 잔향이 밀어내기 0.3) — 성향 "곁 지키기"의 가치 확인용.

### 2.3 기억등을 삼킨 좀나방 여왕 — 1-10 (M1 신규, 360°)

**상태 전이**
```
[INTRO] 등장 연출 1.5초 (스킵 가능) — 몸 안 기억등 불빛이 깜빡임 (ART-10)
   ↓
[P1: 100% ~ 70%] 현재 여왕과 같음 (부하 2 / 6초)
   ↓ 체력 ≤ 70%
[RING_1 예고 1.5초] 8섹터 바깥 테두리에 날개 무늬 표시 (빈 방향 = 빨강 강조)
   ↓
[RING_1] 8섹터 동시 좀나방 1마리씩 (총 8) → 이후 P2
   ↓
[P2: 70% ~ 30%] 부하 간격 ×0.75 · ring_repeat초마다 4섹터 소환 (정방위 N·E·S·W ↔ 대각 NE·SE·SW·NW 교대)
   ↓ 체력 ≤ 30%
[LEAK 연출 1초] 삼킨 기억등 빛이 새어 나옴
   ├─ 분노 (현재 Enrage 규칙, 이 보스만 임계 0.3)
   ├─ 전장의 숨은 적 전부 드러남 + 이후 새로 숨는 적 없음 (빛 = 숨기 대응, CNT_Enemy 1-6)
   └─ RING_2: 8섹터 동시 좀나방 1마리씩
   ↓
[P3: 30% ~ 0%] 부하 간격 ×0.6 (분노) · 링 반복 없음
   ↓ 체력 0
[최후의 쇄도] → 마지막 1체 정화 → [기억등 점등 연출] → 챕터 상자 · 동화책 1장
```

**비즈니스 로직**
```
OnBossDamaged(boss):
  FOR phase IN boss.phases WHERE !phase.done AND boss.hp_ratio ≤ phase.hp_threshold (높은 임계부터):
      phase.done = true
      QUEUE phase.actions (앞 행동과 최소 phase_gap_sec 간격)
  # 한 번에 두 임계를 넘어도 행동은 건너뛰지 않고 순서대로 실행 (360° 패턴이 이 보스의 학습 목표)

RunAction(SummonRing, sectors, minion_id, count_per_sector):
  예고(ring_telegraph_sec) 표시 → 끝나면:
  slots = enemy_cap − 현재 적 수
  IF slots ≤ 0 → 이번 링 보류, 1초 뒤 1회 재시도, 그래도 0이면 취소
  ELSE → sectors를 "빈 방향(지킴이 없음) 먼저" 순서로 정렬해 slots만큼만 소환
  IF 예고 중 보스 처치 → 소환 취소 (최후의 쇄도로)

RunAction(Leak):
  모든 숨은 적 Reveal · 보스 생존 동안 Hide 기믹 무효
  Enrage(boss)
```

## 4. 예외 처리 / 엣지 케이스

| 케이스 | 처리 |
|---|---|
| 한 번에 70% · 30% 동시 통과 (큰 한 방) | 행동 큐에 순서대로, 사이 `phase_gap_sec` (2초) — 링 소환은 건너뛰지 않음 |
| 링 예고 중 보스 처치 | 소환 취소 → 최후의 쇄도 |
| 적 상한(40) 도달 | 남은 칸만큼 빈 방향 먼저, 1초 뒤 1회 재시도 후 취소 (현재 분열 · 부하 보류 규칙과 같은 계열) |
| 잔향 0에서 흡수 | 아무 일 없음 (음수 없음) · 표시도 생략 |
| 흡수 중 일시정지 · 앱 이탈 | 흡수 타이머 · 페이즈 진행 · 행동 큐 모두 전투 스냅샷에 포함 → 복원 시 그대로 |
| 제한시간 | 1-10 `boss_fight_est_sec` = 45 [가정] (페이즈 2회 · 링 3~4회 반영, `BAL_BattleKnobs` §4.5) |
| 숨은 적 + LEAK 이후 새 그림자 등장 | 등장 즉시 드러난 상태 (보스 생존 동안) |
| 지킴이 무적 (D-37) | 부하가 지킴이를 공격하지 않음 → 링 소환 위협 = **빈 방향으로 수선점 직행**. 지킴이 있는 방향은 막힘 |

## 5. 어뷰징 검토

| 시나리오 | 대응 |
|---|---|
| 보스를 살려 두고 부하로 잔향 파밍 | 잔향은 전투 안에서만 쓰는 재화 · 제한시간이 상한 → 바깥 가치 없음 |
| 페이즈 직전 앱 종료 → 재접속으로 링 회피 | 복원은 항상 이탈 시점 상태 (시스템 §9.3) — 큐에 들어간 행동도 복원 |
| 1-10 반복 파밍 | 보상은 스테이지 단위 (챕터 상자 · 동화책은 1회) — 보스 패턴과 무관 |
