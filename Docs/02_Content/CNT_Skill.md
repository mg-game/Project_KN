## 0. 요약
- 5계보 모두 **이미 코드 스킬이 있고 수치도 돌아간다.** 새로 만들 것은 거의 없고, D-39 슬롯 구조(기본 · 고유 · 개화)로 **다시 묶는 일**이다.
- 발견 1: **개화 2갈래 = 지금 있는 2단계 형태 2개를 그대로 쓰면 된다** (똑단이 · 찰칵이 · 몽당이 · 우두커니). 아트 · 데이터가 이미 있음 → 비용 거의 0.
- 발견 2: 시작 편성이 **방어 3 · 공격 1 · 서폿 1**로 방어 편중. 화력은 찰칵이 1명 뿐.
- 발견 3: 찰칵이(키키)는 설정집 역할(탱커 · 수호)과 코드 역할(저격 · 기절)이 다르다 (§3 #5).
- 발견 4: 잔향이 약한 판(D-40)을 넣으면 **찰칵이 잔향이 연속 소환으로 보스를 계속 기절**시킬 수 있다 (§5).

## 4. 예외 처리 / 엣지 케이스
| 케이스 | 처리 |
|---|---|
| 짝짝이 작은 친구가 잔향이 상한(12)을 채움 | **작은 친구는 상한에 안 셈** — 별도 상한 6, 넘으면 가장 오래된 것부터 흩어짐 |
| 몽당이 잔향이가 처치당해 풀림 (수명 아님) | "풀릴 때"는 수명 종료 · 처치 둘 다 발동 (현재 `OnDissolve` 정의와 같게) |
| 찰칵이 잔향이 소환 순간 적 없음 | 현재 재시도 규칙 (1.5초 · 0.25초 간격) → 없으면 소멸 |
| 우두커니 보호막 중복 (지킴이 + 잔향이) | 큰 값으로 덮어씀 · 시간은 새로 (합산 없음, 현재 규칙) |
| 똑단이 기절 + 찰칵이 기절 겹침 | 남은 시간이 긴 쪽 (합산 없음) |
