## 2. 원본 기획 항목

### 한 줄 소개
끝내 전하지 못한 편지를 품은 채, 받는 사람 이름이 번져 버린 유리병.

### 외형
- 둥근 유리병 = 몸통. 유리는 **간유리처럼 뿌옇고 불투명에 가깝게** (투명하면 바닥에 묻힘).
- 코르크 마개 = 모자 · 머리 꼭대기. 마개 아래 병 목 부분에 **얼굴 (작은 점 눈 2개 · 수줍은 입)**.
- 병 안에 둘둘 말린 편지 두루마리가 보이고, 그 아래 **작은 갇힌 빛** (불꽃 모양 X — 빛 규칙 `ART_StyleGuide` §15.1).
- 편지를 묶은 끈이 병 밖으로 나와 **팔 2개**처럼 움직임. 끈 끝에 봉랍 빨간 도장.
- 바닥은 둥글어서 **오뚝이처럼 흔들흔들** 이동. 몸에 마른 물때 줄무늬.

### 성격
- 느리고 조심스럽다. 단어를 고르다 문장을 끝내지 못한다.
- 남의 말을 잘 들어 주고, 들은 말을 소중히 기억한다.
- 자기 편지를 열어 본 적이 없다 — 무슨 내용인지 모른다.

### 원하는 것 · 필요한 것
- **원하는 것:** 편지를 원래 받을 사람에게 전하는 것.
- **필요한 것:** 받을 사람이 없어도 **자기 목소리로 말하는 것** — 편지를 열어 그 마음을 지금 곁의 누군가에게 전하기.

### 진화
- 미정 — M1.5 반영 때 설계.
- [기획 제안] 개화 방향 메모: A = "등대 병" (빛 강화, 마개가 작은 등대 지붕) / B = "편지 다발" (병 여러 개가 줄로 이어짐, 포획 대상 늘림).

### 전투
- 기본: 포획 성향 보정 그대로 (피해 ×0.85 · 기본 공격 기절 0.6초 — `SYS_InGameBattle` §G). 새 수치 없음.
- 고유 스킬 (방향만, 수치는 `CNT_Skill`): **"병에 담기"** — 가까운 망각체 1마리를 빛나는 병에 잠깐 가둬 멈춤 (보스는 짧게). **웅크린("기다림") 망각체를 담으면 바로 소멸** — 2장 기믹과 맞물림 [기획 제안].
- 빛 특성: 비 오는 판에선 약해짐 (비 효과) — 2장에선 웰리, 다른 장에선 보틀리가 빛나는 균형.

### 관계 [기획 제안]
- **키키:** "열리지 않은 것들" — 어느 문을 여는지 잊은 열쇠와 열어 보지 않은 편지. 키키가 병마개를 열어 주겠다고 계속 따라다님.
- **레이니:** 같은 골목 출신. 레이니가 기다리던 사람과 보틀리의 받는 사람이 같은 사람일지도 모른다는 떡밥 (확정 X).

### 수선점 합류
2-10 유실표 → 글자가 번져 사라지던 보틀리를 구조 → 수선점에서 처음으로 마개를 열 용기를 얻을 때까지 머물기로 함 [기획 제안].

### 교훈
전하지 못한 말은 사라지지 않는다. 지금 곁에 있는 사람에게 말하면 된다.

### 대표 대사 [기획 제안]
- "저기… 이건 꼭… 전해야 하는데…"
- "받는 사람 이름이… 비에 번져서…"
- (마개를 만지며) "아직은, 열 수 없어."

### IP 확장
진짜 편지를 넣는 메시지 병 굿즈 · 인게임 "편지 쓰기" 이벤트 · 무드등.

### 아트 제작 주의사항
- 병 = 몸 구조. **병을 들고 있는 사람 금지.**
- 유리 표현은 반투명 대신 간유리 · 굵은 외곽선 (64 px · 바닥 위 가독성).
- 병 속 빛은 갇힌 빛만 — 불꽃은 몽실 전용 (§15.1).
- 번진 사진(적, 세피아 사각)과 같은 장에 나오므로 둥근 초록 병으로 확실히 구분.
