## 2. 원본 기획 항목

### 한 줄 소개
웅덩이만 보면 일단 뛰어들고 보는, 작아져서 버려진 장화.

### 외형
- 장화 한 짝 = 몸 전체. 목 부분(입구)이 머리, 앞코 위쪽 고무에 **동그란 눈 2개 + 웃는 입**.
- 입구 안쪽 남색 안감이 머리카락처럼 살짝 뒤집혀 나옴 (실루엣 포인트).
- 발 없이 **장화 밑창으로 통통 튀어 이동** — 앞코가 진행 방향.
- 옆면 고리(당김 손잡이)가 팔 역할 1개 — 작은 손처럼 흔듦.
- 밑창 홈에 늘 물방울 · 진흙 한 점.

### 성격
- 급하고 시끄럽고 겁이 없다. 생각보다 발이 먼저.
- 기다리는 걸 못 견딘다 — 줄 서기 · 대기 시간 · 잔향이 대기 시간에 투덜댐 [기획 제안].
- 웅덩이를 지나치지 못한다. 전투 중에도 웅덩이가 있으면 일부러 밟고 감.

### 원하는 것 · 필요한 것
- **원하는 것:** 다시 그 아이와 웅덩이를 밟는 것 (과거로 돌아가기).
- **필요한 것:** 아이는 자랐다는 걸 받아들이고, 지금 길을 잃은 다른 유실자를 **먼저 찾으러 가는 것** (앞으로 걷기).
- → 2장 질문 "기다리는 것만이 관계를 지키는 방법일까?"의 **다른 답**. 레이니가 "기다림"이라면 웰리는 "찾아 나섬".

### 진화
- 미정 — `SYS_Evolution` · D-45 기준으로 M1.5 반영 때 설계.
- [기획 제안] 개화 방향 메모: A = "장대비 질주" (돌격 강화, 장화 앞코에 물보라 날개) / B = "웅덩이 수호" (밑창이 넓어져 동료를 태움).

### 전투
- 기본: 돌격 성향 보정 그대로 (피해 ×1.6 · 사거리 ×0.8 — `SYS_InGameBattle` §G). 새 수치 없음.
- 고유 스킬 (시각 · 효과 방향만, 수치는 `CNT_Skill`): **"첨벙 돌진"** — 지정 방향으로 일직선 튀어 나가며 경로의 망각체를 밀어냄. 비 오는 판에서는 물보라로 범위가 넓어짐 [기획 제안].
- 비 특성 → 2장 비 4판(D-68 #1)에서 강함 = 2장 보상이 2장에 바로 쓸모 있음.

### 관계 [기획 제안]
- **레이니:** "기다리는 우산"과 "찾으러 가는 장화" — 비 오는 날의 짝. 처음엔 서로를 답답해함 → 2장 이야기 2-8 레이니 혼잣말 박자와 연결.
- **짝짝이:** 발 친구. 짝짝이는 웰리도 가족이라 부르고, 웰리는 "나는 한 짝이 아니라 혼자 한 켤레"라고 우김.

### 수선점 합류
2-5 유실표 → 첨벙이 떼에게 쫓기던 웰리를 구조 → 수선점 앞 물웅덩이가 마음에 들어 눌러앉음 [기획 제안].

### 교훈
그리운 시간으로 돌아갈 수는 없지만, 그때 배운 용기로 지금 누군가에게 먼저 달려갈 수 있다.

### 대표 대사 [기획 제안]
- "기다리긴 뭘 기다려! 가서 찾으면 되지!"
- "…그 애, 이제 이 장화 안 맞겠지?"
- (웅덩이 앞에서) "이건 밟으라고 있는 거야."

### IP 확장
노란 장화 키링 · 우산꽂이 · 비 오는 날 이벤트 마스코트 · "웅덩이 점프" 짧은 영상.

### 아트 제작 주의사항
- 장화 = 몸 구조. **사람 다리에 장화를 신긴 모습 금지.**
- 노란 장화는 흔한 이미지 → 이상한 점(뒤집혀 나온 안감 머리 · 한 손 고리)으로 차별화.
- 첨벙이(적, 청록 물웅덩이)와 함께 나오므로 몸은 따뜻한 노랑으로 확실히 구분.
