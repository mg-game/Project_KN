## 0. 한 줄 요약
**2장 "비가 그치지 않는 골목"** — 스테이지 2-1 ~ 2-10 (코드 번호 11 ~ 20). 질문 = "기다리는 것만이 관계를 지키는 방법일까?" · 레이니(코드 `udukeoni`) 개인 이야기 · 새 기믹 1 · 새 망각체 3 · 구조 캐릭터 2 (2-5 · 2-10 유실표, D-49).

## 1. 현재 구현 (As-built) — DD 추출, 기개발 확인 필요

> 2장 전용 데이터는 **없다.** 1장 뒤 스테이지는 공식으로 이어진다. 아래는 그 공식이 2장에 내는 결과다.

### 1.1 스테이지 · 기믹 (날씨)
```
스테이지 s = 11 ~ 20 → 라벨 "2-1" ~ "2-10"                       BC GetStageModifier
2장부터: n = 1 · 5 → 없음, n = 10 → 축제,
         나머지 → modifierCycle[(index + chapter − 2) % 5]        modifierCycle = 비 · 바람 · 정전 · 먼지 폭풍 · 보름달
```

| 2장 번호 | 코드 s | 날씨 (지금) |
|---|---|---|
| 2-1 | 11 | 없음 |
| 2-2 | 12 | 비 |
| 2-3 | 13 | 바람 |
| 2-4 | 14 | 정전 |

- 비 오는 밤 효과 (코드): 적 이동 ×0.85 · 비 특성 공격 · 회복 · 보호막 +25% · 빛 특성 약화.
- → "비가 그치지 않는 골목"인데 **비는 10판 중 2판**뿐이다.

### 1.2 망각체
- 새 망각체 없음. 1장 일반 7종(`minStage` 1 ~ 8)이 **모두 그대로** 나온다. 가중치도 같다.
- 보스 = 보스 풀[(s − 1) % 2] → 2-10(s 20)은 **좀나방 여왕**. 1-10과 번갈아 같은 보스 2종 반복.
- 체력 · 공격은 스테이지 레벨 공식으로 커진다. 권장 전투력은 `PowerCalibration`이 맞춘다 (`MetaContent.Power.cs` Calibrated 상수).

### 1.3 캐릭터 · 이야기
- 2장 구조(유실표) 캐릭터 없음. 구조 시스템 자체가 P1 (컨셉 v0.3 메모).
- 동화책 2장 "비 오는 광장의 우산" (그림 `Art/Story/ch2_1~3.png` 있음) — D-53 #6으로 장소 이름만 "비가 그치지 않는 골목"으로.

### 2.3 새 기믹 — "기다림" (③ #2)
```
망각체가 쓰러지면 바로 사라지지 않고 3초 웅크린다 (반투명, 공격 대상 아님)
  IF 3초 안에 빛 특성 공격 OR 광역 피해를 받음 → 완전히 사라짐
  ELSE → 체력 40%로 다시 일어남 (1번만)
대응: 빛 특성 · 광역 스킬 · 웅크린 자리 마커
```

## 4. 예외 처리 / 엣지 케이스
- 기다림 + 분열: 분열체는 기다림 없음 (무한 부활 방지).
- 기다림 + 보스 처치 수: 웅크린 동안은 처치 수에 넣고, 다시 일어나 또 쓰러지면 더하지 않음 (보스 등장 시점 흔들림 방지).
- 기다림 + 방치(오프라인) 계산: 오프라인 보상은 시뮬레이션 결과값만 쓰므로 영향 없음 — 단 `PowerCalibration` 재실행 필수.
- 비 4판: 빛 특성(몽당이 · 찰칵이 계열) 약화가 겹침 → 2-4 · 2-9에서 막힘 여부 플레이테스트 확인.

## 5. 어뷰징 · 리스크
- 구조 캐릭터 = 확정 획득 → 소환(가챠) 가치 하락 우려 없음 (D-49 #3: 구조한 캐릭터만 소환 풀에).
- 2장 가중치 ×2가 처치 보상 단가를 바꾸지 않게 — 보상은 스테이지 기준 그대로.

## 6. 확장성 / 유지보수
- 장별 데이터 = 날씨 덮어쓰기 · 테마 망각체 가중치 · 유실표 2 · 말풍선 박자 — **이 4가지만 장마다 바뀌게** 코드를 만들면 3 ~ 7장은 데이터 추가만으로 된다.
- 망각체 id는 `enemy_` + 원물 영문 한 단어 (예: `enemy_splash`).
