## 1. 공통 규격 (`ART_BattleSpriteSpec` §2 — 일반 망각체)

| 항목 | 최종 (256) | AI 원본으로 뽑을 때 (1024, ×4) |
|---|---|---|
| 캔버스 | 256 × 256 RGBA 투명 | 1024 × 1024 RGBA 투명 |
| 내용 높이 | 190 ~ 230 | 760 ~ 920 |
| 바닥 기준선 y | **241** | **964** |
| 가로 중심 | 128 | 512 |
| 위 여백 | ≥ 10 | ≥ 40 |
| 외곽선 | ≥ 6 px | ≥ 24 px |
| 가장 작은 형태 (눈) | ≥ 14 px | ≥ 56 px |
| 얇은 부속 | 몸 폭의 30% 이하로 튀어나옴 | 같음 |
| 밝기 | 몸 평균 L ≤ 70 **또는** 밝은 몸 + 어두운 굵은 외곽 | 같음 |
| 정면성 | 정면 ~ 3/4, 진행 방향 암시 X | 같음 |

**공통 말:** 어두움 · 뾰족 = 적 / 밝음 · 둥글게 = 아군 (`SYS_InGameBattle` §12.2). 무섭기보다 **잊혀서 탁해진 물건**. 처치 땐 원래 색으로 잠깐 돌아온다(정화 연출) — 그래서 몸 안에 "원래 색"이 살짝 비쳐 보이면 좋다.

**금지:** 피 · 상처 · 해골 · 이빨 가득한 입 · 실제 사람 얼굴 · 글자 · 로고.

**참고 그림 (같이 첨부)** — 기존 적 몸 색 실측: 먼지뭉치 · 그림자 = 보라(L 62 · 66), 좀나방 · 골무 = 자주(L 117 · 79), 녹얼룩 = 적갈색(L 63). 새 3종은 **청록 · 세피아 · 철회색**으로 비켜 간다.

 `Assets/_Project/Art/Enemies/enemy_moth.png` · `enemy_wisp.png` · `enemy_rust.png` — 같은 그림체 · 외곽 두께 · 색 탁함을 맞춘다.

## 2. 그림 카드

### 2.1 첨벙이 `enemy_splash` — 빠른 떼 (2-1~)
| 항목 | 내용 |
|---|---|
| 원물 | 골목 바닥의 물웅덩이 |
| 한 줄 | 아무도 밟지 않아 고여만 있던 웅덩이가 일어나 튀어 다닌다 |
| 실루엣 | **낮고 넓은 물방울 몸 + 머리 위로 튄 물보라 가시 3개** (왕관처럼). 발 없음, 아랫단은 물결 테두리 |
| 크기 | 작은 적 — 내용 높이 **190** (하한), 폭은 넓게 |
| 색 | 탁한 빗물 **청록** (L 50 ~ 65 — 기존 적 대부분이 보라 · 자주라 겹치지 않게), 몸 안쪽에 비친 가로등 노란 점 하나 = "원래 색" |

## 3. AI 아트 프롬프트

**공통 앞부분 (세 개 모두 맨 앞에 붙임)**
```
모바일 2D 방치형 RPG의 적 캐릭터 1마리. 첨부한 적 그림 3장(좀나방·망각의 그림자·녹얼룩)과 같은 그림체·같은 외곽선 두께·같은 탁한 색감.
잊혀서 탁해진 물건이 살아난 귀엽지만 약간 으스스한 몬스터. 무섭거나 잔인하지 않게.
1024×1024 투명 배경, 정면~3/4 정면, 한 마리만, 바닥 그림자 없음.
몸 아래 끝이 위에서 964px 지점, 가로 중심 512px, 위 여백 40px 이상.
굵고 어두운 외곽선(24px 이상), 몸은 바닥보다 어둡게. 눈은 지름 56px 이상.
피·상처·해골·날카로운 이빨 입·실제 사람 얼굴·글자 금지.
```

**첨벙이**
```
[적: 첨벙이] 골목 물웅덩이가 일어난 작은 몬스터.
낮고 넓은 물방울 몸, 머리 위로 튄 물보라 가시 3개가 왕관처럼 솟음, 발 없이 아랫단은 물결 테두리.
탁하고 불투명한 빗물 청록색, 몸 안쪽에 노란 가로등 불빛 점 하나가 비침.
동그란 흰 눈 2개, 몸 표면에 동심원 물결 2~3겹.
내용 높이 760px(작은 적), 폭은 넓게. 투명한 물 표현 금지.
```

**번진 사진**
```
[적: 번진 사진] 비에 젖어 번진 낡은 사진 한 장이 살아난 몬스터.
모서리가 말리고 한쪽이 찢어진 세로 사각 사진 몸, 아래로 물방울 2~3개가 뚝뚝 떨어짐, 살짝 기울어 매달린 자세.
바랜 세피아 회색 몸에 굵은 짙은 갈색 외곽선.
사진 속 그림은 번져서 알아볼 수 없는 둥근 얼룩이고, 그 얼룩 위에 반짝이는 눈 2개만 또렷함. 실제 사람 얼굴이나 일그러진 사람 금지.
내용 높이 880px.
```

**녹슨 우산살**
```
[적: 녹슨 우산살] 부러져 버려진 우산살 다발이 살아난 몬스터.
둥근 우산 꼭지 축이 몸통, 짧고 굵게 꺾인 살 3~4개가 별 모양으로 뻗고 끝은 뾰족함, 찢어진 천 조각 하나가 매달림.
살 하나는 반대로 꺾여 혼자 우산을 펴려는 몸짓.
짙은 철회색 몸에 관절 부분에만 녹 주황 반점, 매달린 천 조각은 바랜 노랑, 꼭지 축에 날카로운 눈 2개.
살은 몸 폭의 30%를 넘게 길게 뻗지 않게, 가는 철사 금지. 내용 높이 800px.
```

## 5. 1회차 검수 결과 (2026-11-13 · DD 직접 실측, PR #84)
256 PNG를 LFS에서 내려받아 쟀다. 바닥 = L 83 보라 합성.

| 항목 | 기준 | 첨벙이 | 번진 사진 | 녹슨 우산살 |
|---|---|---|---|---|
| 캔버스 | 256 × 256 RGBA | ✅ | ✅ | ✅ |
| 내용 높이 | 190 ~ 230 | ✅ 190 | ✅ 220 | ✅ 200 |
| 바닥 · 중심 | 241 · 128 | ✅ 241 · 128.0 | ✅ 241 · 128.0 | ✅ 241 · 128.0 |
| 위 여백 · 테두리 알파 | ≥ 10 · 0 | ✅ 51 · 0 | ✅ 21 · 0 | ✅ 41 · 0 |
| 연결 성분 | 1 | ✅ | ✅ | ✅ |
| 몸 평균 밝기 | L ≤ 70 또는 굵은 어두운 외곽 | ✅ 69.9 | ✅ 67.7 | ✅ 71.1 (굵은 외곽) |
| 카드 반영 | §2 | ✅ 청록 · 물보라 왕관 · 노란 점 · 물결 | ✅ 말린 · 찢긴 사각 · 물방울 · 번진 얼룩 속 눈 | ✅ 철회색 꼭지 · 짧은 살 · 녹 반점 · 노란 천 · 거꾸로 꺾인 살 |
| 64 px · 기존 7종과 구분 | §2.4 | ✅ | ✅ | ✅ |

**판정: 3종 모두 채택.** 메모 (수정 강제 아님):
- 첨벙이: 폭 246 — 좌우 여백 5. 규격 위반은 아니나 트윈 늘림(최대 12%)에서 잘리지 않는지 Unity에서 확인.
- 번진 사진: 계획(세피아 회색)보다 짙은 갈색 — 녹얼룩과 색은 가깝지만 사각 실루엣 · 밝기 차로 64 px에서 구분됨.
- 녹슨 우산살: 64 px에서 "우산"보다 "가시 달린 공"으로 읽힘 — 천 조각을 조금 키우는 2차 수정은 P2 선택.
- 1024 원본 3장이 `Assets/` 안에 있어 Unity가 텍스처로 임포트함 — 게임에서 참조하지 않으면 무해. 정리 시 `Assets` 밖(예: `ArtSource/`)으로 옮기는 것 검토.
