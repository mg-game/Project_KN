## 1. 단계 ① 짝짝이 기본형 기준 — 유지할 것 / 바꿔도 되는 것
설정 근거: `CNT_Character_Main` 짝짝이 · `ART_Character_Brief` §1.

| 구분 | 항목 | 근거 | 시안 판정 |
|---|---|---|---|
| **유지 (정체성)** | 몸 = **양말 한 짝** 자체 (양말을 입은 생물 X) | 브리프 · 가이드 §15-3 | |
| 유지 | 얼굴 = **발꿈치 부분**에 단추눈 + 꿰맨 입 | 설정 외형 2줄 | |
| 유지 | 팔다리 = **서로 다른 색 · 무늬 양말** (짝이 안 맞음) | 설정 외형 3줄 · 이름 | |
| 유지 | **한 발 깡충** 자세 (짝이 없어서) | 브리프 행동 | |
| 유지 | 주변 **작은 양말 유령** (= 전투 작은 친구 · 상한 6) | 설정 외형 5줄 · I-10c | |
| 유지 | 색 = 크림 · 파스텔 멀티 · 보라 | 설정 대표 색 | |

## 2. 단계 ② 양말 카라반 — "양말의 어느 부분 → 어떤 구조 → 새로운 쓰임"
카라반 = **개화 B** (D-45 #6 — 기존 1단계 형태 재사용, 방어형: 수선점 피격 시 작은 친구 3).

| 칸 | 기대 (DD 초안 — 시안이 다르게 풀면 시안 쪽을 적음) | 시안에서 읽히나 |
|---|---|---|
| 양말의 어느 부분 | 양말 **목(고무단)** · 발목 통 · 발가락 주머니 | |
| → 어떤 구조 | 목을 **천막 · 덮개**로, 발목 통을 **수레 몸통**으로, 발가락 주머니를 **짐칸**으로 — 작은 양말 유령들이 끄는 행렬 | |
| → 새로운 쓰임 | 잃어버린 양말들을 **태우고 다니는 이동 가족 집** (= "모든 양말을 가족으로" 욕구의 완성형) · 방어형: 짐칸이 막아 줌 | |

| 검사 | 기준 | 판정 |
|---|---|---|
| 같은 짝짝이인가 | 발꿈치 얼굴(단추눈 · 꿰맨 입) · 짝짝이 색이 남아 있다 | |
| 진화로 보이나 | 기본형보다 **구조가 커졌다** (장식만 늘어난 것 X — 가이드 §15-8) | |
| 역할이 읽히나 | 막는 / 지키는 느낌 (방어형) — 공격형 대행진(개화 A)과 실루엣이 달라야 함 | |
| 외형(costume)과 헷갈리지 않나 | 카라반은 **진화 단계**, 외형 10종은 옷 바꾸기 (D-55) — 카라반만 몸 구조가 바뀜 | |

## 3. 단계 ③ 컨셉 카드 · 텍스트 대조
| 텍스트 | 원문 (요약) | 그림이 같은 말을 하나 |

| 한 줄 소개 | 짝을 찾는 대신 세상의 모든 양말을 가족으로 만들려는 한 짝짜리 양말 괴물 | |
| 성격 | 밝고 시끄럽고 낯을 안 가림 · 혼자 남는 걸 두려워하지만 인정 안 함 | |
| 전투 | 물량 · 교란 → 몸 주변 작은 동료 · 잔향이 기본 성향 앞장서기 (D-46 #6) | |
