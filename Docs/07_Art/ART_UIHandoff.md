## 1. 범위와 상태

사용자 지시 순서인 **홈·전투 통합 배치 → 링·예고 마커·HUD → 성향 아이콘·수선등·창문 → 편성·실패 화면 검수**에 따라 검토 묶음을 제작했다.

- 화면: 홈·전투, 편성, 실패 원인 2종, 강화 시트 위 전투 알림 4종, 승리·반복·보스·실패·연속 실패·퇴각 결과 6상태. 강화는 GR-1 목록·GR-2 성장 상세·GR-3 피드백·공명 확인까지 검토한다. 성장 시스템은 예시 수치 기반의 조작 모델이며 실제 게임 밸런스·저장·전투 구현과 구분한다.
- 신규 후보: **UI 47종의 SVG/PNG 쌍 + 768² 수선점 소등 기본 PNG 1장 = 런타임 후보 48종**. 창문 마스크 5개·단계 합성 검수 5장은 QA 자료로 수량에서 제외한다.
- 재사용: 기존 밤거리·캐릭터 5종·받침·덱 프레임 참조·탭·패널·등불·잔향·바구니를 조사했다. 실제 검토 화면에 사용하는 파일과 원본 커밋·해시는 묶음의 `reference/manifest.json`에서 추적한다.
- 새 후보는 **채팅 전달물**로 보존한다. D-24에 따라 Git/LFS에 시안 이미지를 추가하지 않는다. 저장소에는 본 기록과 기존 문서의 확정 결정 불일치 정리만 반영한다.
- **최종 채택, Unity 임포트, 실기기 적용은 미완료**다. 게임 코드·씬·프리팹·데이터·기존 에셋을 교체하지 않았고, `decisions.md`에 채택 결정을 추가하지 않는다.

제작 중 추가된 develop `755a13a`의 D-52(UI 승인·위험 우선 자동 편성·프리셋 3칸)와 D-53(ART-15 프롤로그)을 최종 전달 전에 대조했다. 기존 승인 상태·신규 항목을 보존하며, ART-15는 본 UI 후보 제작 범위 밖이다.

## 2. 화면 배치 검토

### 2.1 홈·전투

- 상단 메타 바와 전투 HUD를 분리하고 스테이지·타이머·Wave·보스/남은 적 상태를 표시한다.
- 전장 전체, 작은 중앙 수선점, 지킴이 5명, 8방위·빈 방향, 위험 방위, 지속 압박을 함께 보인다. 지킴이 체력바는 넣지 않는다.
- 잔향 줄 오른쪽에 수선등, 그 아래 덱 6칸 1열, 하단 탭 **강화·편성·유실자·사냥·원정·소환·상점** 7칸을 배치한다(D-44).
- 기존 문서의 11% 전장 시작선보다 이 후보의 상단 정보 영역이 넓다. 기준 화면은 상단 약 13%, 전장 하단 64%, 잔향/퀘스트~71%, 덱~80%, 하단 탭~100%다. **검토용 미세 조정이며 승인된 비율의 새 정본이 아니다.** 최종 배치는 Unity 안전 영역·최소 글자 크기 검수와 함께 조정한다.
- 알림은 시트 위에 별도 칩으로 표시하며 누르면 홈으로 복귀한다. 보스·위기·클리어·실패 4상태를 비교한다.
- 일반·예고·보스·최후의 쇄도·내구 위기·잔향 부족·소환 상한·튜토리얼 잠금과 카드 재사용 대기의 9가지 표시 상태를 검토한다.
- 브라우저의 탭·소환·강화 반응은 **상태 비교용 단순화 모델**이다. 전투 판정·시간·AUTO·배속·자원 수급의 실제 시스템 구현이 아니다. 옆 탭 전체 기능을 새로 구현한 것으로 표시하지 않는다.

### 2.2 편성·실패

- 편성: 8슬롯·지킴이 5명·빈 방위 빗금·위험 우선 배치·프리셋 3칸·파견 중 배지를 비교한다. 프리셋은 탭으로 불러오고 길게 눌러 현재 배치를 저장하는 검토 동작을 제공한다(D-52). 슬롯 이동/맞바꿈 후 빈 방향 표시가 함께 갱신된다. 클릭 선택 후 방향 선택과 마우스 드래그를 제공하며, 모바일 드래그 감각은 Unity 검수 대상이다.
- 방위는 색에 더해 글자와 점 개수를 병행한다. 경고는 삼각형·빗금, 지속 압박은 줄무늬로 구분한다.
- 실패: 방어 문제/화력 부족의 원인·권장 행동과 **재도전·편성 변경·강해지기** 3개 CTA를 비교한다. 원인 변경은 검토 도구 바깥 조작으로 하고 실제 리포트에 원인 선택 버튼을 넣지 않는다.
- 화면 외부에 검토용·수치 예시·기준 결정·실제 게임 아님을 표기한다. 내부의 장식 문구·설명은 카피 제안이며 설정·스킬·획득 조건을 추가하지 않는다.

### 3.1 수선점 단계 점등 — 2차 정합 출력

기존 `Battle/shop.png`의 창문 불빛이 본체에 그려져 있어, 이미지 생성 도구로 소등 기본 마스터를 별도 제작·보정했다. 기존 게임 PNG와 1차 전달 묶음은 보존했다.

- 마스터: `concepts/shop_dark_refined_master.png`, **1254×1254 RGBA**. 이미지 생성 도구로 작화 보정 후 비율·캔버스를 유지한 Lanczos3 출력으로 `lighting/shop_dark_base.png` **768×768 RGBA**를 만들었다. 기존 `shop.png`와 픽셀 단위로 동일한 건물은 아니며 교체 채택은 별도다.
- 단계 레이어: `candidates/shop_light_1~5.png`와 SVG, **모두 768×768**. 기본·레이어의 캔버스와 중심 `(0.5, 0.5)`가 동일하다.
- 유리 마스크: `lighting/masks/window_1~5.png`. 각 창의 제한된 영역에서 인디고 유리를 분리해 **갈색 창틀·금속 장식·꽃을 직접 덮지 않는 마스크**를 만들었다. 좌표·색 조건은 이 마스터 전용이며 다른 건물에 그대로 적용하는 범용 추출기가 아니다.
- 단계 순서: 정문 창 → 왼쪽 아래 → 오른쪽 아래 → 왼쪽 위 → 중앙 큰 창. 작은 오른쪽 중간 창은 소등으로 유지한다.
- **합성은 일반 알파, 레이어는 단계당 하나만 사용한다.** Lv.3이면 기본 + `shop_light_3`이며, 1·2·3 레이어를 함께 쌓지 않는다. `lighting/previews/shop_lit_1~5.png`는 같은 입력의 합성 검수본이다.
- `lighting/registration.json`에 창 좌표·마스크 경로·픽셀 수·중심을 기록했다. `refine-delivery.cjs`가 768² 출력·VFX 생성·등록 정보·전달 명세를 재현한다.

2차 검수에서 점등 유리의 sRGB 가중 밝기 증가는 창별 약 **+137~146/255**였다. 아직 켜지지 않은 창은 밝기 변화가 0이며, 레이어 알파가 0인 영역은 합성 전후 최대 1/255 차이 이내다. 이는 출력·합성 정합 검증이며 최종 작화 채택이나 Unity 색공간 검증을 의미하지 않는다.

### 4.1 3차 가독성·조작 검토

기존 48종 런타임 PNG와 1·2차 ZIP은 보존하고, 브라우저 검토본의 조작 흐름을 보완했다. 게임 코드·입력 시스템을 적용한 것으로 표시하지 않는다.

- **홈 가독성:** HUD·잔향·수선등 문구를 키우고 하단 퀘스트/잔향/덱 영역을 다시 배치했다. 비용 부족·상한·잠금·쿨다운을 구분하며, 지킴이 초상의 예시 원형 쿨다운과 위치 하이라이트를 표시한다.
- **소환:** 0.2초 홀드 뒤 8방위 부채꼴을 보여 주며, 유효한 전장에 놓을 때 비용을 한 번 차감한다. 덱/전장 밖 놓기, Pointer Cancel, Lost Pointer Capture, Escape는 비용 없이 취소한다. 탭·키보드 Enter도 단일 소환으로 처리한다. 시각 피드백은 수선점에서 시작하며 줄이기 모드에서는 이동 효과를 생략한다.
- **일시정지 BT-002:** 스테이지·웨이브·남은 시간 요약, 배속·자동 소환·수선등 자동 투자, 계속·도움말·퇴각 확인을 연결했다. 배경은 inert 처리하고 Tab을 대화창 안에 유지한다. 복귀 시 일시정지 버튼으로 포커스를 돌린다.
- **도움말·퇴각:** 탭/홀드/되돌려 취소와 성향 아이콘 3종을 보여 준다. 퇴각은 확인 2단계이며 dim 클릭으로 닫히지 않는다. 취소하면 일시정지로 돌아가고 확정하면 `퇴각` 원인 리포트로 이동한다.
- **편성:** 배치된 슬롯은 브라우저 터치 Pointer Events로 이동/맞바꿈, 길게 눌러 해제, 목록 선택 후 빈 방향에 재배치할 수 있다. 목록의 가로 스크롤·탭 선택과 기존 마우스 드래그를 유지한다. 해제 홀드 0.6초는 검토본 튜닝값이며 새 밸런스 확정이 아니다.
- **입력 범위:** 390px 논리 참조에서 핵심 전투 조작부의 44×44 이상 크기, 두 비율의 하단 영역 겹침 없음, 대화창 조작부 경계를 검수했다. 이는 물리 단말의 터치·접근성 인증이 아니다.

마우스 탭·4방위 홀드/드롭·취소·CDP 터치 취소·카드 쿨다운·대화창 포커스/배경 차단·별도 AUTO 설정·도움말·퇴각·터치 편성·390px 터치 뷰포트를 검사했다. 조준은 이 검토본에서 **수선점 중심 기준 전장 좌표**로 판정하며, 실제 게임의 짧은 드래그 감도·확정 영역은 Unity 구현과 대조해야 한다.

실제 시간 경과·일시정지 중 수급/타이머 동결·위협도 기반 자동 방향·실제 소환/성장/전투 판정은 구현하지 않았다. 현재 AUTO의 일부 켜짐 표시와 문구도 UI 검토 제안이며 새 결정 기록을 추가하지 않는다.

### 4.2 강화·성장 아트 UI

`UI_Growth` D-43의 GR-1/GR-2/GR-3과 `UI_Home` D-44의 시트 구조를 사용한다. D-29·D-45의 한계 돌파·기억 각성 P1 범위는 추가하지 않고, M1 레벨 1~100의 최대 상태를 검토한다.

- **GR-1:** 고정 단추/기억 조각 표시, 수선점 전후 수급·내구 및 10레벨 보상 예고, ×1/×10/최대 구매, 추천 줄, 유실자 2열 카드. 역할·예시 편성 위치·공명 가능 금 점·부족/잠금/최대 상태를 구분한다. 카드 순서는 레벨업 중 유지한다.
- **GR-2:** 초상·이름·공유 레벨, 공격력·체력 전후와 증가값, ×1/×10, 공명 전후의 공용 능력치·소환 비용·지속 시간. 레벨은 지킴이/잔향이 공통 한 축이며 별도 육성 탭·전투 반영 화면을 만들지 않는다.
- **공명 확인:** 효과와 기억 조각 비용을 확인한 뒤에만 차감한다. 취소·Escape는 보존하고 중복 확인 클릭은 1회만 처리한다. 부족·공명 최대는 소비를 차단하고 소환 비용은 예시 계산에서 3 미만으로 내려가지 않는다.
- **GR-3:** 레벨업/공명의 짧은 칩을 사용한다. 연속 구매 피드백은 합산하며, 수선점 10레벨 보상은 우편 예고 문구만 표시한다. 실제 우편 지급을 수행하지 않는다.
- **입력:** 0.45초 홀드 후 반복 구매, 스크롤·포인터 취소·뷰 변경·구매 불가 시 중지. ×10은 살 수 있는 수로 축소하고 수선점 최대 구매는 2레벨 이상 살 수 있을 때 켠다. 추천 줄은 카드로 스크롤하고 강조한다.
- **리소스:** 기존 런타임 PNG 후보 48종은 보존했다. PR #2 `4b73a5a`의 단추·기억 조각·공명·역할 아이콘 9개를 참조용으로 추가 수신했다. `reference/manifest.json` 총 43개에 경로·커밋·해시를 기록하며 신규 채택 에셋으로 집계하지 않는다.

검토용 수치·비용 반올림·공명 비용·능력치·전투력 증가는 `GrowthUIReviewSpec.json`의 예시 모델이다. 편성 배지도 성장 화면 전용 예시이며 실제 게임 편성·전투력·경제 모델을 대체하지 않는다. 실제 방치 수급·세이브·공명 트랜잭션 서버·우편·효과음·Unity 연결은 수행하지 않았다.

공유 레벨·비용 1회 차감·카드 순서·×10 부분 구매·부족/잠금/최대·미편성 성장·공명 확인/취소/중복 차감 방지·소환 비용 하한·홀드/스크롤 중지·수선점 보상 예고·두 비율의 스크롤/확인창·390px 터치 입력을 검사했다. 기존 전투·편성·일시정지 검사도 통과했다.

### 4.3 전투 결과·보상 아트 UI

`UI_Battle` §3과 `SYS_InGameBattle` §17 K의 D-28 자동 진행·반복·실패 후 후퇴 규칙을 기준으로 제작했다. `UI_InGame` RS-001의 범용 정보 순서는 참고하되 현재 M1 근거가 없는 별 평가·신규 구조·챕터 보상 화면은 추가하지 않았다.

- **승리:** 스테이지·클리어 문구, 단추/별빛 사탕, 재료 드롭 유무, 편성된 계보 호감도 +1, 다음 구역 안내를 같은 화면에 배치한다. 단추 86·사탕 3의 일반 승리, 단추 180·사탕 10의 10스테이지 승리, 자동 진행 OFF의 같은 구역 반복을 비교한다.
- **실패:** 처치 진행도 60%의 예시에서 `floor(86 × 0.3 × 0.6) = 15` 단추를 보존한다. 첫 실패는 같은 구역, 연속 2회 실패는 한 구역 이전으로 안내하며 편성·강화로 연결한다. 퇴각은 부분 보상이 미정이므로 0 또는 지급 수치를 제시하지 않고 기존 퇴각 리포트로 연결한다.
- **보상:** 보상은 자동 정산 표시이며 별도 수령 버튼을 만들지 않는다. 로컬 결과 이벤트마다 표시용 명세를 1회 만들고 상세 열기·비율 변경·재렌더로 재정산하지 않는다. 실제 지갑·세이브·아이템·성장 수치는 변경하지 않는다. 단추 보너스 0%, 이벤트 배율 1배, 재료 드롭과 호감도 초상 5종은 고정 예시이며 실제 난수·인벤토리 결과가 아니다.
- **자동 이동:** 기본 대기 1.5초는 배속과 무관한 실제 시간이다. 자세히 보기/보상 아이콘을 누르면 결과 발생 시점부터 최대 6초까지 확인하며 반복 클릭으로 연장 시점을 갱신하지 않는다. 즉시 이동은 한 번만 처리하고 다른 화면으로 나가면 예약을 해제한다. 비교용 브라우저는 화면 외부의 재생 옵션을 켜기 전까지 정지한다.
- **연결과 입력:** 강화 시트 위 클리어·실패 알림에서 결과로 진입한다. 결과의 배경 소환·수선등 조작부는 inert 처리하고 키보드 포커스는 결과 조작부 안에서 순환한다. 상세 영역만 스크롤하고 다음 전투/회복 CTA는 하단에 유지한다. 보스·위기 알림은 기존 전투 복귀 동작을 유지한다.
- **리소스:** 기존 48종 PNG 후보를 보존하고 PR #2의 별빛 사탕 아이콘 `currency_gem.png` 1개를 참조용으로 추가했다. 원본 참조는 총 44개이며 원본 경로·커밋·해시를 기록했다.

보상 5상태의 계산·목적지·표시 명세 단일 생성, 중복 이동 방지, 퇴각 미정 표시, 실패 회복 CTA, 전투 알림 연결, 배경 차단/포커스, 6상태×2비율의 44px 논리 조작부·상세 스크롤, 390px 브라우저 터치, 실제 1.5초 이동·6초 연장 상한·화면 이탈 취소를 검사했다. 기존 화면·소환·편성·일시정지·성장 검사는 회귀 통과했다.

보상 연출 탭 단축·실제 전투 결과 정산·스테이지 이동·자동 보스 도전 분기·게임 인벤토리 연결·Unity TMP/안전 영역/실기기는 미적용이다. 본 결과 화면은 기획 정본을 수정하거나 게임 개발 보류를 해제한 것이 아니다.
