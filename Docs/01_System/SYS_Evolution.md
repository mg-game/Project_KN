## 0. 요약
- 지금 코드의 진화 = **"기본형 + 갈래 형태 제작"** (재료 + 조건을 채우면 확정 제작, 이전 형태도 계속 사용). 랜덤 없음.
- 핵심 제안 3개
  1. **기억형은 새 그림이 아니라 "기억 각성"** — 같은 그림 + 기억 장식 1겹 + 고유 스킬 강화. 해금 = **첫 한계 돌파(Lv.20)** 보상 (D-29 #3과 한 시스템으로 묶음)
  2. **개화 A/B = 지금 있는 1단계 형태 2개** (D-43 #1) — 레시피 · 아트 · 스킬 재사용, 둘 다 제작 가능(배타 아님)
  3. **짝짝이**: 개화 A = 천 짝의 대행진(신규) · 개화 B = 양말 카라반(기존), 나머지 직업 9종 = 외형변경
- **새로 그릴 아트: 기억 장식 7 + 짝짝이 개화 A 1 = 8장** (나머지 전부 재사용)
- M1: **현재 구현 그대로** (진화 기능은 1-10 클리어에 열려 M1에선 거의 안 보임). 3단 · 기억 각성은 P1.

## 1. 현재 구현 (요약)
```
형태 상태 GetState(form)                                         # EvolutionSystem:64
  기본형 OR 제작 완료                 → 해금
  부모 형태 해금 AND 계보 레벨 ≥ clueLevel → 단서 발견 (레시피가 보임)
  그 외 (미보유 계보 포함)             → 미발견
제작 TryCraft(form)                                               # :126
  IF 진화 기능 잠김 (FeatureId.Evolution = 1-10 클리어 전) → 거절
  IF 단서 발견 AND 재료 충족 AND 조건 충족 → 재료 소모 · 형태 해금 (확정, 랜덤 없음)
  이전 형태도 그대로 사용 가능 — 어느 형태로 편성할지 고름 (배타 아님)
기억편(= 기억 조각) 사용                                            # :147-230
  대체: 희귀 재료 1개 = 기억편 N (일반 재료는 대체 불가) — 그 레시피 전용 기록
  가속: 조건 남은 양을 기억편으로 채움 — 원정 · 잔향이 출격 · 지킴이 처치만 (레벨 · 스테이지 · 던전은 직접)
조건 종류 ProgressType: 원정 N회 · 잔향이 출격 N회 · 계보 레벨 N · 스테이지 N · 던전 N층 · 지킴이 처치 N
```

## 2. 기획 방향 (To-be) — DD

### 2.0 3단 구조
| 단계 | 정체 | 해금 | 바뀌는 것 | 그림 |
|---|---|---|---|---|
| **유실형** | 처음 만난 모습 (기본형) | 획득 | — | 기본 (있음) |
| **기억형** | 잃어버린 기억 일부를 되찾은 모습 = **기억 각성** | **첫 한계 돌파 (Lv.20 상한)** 보상 | 고유 스킬 강화 1개 (`CNT_Skill` §2.0) · 기억 장식 · 상한 40 | **같은 그림 + 기억 장식 1겹** 🆕 |
| **개화형 A / B** | 기억을 딛고 새로 피어난 모습 (2갈래) | 기억형 + **단서 Lv.40** + 레시피(재료 + 조건) 제작 | 개화 스킬 (갈래마다 다름) · 세부 성향이 바뀔 수 있음 · 새 그림 | **지금 1단계 형태 재사용** |

- 개화 A · B는 **둘 다 제작 가능**, 편성 때 어느 모습으로 낼지 고른다 (현재 구현 그대로 — 수집형에서 "잘못 고른 후회"를 없앰).
- 개화 후에도 유실형 · 기억형 모습으로 편성 가능 (외형 취향) — 능력치는 **계보 레벨 공유**라 차이 없음, 스킬만 다름.

### 2.1 규칙
```
[기억 각성] (P1, 한계 돌파와 같은 버튼)
IF 계보 레벨 = 20 (상한) AND 돌파 비용 충족 (단추 · 수선 재료 · 기억 조각, SYS_Growth §2.4 Breakthrough_Config cap=20)
  → 상한 20 → 40 · 기억형 해금 (연출: 기억 조각이 모여 장식이 생김) · 고유 스킬 기억형 값으로
ELSE → 조건마다 획득처

[개화 단서]
IF 기억형 해금 AND 계보 레벨 ≥ 40 → 개화 A · B 레시피 보임 (단서 발견)

[개화 제작] = 현재 TryCraft 그대로
IF 진화 기능 열림 AND 단서 발견 AND 재료 충족 AND 조건 충족 → 형태 해금
  재료 대체(기억 조각) · 조건 가속(기억 조각) = 현재 규칙 유지

[편성 모습 고르기]
계보 카드 → 모습: 유실 · 기억 · 개화 A · 개화 B (해금된 것만) → 고른 모습의 스킬 · 세부 성향으로 출전
  지킴이 · 잔향이 각각 다른 모습 가능 (현재 형태 단위 편성 그대로)
```

### 2.2 상태 전이
```
[유실형 Lv.1~20] ─(한계 돌파 20)→ [기억형 상한 40] ─(Lv.40)→ [개화 단서]
                                                         ├─(레시피 제작)→ [개화 A 해금]
                                                         └─(레시피 제작)→ [개화 B 해금]
편성 모습: 해금된 모습 중 자유 선택 (언제든 바꿈)
```

| 기억 조각 결제 상품으로 진화 단축 | 대체는 희귀 재료만 · 조건 가속은 원정 · 출격 · 처치만 (레벨 · 스테이지는 직접) — 현재 규칙이 이미 막음 |
| 조건 "잔향이 출격 N회" 반복 소환 파밍 | 전투 1판 소환 상한 · 칸 대기로 상한 있음 → 허용 (플레이를 시키는 조건) |

## 6. 확장성 · 유지보수
- 새 계보 = 유실형 1 + 기억 장식 1 + 개화 2 = **그림 3장 + 장식 1** 고정 → 아트 일정 예측 가능
- 개화 3갈래가 필요하면 `Evolution_Stage.stage`에 `BloomC`만 추가
- 기억형이 형태를 새로 만들지 않아 **세이브 키 · 편성 데이터 변경 없음** (`memoryAwakened` bool 1개)

> 💡 **조합 제안 (P1 검토용)** — 수집형 "개화 갈래" × 서사 "구조 · 관계"(K-08)
> 개화 A · B 단서를 레벨만으로 여는 대신, **구조 이야기에서 고른 대사**가 갈래마다 단서 하나씩을 연다 (예: 키키에게 "모든 문을 열 필요는 없어" → 자물쇠 기사 단서). 갈래 선택이 숫자가 아니라 "그 아이와 나눈 이야기"가 되어 최애 축(P5)을 강화. 레벨 40 단서는 그대로 두고 **대사 단서 = 재료 −20% 보너스** 정도로 가볍게.
