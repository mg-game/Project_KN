# 1. 디자인 필라

모든 시스템 결정은 아래 6개 필라로 검증한다. 필라에 기여하지 못하는 기능은 채택하지 않는다.

| # | 필라 | 정의 |
|---|---|---|
| P1 | 짧지만 판단은 계속 | 세션은 짧아도 작은 의사결정이 끊이지 않는다 |
| P2 | 전황 가독성 | 물량전이어도 지금 무슨 일이 벌어지는지 한눈에 읽힌다 |
| P3 | 희귀도 ≠ 서열 | 희귀도는 역할과 사용 난도의 차이. 저희귀도 최애로 끝까지 갈 수 있다 |
| P4 | 엉뚱한 매력 + 예상 밖 진화 | 무섭지 않은 이상함. "쟤 왜 저래ㅋㅋ 근데 귀엽네" |
| P5 | 최애 축 & 확산 축 | 애정(깊이)과 밈/공유(확산)를 의도적으로 분리 설계 |
| P6 | 혼자 자기 속도로 | 경쟁 압박·시간 강제 없음. 내 페이스의 싱글 경험 |

# 2. 전투 컨셉 개요

## 2.1 한 줄 정의 ✅

> **움직이는 수선점이 로스트 타운을 날아가며, 매 지역에 뿌리내리고 밀려오는 망각체로부터 스스로를 지켜내는 360° 수성전.**

## 2.2 코어 = 움직이는 수선점 ✅

- 전투 화면 중앙의 코어 오브젝트 = **수선점 본체** (분신·대체물 없음)
- 수선점은 살아있는 건물로, 스테이지/챕터 진행 = 수선점이 직접 다음 지역으로 이동
- 서사 문장: *"집이 아이들을 데리러 간다"* — 지키는 것과 전진하는 것이 한 몸
- 소환 문법: 지킴이와 잔향이는 **집(수선점)에서 나온다** — 별도 설명 레이어 불필요
- 애착 설계: 지키는 대상은 게임 전체에서 **항상 단 하나** — 시설 성장·꾸미기가 전투 화면에 상시 노출되어 "진행할수록 예뻐지는 코어"를 구현 (냥코 대전쟁의 기지 문법 + 성장 비주얼 확장)

### 파생: 컨셉 문서 v0.3 개정 항목 ✅
- 컨셉 3.5 기억 수선등: 전투 코어 역할 삭제 → 파견(수선 의뢰) 휴대등 + 지역 기억등 복구 의식의 매개 소품으로 역할 축소 (컨셉 문서 반영 완료)
- 마지막 매듭 로어 패치: 매듭은 수선점이 어디에 있든 그 지하에 함께 있다 (수선점 = 매듭을 품고 다니는 그릇)
- 앞마당 방어전(이벤트 모드) → "망각의 대공세" 등 이동 불가 농성전 상황으로 차별화 재정의

## 2.3 전투 모드 구분 ✅

| 모드 | 내용 | 비고 |
|---|---|---|
| 메인 스테이지 (온라인 수동) | 지역별 방어전, 스테이지형 진행 | 도전·고효율 |
| 방치 파밍 (오프라인 자동) | 클리어한 최고 스테이지 안전 순회 | 저효율, 패배 없음 |
| 무한 모드 (별도 콘텐츠) | 도달 웨이브 기록 갱신. **랭킹 없음** — 개인 최고 기록 + 구간 보상 (P6) | 주간 리셋 |
| 구조 전투 (캐릭터 획득) | 메인 전투 규격 + 보호 대상 1체 추가 변형 | 유실표 연계, 상세 별도 |
| 이벤트 방어전 | 망각의 대공세 (농성전) | 시즌 운영 |

# 3. 전장 규격

## 3.1 화면·전장 기하

- ✅ 세로 고정 (Portrait Lock), 가로 모드 미지원. 한 손 엄지 조작 기준
- ✅ 완전 자유 360° 전장, 수선점 중앙 배치 (플레이필드 = UI 제외 영역 기준 중심)
- ✅ 행진(라인 전진) 없음 — 코어 보전형 수성전
- ✅ 카메라 고정 (줌/스크롤 없음). 기종별 화면비는 상하 배경 여백으로 흡수, 플레이필드 규격 고정
- 🔶 전장 형태 = **정원(circle)** (세로 타원안 폐기 제안): 방위별 도달 거리 균일화로 `sector_speed_mod` 보정 불필요. 상하 잔여 공간 = 지역 배경 연출(챕터별 풍경 변화)
- ✅ 결계 링 시각화: 수선점의 빛이 만드는 원형 결계 링 = 아군 진영 경계 (P2의 핵심 장치)

## 3.2 섹터 구조 ✅

- 내부 로직: 전장을 8섹터로 분할 (유저 비노출)
- 용도: 적 스폰 패턴 지정, 위협도 계산, 소환 자동 배치, 유실자 방위 배치 매핑
- 남측(하단) 정면 스폰 억제 — 하단 UI 간섭 회피 (남측 스폰은 남동/남서 대각으로 대체)
- 🔶 보스 진입 방위: 기본 북측 (상단 연출 공간 활용)

# 4. 유닛 시스템 — 2계층 × 단일 캐릭터 풀

## 4.1 구조 원칙 ✅

- 캐릭터(유실자)는 **단일 풀**이며, 편성 슬롯에 따라 두 모드로 운용된다.

| | 지킴이 모드 (배치 5인) | 잔향이 모드 (소환 덱) |
|---|---|---|
| 정체 | 본체 — 살아있는 동료 | 잔향으로 만든 분신 (에코) |
| 전용 스킬/패시브 | 있음 | 없음 |
| 소멸 | 사망 없음: 전투불능 → 부활 타이머 → 복귀 | 소모성: HP 0 또는 지속시간 만료 → "잔향이 흩어짐" (귀환 연출, 죽음 아님) |
| 담당 필라 | 최애 축 (P5), 수집·개별 성장 | 확산 축 (P5), 물량·눈의 즐거움 |

- ✅ 배타 원칙: 동일 캐릭터의 지킴이 배치 + 소환 덱 동시 등록 불가. 파견(수선 의뢰) 중인 캐릭터는 양쪽 모두 사용 불가
- ✅ 성장 공유: 레벨·진화는 Character_Base 단일 축 — 한 번 육성하면 양 모드에 반영 (육성 이원화 금지)
- ⬜ 공명 해금 (진화 완성 보상으로 배타 원칙 예외 허용): 소프트런칭 이후 검토 항목

## 4.2 지킴이 포지션 ✅

- 공격(Dealer): 처치 속도 = 보상 효율 담당
- 방어(Tanker): 코어 피해 흡수·차단 담당 (어그로 독점)
- 서폿(Support): CC·버프 담당 (CC는 서폿 독점 권장)
- 포지션별 요격 범위 차등: 공격형 = 좁고 김 / 방어형 = 넓고 짧음 / 서폿 = 배치 중심 오라 🔶

## 4.3 성격과 행동 성향 ✅

두 층으로 분리한다. **성격 = 불변(정체성)** / **행동 성향 = 기본 1종 + 성장 해금 1종**.

### 성격 (Personality)
- 캐릭터 고유 행동 특성, 변경 불가 — P4(엉뚱함)를 움직임으로 표현하는 지점
- 예: 겁쟁이(적 많으면 후퇴 후 복귀, 공속↑) / 맹함(제일 큰 적만 추적) / 잠꾸러기(가끔 졸다가 폭딜 기상)
- Personality_Master 테이블로 모듈화 — 신규 캐릭터는 모듈 조합으로 생산 (데이터 주도, 코드 수정 없이 확장)
- ⬜ 성격 간 케미(조합 상호작용): 3~4쌍 초기 탑재 검토

### 행동 성향 (Behavior) — 컨셉 문서 6.4 대응 ✅
| 성향 | 컨셉 명칭 | 시스템 동작 | Duration | 비용 |
|---|---|---|---|---|
| 돌격형 | 앞장서기 | 지정 방향 적에게 돌진, 긴급 대응 소모품 | 짧다 (15~25s) | 저 |
| 순회형 | 함께 걷기 | 결계 궤도 순회 요격, 전방위 보험 | 중간 (30~45s) | 중 |
| 고정형 | 곁 지키기 | 지정 섹터 궤도 슬롯 정착, 사전 투자재 | 길다 (60~90s) | 중~고 |

- 성향 변경: 편성 화면에서만 선택. **전투 중 변경 불가**
- 제2성향 해금 = 진화 마일스톤 보상 (일부 캐릭터) — "예상 밖 진화"(P4)의 게임플레이 버전이자 컨셉 문서 6.5 성향 성장(대사 해금)과 연동
- 희귀도 연결 (P3): 저희귀도 = 단순 성격 + 성향 1종 (쉬움) / 고희귀도 = 강한 성격(변칙) + 성향 확장 (어려움)

## 4.4 배치 반경 ✅
- 내선(코어 밀착) / 외선(바깥 궤도)은 **캐릭터 고유 속성** — 전투 중 선택 없음 (조작 과부하 방지, 반경 판단은 편성 단계로 이동)

# 5. 소환 시스템 (잔향이)

## 5.1 소환 은유 ✅
- 소환 = 생산이 아니라 **안정화**: 유실자가 자신의 잔향을 불어넣고, 수선점의 빛이 형태를 잡아준다
- 연출: 코어 곁 빛무리에서 형태가 "잡히는" 등장 / 만료 시 빛으로 돌아가는 귀환
- 스폰 지점: 항상 수선점 (탄생 지점 단일화 — P2)

## 5.2 소환 입력 ✅

```
├─ 탭 (≤0.2s) → 즉시 소환 + 자동 배치 (위협도 최고 섹터)
├─ 홀드 (>0.2s) → 조준 모드
│   ├─ 드래그: 부채꼴 프리뷰 표시 (배치 섹터 하이라이트)
│   ├─ 릴리즈: 지정 섹터 소환
│   └─ 버튼 위치로 복귀 릴리즈: 취소 (재화 미소모)
└─ 재화 부족: 버튼 비활성 + 부족분 표시
```

- 홀드 임계 0.2s는 튜닝 파라미터 (소프트런칭 오입력률 기준 조정)
- 드래그 감도: 화면 이동량이 아닌 **방향 벡터** 기준 (짧게 끌어도 방향만 맞으면 원거리 방위 지정 가능)
- 자동 배치 위협도 = 섹터별 (적 수 × 적 강도 × 코어 근접도) 가중합 ⬜ 산식 상세 미결
- 튜토리얼: 탭만 교육, 조준은 진행 중 팁 노출 (학습 계단)

## 5.3 지속시간제 ✅
- 소환 시 Duration 타이머 부여 (캐릭터별 고유값, §4.3 성향 프로파일 기준)
- 소멸 조건 (OR): HP ≤ 0 / Duration 만료
- 만료 예고: 발밑 게이지 금지 (P2) — 만료 3초 전 깜빡임만
- 만료 후: 덱 슬롯 쿨다운 → 재소환 가능

## 5.4 소환 상한 ✅
- 동시 존재 상한 규격화 (초기값 20체, Stage_Battle_Config) — 가독성(P2)·Unity 성능(오브젝트 풀링) 양면 근거
- 상한 도달 시: 소환 버튼 비활성 + "가장 먼저 흩어질 유닛의 잔여 시간" 표시 (대기 판단 재료)

# 6. 지킴이 배치 시스템 🔶 (설계 완료, 승인 대기)

## 6.1 8방위 링 배치
- 편성/배치 화면에서 유실자를 드래그 → 코어 주위 **8방위 슬롯에 스냅** 배치
- 내부 처리: 방위 슬롯 → 담당 섹터(호 범위) 자동 매핑 (섹터 비노출 원칙과 양립)
- 배치 화면에 스테이지 위험 방위 표시 (스폰 집중 + 지속 압박 섹터 마커) → 정보 기반 판단 (P1)
- 요격 부채꼴 프리뷰 표시 → 5인으로 360°가 덮이지 않음을 시각화 ("어디를 비울 것인가"가 배치 판단의 본질, 파견 공백도 동일 UI로 표현)
- 배치 저장: 스테이지별 마지막 배치 기억 + 추천 배치 버튼 (P6)
- 최소 1인 배치로 입장 가능 (5인 미만 허용 — 초반 로스터 대응)

## 6.2 요격 규칙
- 유실자는 배치 방위 중심 부채꼴을 담당, 범위 내 자동 교전
- 교전 우선순위: 코어 근접 > 공성형 > 고위협
- 범위 밖 원칙적 무시. 단, **코어 인접 링 진입 적은 전원 공유 어그로** (최후 방어선의 드라마 보장)

## 6.3 재집결 (Rally) — 전투 중 재배치
- 하단 버튼 1개 → 방위 링 오버레이 → 드래그 재배치 → 확정 시 전원 동시 이동
- 쿨다운제 (초기 60s), 재화 비용 없음 (인게임 경제 판단 오염 방지 — 시간 자원으로 분리)
- 이동 중 교전 불가 (피격은 가능) — 공백을 감수하는 리스크 판단 (P1)
- 미조작 무방 (캐주얼은 몰라도 되는 심화 기능, P6) / 오프라인 자동 모드 미사용

## 6.4 부활 규칙 ✅
- 전투불능 → 부활 타이머 → 수선점에서 재등장 후 배치 방위로 걸어서 복귀
- 부재 중: 담당 방위 공백 + 해당 캐릭터 전용 시너지 정지 (⬜ 정지 범위 상세 미결 — 버프만인지 전용 잔향이 소환 금지까지인지)

# 7. 인게임 경제 — 잔향

## 7.1 수급 3원 구조 ✅

```
├─ ① 기본 수급: 초당 +r (자동, 바닥 보장 — P6 안전망)
├─ ② 수선등 밝히기: 전투 중 잔향으로 수급 레벨 구매 (예: 5단계, 스테이지 리셋)
│    └─ P1 핵심 판단: "지금 소환해 급한 불 끄기 vs 수급 투자로 미래 대비"
└─ ③ 정화 드랍: 망각체 처치 시 소량 (총 수입의 ~20%, 성과 즉각 피드백)
```

- 의도된 리듬: 초반 = 투자 타이밍 → 중반 = 수급 완성 경쟁 → 후반/보스 = 풀가동 물량 절정 (눈의 즐거움 피크를 후반 배치)
- ✅ 잔향은 인게임 전용, 세션 종료 시 소멸. 아웃게임 반출 절대 금지 (파밍 어뷰징 벡터 차단)
- ✅ 일시정지 중 수급·타이머 동시 동결 (정지 방치 어뷰징 차단)
- ✅ 아웃게임 영구 강화(§8)와 층 분리: 아웃게임 = 시작 베이스 / 인게임 밝히기 = 세션 내 성장 (냥코의 지갑 이중 구조 문법)

- 효과: 골드 싱크 확장 + 가챠 운 비의존 안정 성장축 (P3 정신)

# 9. 스테이지·웨이브 진행

## 9.1 스테이지 골격 ✅
- 스테이지형 진행 (A안): 규정 웨이브 방어 = 클리어 → 다음 스테이지 해금 → 방치 파밍 기준 갱신
- 스테이지당 웨이브 수 고정 권장 (테이블 관리·방치 보상 계산 단순화)
- Core_HP: 스테이지 단위 리셋, 웨이브 간 지속 (아슬아슬함의 근간)
- 챕터 구조: 7개 지역(기억등) = 7챕터 골격. 챕터 보스 = 지역 기억등 복구 전투
- 지속 압박 섹터: 스테이지마다 1개 지정 (스테이지 내내 얇게 스폰) — 고정형(곁 지키기)의 정답 자리 보장

## 9.2 전투 상태 머신 ✅

```
STAGE_ENTER → PREP → WAVE_LOOP ⟳ → FINAL_WAVE(BOSS) → 최후의 쇄도 → STAGE_CLEAR
                          │                    │
                          └── FAIL 조건 성립 ──┴──→ STAGE_FAIL (즉시)
```

### STAGE_ENTER
1. 스테이지 정보 로드 (웨이브 수 N, 섹터 패턴, 적 구성, 보상)
2. 편성 검증: 최소 1인 / 파견 중 캐릭터 공백 경고 / 배타 원칙 최종 검증
3. 전장 생성: 수선점 중앙, 지킴이 배치 방위 정위치

### PREP (3~5초, 스킵 가능)
- 첫 웨이브 위험 방위 인디케이터 표시 (P2)
- 잔향 초기값 지급 → 개전 즉시 소환/투자 판단 시작 (P1)
- 선배치 조작 가능

### WAVE_LOOP (n = 1 → N-1) — 3중 동시 사이클
```
▶ 적 사이클: 섹터 스폰 → 코어 접근 → 교전/도달
   ├─ 도달 시: Core_HP 감소 → 적 소멸 (기본) / 공성형은 코어에 붙어 지속 공격 (예외)
   └─ 웨이브 전환: 잔존 ≤ 오버랩 임계치 OR 타이머 만료 (선충족) → 누적 압박
▶ 소환 사이클 (초 단위): 잔향 수급 → [판단A] 소환 vs 밝히기 → [판단B] 탭/홀드 방향
▶ 지킴이 사이클 (십수 초): 자동 요격 → 스킬 게이지 → [판단C] 액티브 타이밍
   └─ + [분 단위] 재집결 판단 / [웨이브 간] 잔향 비축 판단
```

### FINAL_WAVE (n = N)
1. 보스 등장 연출 (스킵 가능) — 🔶 이 연출 구간에서 기억 카드 선택 (§11, 미확정)
2. 보스 행동 원칙: 360° 활용 패턴 최소 1개 필수 (전장 순회 / 전 섹터 소환 / 회전·관통 돌진)
3. 페이즈제: Boss_HP 구간(70%/30%)마다 패턴 강화 + 호위 스폰

### 최후의 쇄도 ✅
```
Boss_HP ≤ 0
├─ IF 잔존 적 0 → 즉시 STAGE_CLEAR
└─ ELSE → 쇄도 발동
    ├─ 잔존 적 전원: 광폭화 + 코어 직진 AI 강제 전환
    ├─ 연출: 전원 하이라이트 + "남은 적 N" 카운터 (P2)
    ├─ Core_HP·타이머 판정 유효 (진짜 위험 구간)
    └─ 마지막 1체 정화 → 슬로우 연출 → STAGE_CLEAR
```
- 설계 의도: 보스 올인 vs 주변 정리 병행이 대가 있는 선택이 됨 (P1) / 안티클라이맥스 방지
- 전투 톤: 처치 = **정화** (망각체를 파괴가 아니라 되돌림 — 컨셉 문서 6.2 정합)

## 9.3 공통 예외 처리 ✅
```
├─ 진행 불능 방지: 잔존 적 일정 시간 미교전 → 강제 코어 돌진 AI 전환
├─ 앱 이탈/중단: 전투 스냅샷 저장 → 이탈 시점 그대로 복원 (일시정지 상태)
│   └─ 강제 종료 악용 차단: 복원은 항상 이탈 시점 상태
├─ 일시정지: 무제한, 페널티 없음 (P6) — 타이머·잔향 수급 동결
└─ 소환 상한: §5.4 규격
```

# 10. 종료 조건 ✅

```
[STAGE_CLEAR]
조건: 최종 웨이브 도달 AND 필드 내 모든 적 소멸 (보스 포함)
※ 보스 사망 ≠ 클리어 — 최후의 쇄도 트리거

[STAGE_FAIL] (OR)
① Core_HP ≤ 0 — 전 구간 유효
② Stage_Timer ≥ Time_Limit — 전 구간 카운트

[판정 우선순위 — 같은 프레임 동시 성립 시]
CLEAR > FAIL① > FAIL② (유저 유리 판정 원칙 / 평가 순서: 정화 완료 → Core_HP → Timer)
```

## 10.1 제한시간 규격 ✅
- 스테이지 전체 단위 (웨이브별 아님)
- Time_Limit = 예상 클리어 시간 × 여유 계수 (2.5~3.0) + 쇄도 예상 소요 (+10~20s)
- **상시 노출** — 상단 HUD에 항상 표시, 잔여 20% 진입 시 경고 톤으로 전환
- 목적: 시간 압박 재미가 아니라 화력 미달 교착·방치 악용 차단 (경고 톤 이전 구간은 압박 없는 정보 표시)
- 오프라인 자동 파밍: 클리어 스테이지 순회라 타임아웃 비발생 구조. 자동 전투 예상 소요 ≤ Time_Limit 검증 항목 등록

## 10.2 실패 후처리 ✅
- 무손실 재도전 (소프트 실패 원칙). 실패 연출 담백하게 — "수선점의 불이 잦아듦" 수준 (톤 보호)
- 실패 리포트 원인별 분리: ① = 뚫린 섹터 + 피해 상위 적 (방어 문제 → 편성 CTA) / ② = 화력 부족 (→ 딜러 강화 CTA)
- CTA 3버튼: 재도전 / 편성 변경 / 성장 바로가기

## 10.3 종료로 취급하지 않는 것 ✅
- 지킴이 전원 전투불능 (잔향이로 버티는 상황 = 최고의 드라마 — 의도된 설계)
- 소환 불가 상태 / 일시정지·앱 이탈
- ⬜ 포기(자발 종료) 시 부분 보상: 미지급 권장 (부분 보상은 무한 모드 전용 문법) — 결정 대기

# 11. 기억 카드 (구 로그라이크 3택) ⬜ 재설계 대기

- 확정된 뼈대: 보스 웨이브 직전 3택 강화 (경량 로그라이크, P1)
