## 0. 요약
- 보유 = 그 계보 **공격력 +N%** (체력 X) · 장착 = **이름 · 초상화만** 바뀜 (전투 그림 X).
- 기능 개방 2-5 클리어. 잠겨 있어도 목록 · 조건은 보이고, 야간 방문은 기록됨.
- 해금 길 8종 (기본 · 야간 방문 · 이벤트 상점 · 스테이지 · 원정 횟수 · 공명 · 형태 해금 · 시즌).

## 1. 현재 구현 (추출)

### 1.1 규칙
```

  외형 % = 그 계보에서 보유한 외형 attackBonusPercent 합   # 상한 없음
```

## 2. 기획 방향 (To-be) — DD

### 2.1 외형의 역할
- 컨셉: 같은 원물(양말)이 **다른 쓰임 · 다른 이야기**를 입은 모습 (`ART_Character_Brief` "양말의 어느 부분 → 어떤 구조 → 새로운 쓰임"). 외형 = **수집 · 표현** 축. 힘의 축은 레벨 · 공명 · 진화.
- 그래서 능력치는 **작게, 계보당 상한 +10%** (D-29 #6). 상한을 넘는 외형은 "보유 효과 최대" 표시 후 순수 수집.

### 2.2 상한 적용 방식 (D-29 #6 구현안)
```
외형 % = min(costumeAtkCapPercent(=10), 보유 외형 % 합)
각 외형 값 = 1 ~ 3% (등급별: 기본 해금 1 · 도전 해금 2 · 이벤트 · 시즌 3)
UI: "보유 효과 공격력 +7% / 최대 +10%"  (CostumeListView 문구에 상한 추가)
```
- 짝짝이 지금 10종 → 값을 1~3%로 다시 매김 (합 ≈ 20 → 상한 10에서 멈춤). 즉 **외형 4~5개면 효과 최대**, 나머지는 수집.

### 2.3 D-45 직업 형태 9종 → 외형 (P1)
| 항목 | 방향 |
|---|---|
| 해금 조건 | 지금 진화 단서 조건을 그대로 외형 해금 조건으로 (StageReached · ExpeditionCount · Resonance 재사용 — 새 종류 불필요) |
| 능력치 | 0% (보는 것만) — 상한이 이미 찼을 가능성이 커서 값이 의미 없음 |
| 그림 | 이미 있는 형태 그림 재사용 (D-45 원칙) |
| 도감 | `form:` → `costume:` 기록 이전, 받은 보상 중복 지급 X (`SYS_Codex` §4) |

### 2.4 전투 그림
- 지금 = 이름 · 초상화만. 전투 스프라이트까지 바꾸면 외형마다 `ART_BattleSpriteSpec` 캔버스 세트가 필요 → **아트 비용 큼**.
- M1 = 지금대로. P1 = **이벤트 · 시즌 외형만** 전투 그림 교체 (과금 · 이벤트 가치), 조건형은 초상화만.

## 4. 예외 처리 / 엣지 케이스
| 케이스 | 처리 |
|---|---|
| 상한 적용 뒤 이미 +49%였던 세이브 | 상한은 계산식에서 적용 → 세이브 이전 불필요 · 전투력이 줄어듦 → **M1 전(출시 전)에 적용**하면 문제 없음 |
| 계보 미보유 상태에서 조건 충족 | `CanUnlock` = false (현재) → 계보를 얻은 뒤 조건 다시 확인, 빨간 점 |
| 기능 잠김(2-5 전) 중 조건 충족 | 목록 · 조건 표시, 받기는 2-5 뒤 (현재) |
| 장착한 외형의 계보를 잔향이로 출격 | 잔향이는 본체 그림 (D-48) — 외형 초상화와 무관 |
| 이벤트 상점 외형을 이벤트 뒤에 원함 | 복각 이벤트에서만 (LiveOps P2) |

## 5. 어뷰징 검토
| 시나리오 | 대응 |
|---|---|
| 기기 시계를 밤으로 바꿔 야간 외형 | 허용 (1회성 외형, 상한 안 능력치 1~3%) — 막는 비용 > 피해 |
| 원정 짧게 반복해 원정 N회 외형 | 의도된 설계 (`SYS_Dispatch` §5와 같음) |
| 상한 없는 지금 구조로 과금 외형 파워 | §3 #1 상한으로 차단 — **결제 외형이 강함의 길이 되지 않게** |

## 6. 확장성 · 유지보수
- 상한 · 값은 데이터(`costumeAtkCapPercent` · `attackBonusPercent`) → 밸런스 조정에 코드 수정 없음.
- 해금 종류 8개로 대부분 커버 — 새 외형은 행 추가만. 새 조건(예: 도감 N개)은 `CostumeUnlockType` 1개 추가.
- 직업 형태 이전(P1)은 **세이브 이전 스크립트**가 필요한 유일한 작업 → `SYS_Save`(P1)에 항목으로 남김.

> 💡 **조합 제안 (검토용)** — 외형 × 원정 의뢰
> 외형마다 "어울리는 의뢰" 태그 (예: mail 외형 = 배달 구역). 그 외형을 **장착한 채** 의뢰를 보내면 의뢰 시간 −10%. 능력치 상한 밖에서 외형에 쓸모를 주고, 전투 편성과 다른 "옷 갈아입혀 보내기" 재미가 생김.
