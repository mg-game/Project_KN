## 0. 요약
- 찾기 기록은 **설치 때부터** 쌓이고, 보상(별조각)과 영구 보너스는 **1-10 클리어(도감 개방) 뒤**부터.
- 첫 발견 별조각 총량 ≈ **2,585** (상한 추정 · §1.3) = 소환 약 26회분. 1-10 개방 순간 "받을 것 쌓임" 연출이 큼.
- ⚠ 시너지 종류 보너스(최대 +15%)가 **불빛 충전 %** → 불빛 게이지는 D-27로 폐지됨 → 지금 효과 0.

## 1. 현재 구현 (추출)

### 1.1 분류와 "찾음" 조건
| 분류 (`CodexCategory`) | 찾음 조건 | 키 | 첫 발견 별조각 |
|---|---|---|---|
| Friend (형태) | 기본형 받음 · 진화로 형태 해금 · 그 밖 해금은 다음 Tick 훑기 | `form:{id}` | 기본형 20 · 1단 30 · 2단 50 |
| Costume (외형) | 외형 해금 (`CostumeUnlocked` · 훑기) | `costume:{id}` | 30 |
| Enemy (적) | 전투에서 그 적을 처음 처치 | `enemy:{id}` | 10 |
| Synergy (시너지) | 전투에서 처음 켜짐 / 마지막 단계 켜짐 | `synergy:{id}` · `synergymax:{id}` | 20 · 30 |
| Material (재료) | 인벤토리에 처음 들어옴 | `material:{id}` | 5 |
| Story (이야기) | 동화책 장을 봄 | — | 없음 (동화책 쪽이 별조각 50) |

### 1.2 규칙
```
찾기 기록: 항상 (도감 잠겨 있어도)
옛 세이브(backfillPending) OR 찾은 것 0 → Connect에서 가진 형태 · 외형 · 재료,
    minStage < 최고 스테이지인 적, 지금 켜진 시너지를 "찾음"으로 채움 (받기는 수동)

IsUnlocked = FeatureGate(Codex) = 1-10 클리어 (정의 없으면 열림)
받기 TryClaim(key) / ClaimAll(분류)
  IF NOT IsUnlocked → 거절
  IF 찾음 AND 안 받음 AND 별조각 > 0 → 지급 · 진행 기록 CodexClaim +1

영구 모음 보너스 AddCollectionBonus(team)   # 받기 없이 저절로, IsUnlocked일 때만
  형태 수 → 공격력 % AND 체력 % (formTiers: 5→1 · 10→3 · 15→5 · 20→7 · 25→8 · 29→10)  # 단계 값 = 합계, 누적 아님
  적 전부 찾음 → ShopMaxHpPercent +5
  켜 본 시너지 종류 수 → LampGainPercent (synergyTiers: 10→5 · 20→10 · 25→15)          # ⚠ 죽은 능력치
  값이 바뀌면 SynergySystem.MarkDirty → 전투력 · 다음 전투 재계산
기타: codex.seenSkills = 스킬 이름 첫 표시(FX-06)용
```

## 2. 기획 방향 (To-be) — DD

### 2.1 도감의 역할 (컨셉 맞춤)
- 컨셉: 수선점은 **"잊힌 것을 기억해 두는 곳"** (`KN_ConceptNarrative`). 도감 = **수선 장부** — 만난 유실자 · 그 모습들 · 싸운 그림자 · 손에 넣은 재료 · 읽은 이야기를 적는 책.
- 보상 구조는 지금 그대로 좋다: 기록은 처음부터 → 1-10에서 한꺼번에 받기 = **중반 첫 "큰 선물"** (FTUE 졸업 직후 소환 2~3회 분량).

### 2.2 영구 보너스 정리
| 보너스 | 지금 | 기획 방향 |
|---|---|---|
| 형태 수 → 공격 · 체력 % | 29개 기준 단계 | D-45 뒤에는 **형태 + 외형 합산 수**로 세고, 단계는 "전체 대비 %"로 데이터화 (§3 #2) |
| 적 전부 → 수선점 내구 +5% | 유지 | 유지 (장이 늘면 "장별 적 전부" P1 검토) |
| 시너지 종류 → 불빛 충전 % | 효과 0 | **잔향 수급 % (`ResonanceRegenPercent`)로 교체, 같은 값** — D-50 #2와 같은 규칙 (§3 #1) |

### 2.3 화면 이름 (D-44 용어)
- 분류 탭: 친구 → **유실자** · 의상 → **외형** · 적 → **그림자** [가정 — 적 총칭이 `KN_Glossary`에 따로 있으면 그쪽] · 시너지 → **조합** · 재료 · 이야기는 그대로.

## 6. 확장성 · 유지보수
- 보너스 단계는 `CodexBonusTier` 리스트 데이터 → 로스터가 늘어도 코드 수정 없음. 단 **고정 개수(29)가 아니라 비율**로 바꾸면 매 업데이트마다 단계를 고칠 필요가 사라짐 (§3 #2).
- 새 분류(예: 장비 · 장소)는 `CodexCategory` 추가 + 찾기 훅 1개 + `KeyPrefix` — 구조 단순.

> 💡 **조합 제안 (검토용)** — 도감 × 방치 오프라인 보상
> 장(지역)마다 **"이 지역 그림자 전부 기록"** 시 그 지역 의뢰(원정) 재료 확률 +5%. 도감을 채우는 이유가 "숫자 %"에서 "그 지역 파밍이 좋아짐"으로 바뀌고, 원정 구역 = 기억등 지역(D-54 #3)과 자연스럽게 묶임.
