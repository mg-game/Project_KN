> 결론 먼저: 던전은 **잔향이 덱만으로 싸우는 화면 없는 층 돌파**이고, 코드 · 데이터 모두 동작한다. 꺼져 있는 확장 2개(**축복 풀 비어 있음 · 입장권 모아 두기 상한 0**)와, 컨셉상 "잔향이는 지킴이 한 발짝 뒤"(D-48)인데 **지킴이 없이 잔향이만 싸우는 이유**를 이야기로 채우는 것이 남은 일.

## 0. 요약
- 1-10 클리어 개방 · 하루 입장권 3장 (현지 05:00 충전, 수요일 +2) · **돌파 성공 때만 입장권 소모** · 소탕 1장 · 한 번에 소탕은 5층 돌파 뒤.
- 층마다 시드 고정 → 같은 덱이면 결과 같음 ("다시 굴리기" 불가 → 키워서 재도전).
- 보상: 단추 + 기억의 실(3층~) · 오르골 태엽(5층~) · 달빛 조각(10층~, 확률).

## 1. 현재 구현 (추출)

### 1.1 규칙
```
도전 Challenge(층)
  IF 기능 잠김(1-10 전) → null
  IF 남은 입장권 0 → 거절
  덱 = 잔향이 덱 (지킴이 없음) · 시작 잔향 30 · 수선점 내구 = CalcShopMaxHp(수선점 레벨)
  시너지 = 덱만 셈 (지킴이 쪽 계보 공명 공격력 X)
  시드 = 층 고정 → 화면 없이 시뮬레이션 (제한 120초, 넘기면 실패)
  성공 → 입장권 −1 · 보상 · "잔향이 출격 N회" 기록 · 최고 층 갱신
  실패 → 입장권 그대로 (같은 결과 반복 가능하니 기록도 안 셈)
소탕 Sweep(돌파한 층) → 입장권 1장, 같은 보상, 출격 기록 X
한 번에 소탕 SweepMany(층, n) → 입장권 n장(남은 만큼), 보상 합산 · DungeonBatchSweep(5층 돌파) 필요
수요 던전 데이 → 그날 입장권 +2
```

## 2. 기획 방향 (To-be) — DD

### 2.1 컨셉 자리
- 잔향이는 "지킴이 한 발짝 뒤"(D-48). 던전은 반대로 **잔향이만** 들어가는 곳 → 이유가 필요.
- 제안: 던전 = **"기억의 안쪽"** — 기억등 안쪽은 지킴이(원물 몸)가 못 들어가고, 기억으로 남은 잔향이만 들어갈 수 있다. 층 = 기억이 깊어지는 단계, 보상(기억의 실 · 오르골 태엽 · 달빛 조각) = 기억 재료라 설정이 맞음. [가정 — `KN_ConceptNarrative` 설정과 충돌하면 그쪽 우선]
- 이름: 탭 = **잔향이 던전** 유지 (기능명 명확) · 화면 제목 · 대사 = "기억의 안쪽" (문구, M1).

### 2.2 꺼진 확장 2개
| 확장 | 지금 | 방향 |
|---|---|---|
| 잔향 축복 (PRG-07) | 풀 비어 있음 → 꺼짐 | **P1** — 축복 8~10종 (잔향 수급 · 소환 비용 · 성향별 공격 등 잔향이 전용 능력치). 던전에 "로그라이트 선택" 재미 추가 |
| 입장권 모아 두기 (NEW-04) | 상한 0 → 날마다 초기화 | **P1** — 상한 6 (2일분). 복귀 유저가 손해 덜 봄. M1은 꺼 둠 (경제 확인 전) |

### 2.3 역할 정리
- 스테이지 = 단추 · 진행 / 의뢰 = 재료 · 시간 / **던전 = 진화 재료(실 · 태엽 · 달빛) + 잔향이 덱 시험장**.
- 단추는 층 1.15 복리라 높은 층에서는 스테이지 단추보다 작아짐 → 던전 가치는 **재료 쪽**에 둠 (의도대로).

## 6. 확장성 · 유지보수
- 층 곡선 · 보상 · 입장권 모두 데이터. 축복 · 모아 두기는 **데이터만 넣으면 켜지는 구조**라 P1 비용이 작음.
- 장이 늘어 적 종류가 늘면 `dungeonStagePerFloor`로 풀이 자동 확장.
- 화면 없는 시뮬레이션 → 서버 검증(P1)으로 옮기기 쉬운 구조 (같은 시드 = 같은 결과).

> 💡 **조합 제안 (검토용)** — 던전 × 도감
> 던전 10층마다 **"기억의 안쪽에서만 만나는 그림자"** 1종 (스테이지엔 안 나옴). 도감 적 칸이 던전으로만 채워져, 도감 "적 전부" 보너스(수선점 내구 +5%)가 던전 진행 목표가 됨.
