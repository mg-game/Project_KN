## 0. 요약
| 종류 | 수 | 세는 법 | 효과 범위 |
|---|---|---|---|
| **특성** (원물 재질) | 7 | 그 특성을 가진 편성 형태 수 (지킴이 + 잔향이 = 2) | 구성원만 |
| **성향** (`CombatStyle`) | 6 | 그 성향 편성 형태 수 | 방어 · 힐 · 지원 = 팀 전체 / 돌격 · 포획 · 저격 = 구성원만 |
| **조합** (관계) | 12 | 정해진 계보가 모두 편성 (지킴이든 잔향이든) | 팀 전체 + 보너스 스킬 |
- 따로: **계보 공명** (같은 계보 여러 칸 → 팀 공격 +%, `FormationSystem`) — 시너지 계산 밖.
- 스테이지 변수(비 · 정전 · 보름달 · 바람 · 먼지 폭풍 · 축제)가 특성 하나를 **×1.5** 강화 (`favoredModifier`).

## 2. 기획 방향 (To-be) — DD

### 2.1 죽은 능력치 교체 (M1 — I-10c와 함께)
| 기존 | 교체 | 값 | 이유 |
|---|---|---|---|
| `LampGainPercent` | **`ResonanceRegenPercent`** (잔향 수급, 이미 있음) | 같은 값 | 불빛 게이지 → 잔향 투자(D-27)로 바뀐 자리 그대로 |
| `LampDamagePercent` | **`LightInvestCostReductionPercent`** 🆕 (수선등 밝히기 비용 감소) | 값 × 0.5 (25 → 12, 35 → 17) [가정] | "빛"의 정체성 유지 · 판단 구조(투자 타이밍)에 붙음 |
| 보름달 "불빛 게이지 충전 증가" | 잔향 수급 +20% | | 문구 · 효과 교체 |

### 2.2 설정집 관계 ↔ 조합 맞추기 (P1)
| 설정집 관계 | 지금 | 할 일 |
|---|---|---|
| 짝짝이 × 레이니 | 기다림의 끝 (드디어 만났어) | 스킬 이름 → **비 오는 날의 분실물 센터** (I-7 뒤 이름 일괄) |
| 키키 × 엘리제 | 잠긴 오르골 (다시 흐르는 노래) | 스킬 이름 → **닫힌 악장의 문** + 효과에 "적 잠시 가두기"(기절) 강화 |
| 엘리제 × 루루팝 | 없음 (축제 퍼레이드 3인에 포함) | **조합 신설** "마지막 곡은 끝나지 않아" — 공속 · 쿨감 팀 · 그림 카드 1 |
| 몽실 × 루루팝 | 없음 | **조합 신설** "오늘의 주인공은 모두야" — 팀 공격 · 체력 · (개화 게이지 → P1 개화 스킬 쿨감) · 그림 카드 1 |

- 연계 스킬(K-11)은 **조합 보너스 스킬**로 들어간다 — 별도 시스템 없음.

### 2.3 새 캐릭터 특성 규칙 (로스터 15, D-49)
```
캐릭터 1명 = 특성 2개
  IF 신규 → 기존 특성 1개 이상 포함 (조합 진입 쉽게)
  특성당 인원 목표: 정식 15명 기준 3~4명 (지금 비 1명 · 금속/빛/소리/밤/치장 2명 → 신규로 채움)
  새 특성은 최대 1종 추가 (총 8종)
조합: 설정집 관계가 있는 쌍만 조합으로 (억지 조합 금지) · 신규 1명당 조합 1~2개
```
| 신규 [가정] | 특성 | 조합 후보 |
|---|---|---|
| 푸딩 경 | 밤 (야식) + **말랑** 🆕 | 몽실 × 푸딩 경 (생일 케이크) |
| 네임리스 00 | 금속 (명찰) + 소리 (이름 부르는 목소리) | 키키 × 네임리스 00 (이름표와 열쇠) |
| 2~6장 신규 6명 | 비 · 빛 · 치장 우선 채움 | 구조 이야기에서 생기는 관계로 |

### 2.4 화면 (현재 구현 유지)
- 편성 화면 오른쪽 "팀 시너지" 칸: 켜진 것 + **한 명만 더 있으면 켜지는 것(흐리게)** + 끌어 놓기 미리보기(금빛 = 새로 켜짐 / 붉게 = 꺼짐) — **이미 있음, 유지**
- 전투 시작 "시너지 발동!" 띠 — 유지
- 캐주얼 부담: M1 테스트에서 "시너지 칸을 봤나 · 이해했나"만 확인 (설문 1문항)

## 6. 확장성 · 유지보수
- 시너지 추가 = 데이터 1행 (+ 조합이면 그림 카드 1) — 코드 수정 없음

> 💡 **조합 제안 (검토용)** — 시너지 × 구조 이야기
> 조합을 처음부터 다 보여 주지 않고, **구조 이야기(K-08)에서 두 캐릭터가 만나는 장면을 본 뒤에 조합 카드가 도감에 생기게** 한다 (효과는 그 전부터 작동, 이름 · 그림만 잠김). "둘이 이런 사이였어?"가 시너지 발견이 되어, 시너지 표를 외우는 대신 이야기로 기억하게 됨.
