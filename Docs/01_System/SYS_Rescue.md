> 컨셉의 약속: **"모든 캐릭터가 우연히 수선점 문을 두드리거나 구조 직후 충성하는 방식은 피한다. 플레이어가 직접 찾아가 관계를 만든다."** 지금 코드에는 이 길이 없다 — 캐릭터는 시작 지급 · 첫 만남 확정 소환 · 소환(가챠) · 선택권으로만 들어온다. 이 문서는 **구조라는 두 번째 입구**와 **머무는 이유 6단계**를 기존 시스템(호감도 · 진화 · 동화책)에 얹는다.

## 0. 요약
- 새 입구 = **유실표 → 구조 전투 → 임시 수선 → 합류**. 별도 콘텐츠가 아니라 **원정 탭 안 "유실표 장부"** + 기존 전투의 변형 1종(구조 전투).
- 머무는 이유 6단계(피난자 → 작은 수선사) = **새 수치 없이** 기존 진행에 묶음: 구조 · 호감도 Lv.3 · 기억 각성 · 호감도 Lv.6 · 호감도 Lv.8 · 개화.
- ⚠ 숫자 불일치 발견: D-46 #1 정식 출시 15명 ↔ D-46 #3 "장마다 구조 1명" — 2~7장 6명 + 시작 5명 = 11 ≠ 15 (§3 #2).
- M1 = 없음 (D-35 메타 그대로, 레이니 첫 만남은 연출만 "구조", D-32). P1부터.

## 2. 기획 방향 (To-be) — DD

### 2.1 구조 흐름 (컨셉 §5.2 → 게임 동작)
```
[유실물 종] 장 진행 지점(x-5 · x-10 클리어) 도달
  → 수선점 종 연출 + 홈 알림 칩 "유실표가 도착했어요"
  → 원정 탭 · 유실표 장부에 카드 1장 (이름 · 위치 없이 수수께끼 문구만)
[흔적 조사] 유실표 카드 = 흔적 3칸
  → 그 장 스테이지 파밍 · 원정(파견)으로 흔적 채움 (기억 조각 대신 "흔적" 진행도)
  → 3칸 다 차면 [찾아가기] 켜짐
[최초 조우] 짧은 대화 컷 (2~4컷) — 캐릭터는 우호적이지 않음 (컨셉 §5.2-3의 6유형 중 1)
[구조 전투] 전투 1판 (변형, §2.2) — 이기면 다음, 지면 흔적 1칸만 남기고 다시 도전 (흔적 일부 유지)
[임시 수선] 컷 1장: "이름과 형태를 임시 매듭으로" → 캐릭터 획득 (= 손님 단계)
  → 잔향이 사용 가능 (컨셉: 손님부터 잔향이 가능)
[수선점 체류] 홈 · 수선점(P1 집)에 손님으로 등장
```

### 2.2 구조 전투 — 기존 전투의 변형 1종
| 항목 | 일반 전투 | 구조 전투 |
|---|---|---|
| 지키는 것 | 수선점 (가운데) | **수선점 + 구조 대상**(수선점 바로 앞, "형태 게이지") |
| 지는 조건 | 수선점 내구 0 · 시간 끝 | **형태 게이지 0** · 수선점 내구 0 · 시간 끝 |
| 적 | 장 적 풀 | 장 적 풀 + **대상을 노리는 망각체 1종**(그림자 계열, 대상 쪽으로만 감) |
| 웨이브 | 3~5 | 3 (짧게) |
| 보스 | 있음 | 없음 → 대신 마지막 웨이브 "망각의 손길" 360° (`CNT_Boss` 링 소환 재사용) |
| 구조 대상 | — | 전투 중 지킴이로 못 씀 · 끝나면 합류 |

- 구현 = 수선점 옆에 "대상" 오브젝트 하나 + 지는 조건 하나 + 링 소환 재사용 (I-10h). 새 화면 없음.

### 2.3 머무는 이유 6단계 = 기존 진행에 묶기
| 합류 단계 (컨셉 §5.3) | 서사 마일스톤 (§5.5) | 게임 조건 (기존 시스템) | 열리는 것 |
|---|---|---|---|
| 피난자 | 1 유실 | 구조 전투 중 | — (잔향이 불가) |
| 손님 | 2 임시 수선 | **구조 완료 = 획득** | 편성 · 잔향이 · 레벨업 |
| 동행자 | — | **호감도 Lv.3** | 개인 이야기 시작 (호감도 짝수 단계 이야기 줄을 이 캐릭터 이야기로) |
| 수선 동료 | 3 기억 회수 → 4 다시 잇기 | **기억 각성 (한계 돌파 20, D-45)** + **호감도 Lv.6** 에피소드 "다시 잇기" | 기억형 · (P1) 잔향이 또렷함 +1 |
| 주민 | 5 새로 잇기 | **호감도 Lv.8** 에피소드 "새로 잇기" | 홈 행동 · 대표 대사 변경 · 개화 단서 보너스 |
| 작은 수선사 | 6 개화 | **개화 제작 (D-45)** | 개화형 · 잔향이 따라잡음 (D-48) · 도감 칸 |

- **새 수치 · 새 화폐 없음.** 단계 표시는 캐릭터 상세에 "손님 → 동행자 …" 한 줄 + 다음 단계 조건.
- 개인 에피소드 = 캐릭터당 **2편**(다시 잇기 · 새로 잇기) + 구조 이야기 1편 → 9명 × 3 = 27편 (짧은 컷 대화).

### 2.4 입구 정리 — 구조 vs 소환
| 입구 | 누구 | 역할 |
|---|---|---|
| 시작 지급 · 첫 만남 | 1장 5명 | 튜토리얼 (현재) |
| **구조** | 2장~ 이야기 캐릭터 | **첫 획득 = 무료 확정** · 서사 · 합류 단계 시작 |
| 소환 (가챠) | **출시된 캐릭터 전부** — 구조 전에 뽑으면 "먼저 만남"(손님 합류, 구조 이야기는 나중에 그대로) (D-51 #1, D-49 #3 대체) | 새 친구를 먼저 만나는 설렘 + 중복 → 기억 조각 |
| 친구 선택권 | 소환 풀과 같음 (전설 이하) | 현재 규칙 유지 |

- ~~구조한 캐릭터만 소환~~ → D-51 #1로 대체: 소환 = 유실물 종 지름길 (`SYS_Gacha` §2.1). 구조 이야기는 소환 결과와 관계없이 누구나 봄.

## 4. 예외 처리 / 엣지 케이스
| 케이스 | 처리 |
|---|---|
| 이미 소환으로 가진 캐릭터의 유실표 (이전 세이브 · 이벤트) | 유실표는 오고 구조 전투도 하지만 결과 = 중복(기억 조각) + 이야기 · 합류 단계 시작 |
| 구조 대상이 잔향이로 쓰이는 중 (중복 보유) | 구조 전투 편성에서 그 계보는 빠짐 |
