# LOST & LOVELY — design documents

Copies of the working specs used to build the game (snapshot 2026-11-05, after UX Wave 3 and RM-1). The game is built from code
(editor builders + content-in-code), so these documents explain *why* things are the way they are and
what is planned next.

| File | What it is |
|---|---|
| `UX-SPEC.md` | UI/UX overhaul: design tokens, per-screen changes (Mxx findings), cross-cutting behaviour, packages WP-0…WP-9, acceptance |
| `UX-SPEC-IA.md` | The screen frame: big battle map by default (MAIN), feature tabs as sheets, centre 사냥 button, ≡ menu, quick rails |
| `FX-JUICE-SPEC.md` | Battle effects / hit-feel spec (tiers, recipes, numbers, budgets, art list) |
| `AUDIO-SPEC.md` | Sound: key catalogue, sourcing rules (original synthesis + CC0), engine, battle listener, hooks |
| `SPEC4.md` | Phase 4 systems (collection, progression, events, return, platform) |
| `SPEC5.md` | R2 systems (weekly guest, techniques, cap breaks, errands, tower, hubs, …) |
| `PHASE4-ROADMAP.md` | Order of all remaining work (waves RM-1…RM-10), ownership, gates, art credits |
| `IDLE_RESEARCH2.md` | Idle-genre research backlog and dispositions |
| `ART-UPGRADE-PLAN.md` | Higgsfield art plan (batches, prompts, QA) |
| `PROGRESSION-SIM.md` | Economy/progression simulation and the curve fix |
