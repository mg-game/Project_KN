# 1부. 게임 개요

## 1.1 한 줄
> **잊힌 물건에서 태어난 이상하고 사랑스러운 유실자들을 모아, 날아다니는 수선점을 지키는 360° 방치 디펜스 RPG.**

| 항목 | 내용 |
|---|---|
| 게임명 | LOST & LOVELY (D-12) |
| 장르 | 캐릭터 수집형 방치 디펜스 RPG (경량 로그라이크 가미) |
| 플랫폼 | 모바일 iOS / AOS, 세로 고정 · 한 손 조작 · Unity 6000.2.6f2 (D-13) |
| 플레이 형태 | 싱글 · 오프라인 중심 · 랭킹 없음 (P6 혼자 자기 속도로) |
| 타겟 [가정] | 방치형 키우기를 즐기는 캐주얼 ~ 미드코어, 귀엽고 살짝 기묘한 캐릭터 수집을 좋아하는 층 |

## 1.2 핵심 루프
```
[자동 진행 전투] 수선점을 360°에서 지킴 — 지킴이 배치 · 잔향이 소환 · 수선등 밝히기
      │ 클리어 → 다음 스테이지 / 2연패 → 한 단계 아래 파밍 (D-28)
      ▼
[보상] 단추 · 재료 · 기억 조각 · 별조각        [방치] 수선 바구니 (앱을 닫아도 쌓임, D-31)
      │                                          │
      ▼                                          ▼
[성장] 계보 레벨(공유) · 공명 · 수선점 · 진화 (D-29) ◀──┘
      │
      ▼
[수집] 소환 · (P1) 구조 → 새 유실자 합류 → 편성 고민 → 다시 전투
```

## 1.3 차별점 3
| # | 차별점 | 무엇이 다른가 |
|---|---|---|
| 1 | **지키는 집이 곧 홈** | 전투 코어 = 꾸미고 키우는 수선점 그 자체 (시스템 §2.2). 진행할수록 예뻐지는 코어 |
| 2 | **한 캐릭터, 두 모드** | 같은 유실자가 지킴이(본체 · 최애)로도 잔향이(분신 · 물량)로도 선다. "누구를 어디에" 판단 (시스템 §4.1) |
| 3 | **웃겨서 뽑고, 진화가 궁금해 키우고, 이야기를 알고 최애가 된다** | 사물이 몸이 된 캐릭터 · 예상 밖 진화 · 관계 서사 (컨셉 · 아트 가이드) |

## 1.4 BM 방향 [미정]
- 하드 재화 별조각(유료 · 무료 2풀, D-30) → 소환 · 빠른 수선 · 상점. 상세는 `SYS_Gacha` · `SYS_Shop` (P1).
- 원칙: 희귀도 ≠ 서열(P3) — 과금이 "더 빨리"는 사도 "더 강한 유일 정답"은 사지 않게.
