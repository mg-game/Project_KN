## 2. 전투 · 시스템

| 용어 | 정의 | 비고 | 구 용어 |
|---|---|---|---|
| 지킴이 | 전장에 직접 서는 본체. 수선점 주위에 배치하는 최대 5인 | 편성 역할명 | 유실자 모드 |

| 재집결 | 전투 중 지킴이 진형을 한 번에 재배치 (쿨다운제) | ⚠ 미구현 | |

## 4. 코드 대응표

기획 용어 ↔ 코드 식별자. 코드 리뷰 · 기개발 지시 때 이 표를 기준으로 한다.

| 기획 용어 | 코드 식별자 (PR #2) | 비고 |
|---|---|---|
| 지킴이 | `GuardianUnit` · `GuardianState` · `GuardianSlotView` | |
| 잔향이 | `EchoUnit` · `EchoView` | |
| 수선점 내구 | `ShopHp` | 기획 `Core_HP` |
| 불 밝히기 게이지 | `LampGauge` · `LampPolicy` | ⚠ 기획의 수선등 밝히기와 다른 기능 |
| (계보) | `Lineage` | ⚠ 기획서에 없는 개념. 한 원물의 캐릭터 계열 |
| (형태) | `FormId` | ⚠ 기획서에 없는 개념. 계보 안의 개별 형태 (진화 단계 · 분기) |
| 원정 · 의뢰 | `ExpeditionSystem` | 탭 = 원정 · 쪽 = 의뢰 (D-54) |
| 시너지 | `SynergySystem` | |
| 호감도 | `AffinitySystem` | 기획 "합류 단계 · 관계" |
| 도감 | `CodexSystem` | |
| 외형 | `CostumeSystem` · `CostumeDef` | 화면 "의상" → "외형" (D-55 · D-60) |
| 진화 | `EvolutionSystem` | 기획 유실 → 기억 각성 → 개화 A/B (D-45, P1) |
| 도감 분류 | `CodexCategory` (Friend · Costume · Enemy · Synergy · Material · Story) | 화면 유실자 · 외형 · **그림자** · 조합 · 재료 · 이야기 (D-55) |

> 계보 · 형태와 기획서 "캐릭터 · 진화 단계"의 대응은 I-7(캐릭터 이름 대조표) 결과로 확정한다. 그 전까지 코드 이름 ↔ 기획 이름은 [`KN_M1_DevBrief`](./KN_M1_DevBrief.md) §0.4.
