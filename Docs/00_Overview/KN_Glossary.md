## 1. 세계관

| 용어 | 정의 | 비고 | 구 용어 |
|---|---|---|---|
| 로스트 타운 | 잊힌 기억과 오래된 장소가 뒤섞인 밤의 도시 | | |
| 유실자 | 잊힌 물건·감정에서 태어난 존재. 수집 캐릭터 전체를 가리키는 종족명 | | 히어로 |
| 잔향 | 물건에 쌓인 시간과 감정의 여운. 유실자를 이루는 힘이자 전투에서 소모하는 자원 | 에너지 상태 | 꿈가루 |
| 수선점 | 날아다니는 살아있는 집. 홈이자 전장의 중심(코어) | | 코어 |
| 결계 | 수선점이 펼치는 빛의 안전 구역. 전장에서는 원형 결계 링으로 보인다 | | |
| 망각 | 로스트 타운을 뒤덮는 검은 안개와 그 힘 | | |

| 다시 잇기 / 새로 잇기 | 과거와 화해하는 단계 / 새로운 삶을 만드는 단계 | 순차 진행 | |

## 2. 전투 · 시스템

| 용어 | 정의 | 비고 | 구 용어 |
|---|---|---|---|
| 지킴이 | 전장에 직접 서는 본체. 수선점 주위에 배치하는 최대 5인 | 편성 역할명 | 유실자 모드 |
| 잔향이 | 유실자의 잔향이 수선점의 빛 안에서 잠시 형태를 얻은 소환 분신 | 형태 상태 | 잔향체 · 소환 유닛 · 꿈조각 · 에코 |
| 수선등 밝히기 | 전투 중 잔향을 투자해 잔향 수급 레벨을 올리는 트랙 | ⚠ 코드는 "불 밝히기" = 게이지 전체 공격 | 수급 강화 |
| 재집결 | 전투 중 지킴이 진형을 한 번에 재배치 (쿨다운제) | ⚠ 미구현 | |
| 최후의 쇄도 | 보스 사망 후 잔존 적이 광폭화해 코어로 돌진하는 구간 | ⚠ 미구현 | |
| 앞장서기 / 함께 걷기 / 곁 지키기 | 행동 성향 3종 | ⚠ 미구현 | 돌격형 / 순회형 / 고정형 |
| 성격 | 캐릭터 고유 행동 특성 (불변) | ⚠ 미구현 | |
| 기억 카드 | 보스 전 3택 강화 (런 중 개화 연계 예정) | 재설계 대기 | 로그라이크 3택 |
| 공명 | 개화한 유실자가 지킴이와 잔향이로 동시에 설 수 있는 예외 | 검토 중 · ⚠ 코드에는 "계보 공명" 시너지가 이미 있음 | |
| 수선 의뢰(파견) | 재료·기억 조각 회수를 위해 유실자를 내보내는 일 | ⚠ 코드 표기 "원정", 파견 중 편성 가능 | 원정(파견) |
| 외형변경 | 수선 재료와 이야기로 얻는 대체 외형 | ⚠ 코드 표기 "코스튬" | 코스튬 |
