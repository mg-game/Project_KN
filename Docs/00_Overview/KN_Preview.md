## 2. 운영 규칙 (D-42)
1. **착시 금지** — 화면마다 "기획 미리보기 · 수치 [가정]" 표시. **밸런스 · 난이도 판단에 쓰지 않는다** (판정 · 수치는 단순화 모델)
2. **정본은 기획서** — 미리보기에 기준 결정 번호 · 날짜를 박는다. 기획서와 다르면 기획서가 맞다
3. **범위 = M1 P0 화면만** — 전투 · 편성 · 레벨업 · 홈. 그 밖은 만들지 않는다
4. **실기기 감각은 Unity 빌드에서** — 터치감 · 성능 · 화면 비율 · Unity UI 제약은 R3 / 앱 빌드로 판단
5. **공유는 팀 안에서만** — 실제 게임 아트가 들어 있음
6. **갱신은 화면 흐름이 바뀌는 결정이 나올 때만** — 수치만 바뀌면 갱신하지 않음
